# 树状数组

## 区间修改，单点查询

> 对区间 `[l, r]` 整体加一个值，等价于在差分数组上做单点修改：`diff[l] += v`，`diff[r + 1] -= v`。
>
> 用树状数组维护差分数组后：
>
> - 区间修改 → 两次单点修改：`update(l, v)`、`update(r + 1, -v)`。
> - 单点查询 → 一次前缀和查询：位置 $i$ 的最终值 = `sum(i)`。
>
> 复杂度：每次修改/查询均为 $O(\log n)$，总复杂度 $O(n \log n)$。

## 区间修改，区间查询

> 在差分的基础上再进一步：前缀和 $P(x) = \sum_{i \le x} a_i = \sum_{j \le x} d_j \cdot (x - j + 1) = (x + 1) \cdot \sum d_j - \sum j \cdot d_j$。
>
> 用两个树状数组维护差分数组：
>
> - `tr1` 维护 $d_j$ 的前缀和，`tr2` 维护 $(j - 1) \cdot d_j$ 的前缀和。
> - 区间修改 `[l, r]` 加 `v` → `tr1`：`update(l, v)`、`update(r + 1, -v)`；`tr2`：`update(l, (l - 1) * v)`、`update(r + 1, -r * v)`。
> - 前缀和查询 → `P(x) = x * sum(tr1, x) - sum(tr2, x)`，区间查询 `[l, r]` = `P(r) - P(l - 1)`。
>
> 复杂度：每次修改/查询均为 $O(\log n)$，总复杂度 $O((n + m) \log n)$。
