# 连通分量

## 有向图的连通分量

### Kosaraju

原图 DFS，点结束递归时压入序列。再按该序列的逆序，在反图上 DFS。反图上每次新起点走出的点集就是一个强连通分量。

点编号从 $1$ 到 $n$。原图有边 $u \to v$ 时，同时记下反图的边 $v \to u$。

```cpp
// G 为原图，rG 为反图。返回各强连通分量的点集。
// scc 的先后顺序是缩点后拓扑序的逆序。
std::vector<std::vector<int>> kosaraju(const std::vector<std::vector<int>>& G,
                                       const std::vector<std::vector<int>>& rG) {
    int n = (int) G.size() - 1;
    std::vector<bool> st(n + 1);
    std::vector<int> order;
    auto dfs1 = [&](this auto&& dfs1, int u) -> void {
        st[u] = true;
        for (int v : G[u]) {
            if (!st[v]) {
                dfs1(v);
            }
        }
        order.push_back(u);
    };
    for (int i = 1; i <= n; i++) {
        if (!st[i]) {
            dfs1(i);
        }
    }

    std::vector<std::vector<int>> scc;
    auto dfs2 = [&](this auto&& dfs2, int u) -> void {
        scc.back().push_back(u);
        st[u] = true;
        for (int v : rG[u]) {
            if (!st[v]) {
                dfs2(v);
            }
        }
    };
    std::fill(st.begin(), st.end(), false);
    for (int i = (int) order.size() - 1; i >= 0; i--) {
        if (!st[order[i]]) {
            scc.push_back({});
            dfs2(order[i]);
        }
    }
    return scc;
}
```

- 建图：`G[u].push_back(v);`，`rG[v].push_back(u);`。`G`、`rG` 的大小都是 $n + 1$。
- 时间 $O(n + m)$，空间 $O(n + m)$。
- 两遍 DFS 之间要清空访问标记。第二遍必须走反图，并且按第一遍结束顺序的逆序启动。
- 需要分量编号时，按 `scc` 的下标给点打标记：`bel[u] = i`。
- 递归实现，依赖 C++23 的显式对象参数。链长接近 $n$ 时注意栈深度。
- 例题：CF 427C Checkposts。

### Tarjan

一遍 DFS。$dfn_u$ 是 $u$ 第一次被访问的时间戳。$low_u$ 是 $u$ 及其子树经过最多一条指向栈中点的边，能回到的最小 $dfn$。$low_u = dfn_u$ 时，$u$ 是一个强连通分量的根，栈顶一直弹到 $u$，这些点组成该分量。

点编号从 $1$ 到 $n$。只建原图，不需要反图。

```cpp
// G 为原图。返回各强连通分量的点集。
// scc 的先后顺序是缩点后拓扑序的逆序。
std::vector<std::vector<int>> tarjan(const std::vector<std::vector<int>>& G) {
    int n = (int) G.size() - 1;
    std::vector<int> dfn(n + 1), low(n + 1);
    std::stack<int> stk;
    std::vector<bool> inStk(n + 1);
    int ts = 0;
    std::vector<std::vector<int>> scc;
    auto dfs = [&](this auto&& dfs, int u) -> void {
        dfn[u] = low[u] = ++ts;
        stk.push(u);
        inStk[u] = true;
        for (int v : G[u]) {
            if (!dfn[v]) {
                dfs(v);
                low[u] = std::min(low[u], low[v]);
            } else if (inStk[v]) {
                low[u] = std::min(low[u], dfn[v]);
            }
        }
        if (low[u] == dfn[u]) {
            scc.push_back({});
            while (true) {
                int v = stk.top();
                stk.pop();
                inStk[v] = false;
                scc.back().push_back(v);
                if (v == u) {
                    break;
                }
            }
        }
    };
    for (int i = 1; i <= n; i++) {
        if (!dfn[i]) {
            dfs(i);
        }
    }
    return scc;
}
```

- 建图：`G[u].push_back(v);`。`G` 的大小是 $n + 1$。
- 时间 $O(n + m)$，空间 $O(n + m)$。
- 只有还在栈里的点才能更新 $low$（代码里用 `inStk` 标记）。已经弹进其他分量的点即使 $dfn$ 非 $0$，也不能拿来更新。
- $low_u = dfn_u$ 时 $u$ 是当前分量的根。访问 $u$ 时必须先入栈，否则这里对空栈取栈顶。
- 需要分量编号时，按 `scc` 的下标给点打标记：`bel[u] = i`。
- 递归实现，依赖 C++23 的显式对象参数。链长接近 $n$ 时注意栈深度。
- 例题：HDU 1269 迷宫城堡。

## 无向图的连通分量

### 割点（Tarjan）

无向图没有强连通分量的概念，但可以求割点与桥。$dfn_u$ 是 $u$ 第一次被访问的时间戳。$low_u$ 是 $u$ 及其子树不经过 $u$ 的父亲就能回到的最小 $dfn$。

若 $v$ 是 $u$ 的树边儿子且 $low_v \ge dfn_u$，说明 $v$ 的子树无法绕过 $u$ 回到 $u$ 的祖先，删掉 $u$ 后 $v$ 的子树就与祖先部分断开，$u$ 是割点。根节点没有祖先可回退，需要至少两棵子树才是割点。

点编号从 $1$ 到 $n$，图可以不连通，允许重边。

```cpp
// G 为无向图（每条边两端点各 push 一次，允许重复边）。
// 返回大小为 n + 1 的标记数组 cut，cut[u] == 1 表示 u 是割点。
std::vector<int> cutVertices(const std::vector<std::vector<int>>& G) {
    int n = (int) G.size() - 1;
    std::vector<int> dfn(n + 1), low(n + 1), cut(n + 1);
    int ts = 0, root = 0;
    auto dfs = [&](this auto&& dfs, int u, int fa) -> void {
        dfn[u] = low[u] = ++ts;
        int cnt = 0;
        for (int v : G[u]) {
            if (v == fa) {
                continue;
            }
            if (!dfn[v]) {
                cnt++;
                dfs(v, u);
                low[u] = std::min(low[u], low[v]);
                if (u != root && low[v] >= dfn[u]) {
                    cut[u] = 1;
                }
            } else {
                low[u] = std::min(low[u], dfn[v]);
            }
        }
        if (u == root && cnt >= 2) {
            cut[u] = 1;
        }
    };
    for (int i = 1; i <= n; i++) {
        if (!dfn[i]) {
            root = i;
            dfs(i, -1);
        }
    }
    return cut;
}
```

- 建图：对边 $u - v$ 执行 `G[u].push_back(v);`，`G[v].push_back(u);`。`G` 的大小是 $n + 1$。
- 时间 $O(n + m)$，空间 $O(n + m)$。
- 割点判据必须写成 $low_v \ge dfn_u$，且只能对树边儿子 `dfn[v] == 0` 判断。写成 `low[v] >= low[u]` 会恒真（回溯后 $low_u \le low_v$）；把判定放到树边分支之外，则已访问的后代（重边输入时会出现）也会触发误判。
- 无向图 DFS 中，已访问的非父点要么是祖先（真回边，取 $dfn_v$ 更新正确），要么是后代（该边在对方那一侧已按回边处理过，且 $dfn_v > dfn_u \ge low_u$，`min` 是空操作），所以用 `dfn[v]` 更新 $low_u$ 即可，不必再判 `dfn[v] < dfn[u]`；跳过父点 `fa` 的写法在重边输入下也是安全的（割点判据只看儿子的 $low$，父点方向的 $low$ 被少算不会漏报或误报）。
- 图可能不连通，每个未访问点都要单独起一次 DFS，并在启动前把 `root` 设为该点。
- 求桥见下一节：判据换成 $low_v > dfn_u$，命中的是树边而非点，也不需要根节点特判；但跳过父边的写法不能照搬这里。
- 递归实现，依赖 C++23 的显式对象参数。链长接近 $n$ 时注意栈深度。
- 例题：OpenJ_Bailian 1144 Network。

### 割边（Tarjan）

延续割点的记号。$v$ 是 $u$ 的树边儿子时，若 $low_v > dfn_u$，说明 $v$ 的子树一条回到 $u$ 或 $u$ 祖先的边都没有，删掉边 $u - v$ 后图就断成两半，$u - v$ 是桥。判据比割点严格一格（是 $>$ 而不是 $\ge$）：割点只要求 $v$ 的子树回不到 $u$ 的祖先，$v$ 还连得住 $u$；桥则要求 $v$ 的子树连 $u$ 都碰不到。桥也不涉及根节点特判。

点编号从 $1$ 到 $n$，图可以不连通，允许重边。

```cpp
// G 为无向图（每条边两端点各 push 一次，允许重复边）。
// 返回所有桥，每个元素为 {min(u, v), max(u, v)}，按字典序排序。
std::vector<std::pair<int, int>> bridges(const std::vector<std::vector<int>>& G) {
    int n = (int) G.size() - 1;
    std::vector<int> dfn(n + 1), low(n + 1);
    std::vector<std::pair<int, int>> res;
    int ts = 0;
    auto dfs = [&](this auto&& dfs, int u, int fa) -> void {
        dfn[u] = low[u] = ++ts;
        bool skipped = false; // 是否已经跳过通往父点的那一条边
        for (int v : G[u]) {
            if (v == fa && !skipped) {
                skipped = true; // 只跳一条，重边里剩下的几条是真正的回边
                continue;
            }
            if (!dfn[v]) {
                dfs(v, u);
                low[u] = std::min(low[u], low[v]);
                if (low[v] > dfn[u]) {
                    res.push_back({std::min(u, v), std::max(u, v)});
                }
            } else {
                low[u] = std::min(low[u], dfn[v]);
            }
        }
    };
    for (int i = 1; i <= n; i++) {
        if (!dfn[i]) {
            dfs(i, -1);
        }
    }
    std::sort(res.begin(), res.end());
    return res;
}
```

- 建图：对边 $u - v$ 执行 `G[u].push_back(v);`，`G[v].push_back(u);`。`G` 的大小是 $n + 1$。
- 时间 $O(n + m)$，空间 $O(n + m)$。
- 判据只能放在树边分支里，且必须写成 $low_v > dfn_u$。写成 $low_v \ge dfn_u$ 会把割点判据混进来，$u$ 的每条树边都会被误报为桥。
- 跳过父边不能照搬割点那里的 `v == fa`：$u$ 与父点之间有两条重边时，其中一条是真正的回边，全跳过会把这条非桥误判成桥。上面用 `skipped` 只跳一条，因此仍然只传父点即可，不必给边编号。
- 无向图 DFS 中已访问的非父点要么是祖先（真回边，取 $dfn_v$ 更新正确），要么是后代（那条边在对方那一侧已经当回边处理过，且 $dfn_v > dfn_u \ge low_u$，`min` 是空操作），所以 `else` 分支直接写即可，不用判 $dfn_v < dfn_u$。
- 图可能不连通，每个未访问点都要单独起一次 DFS。
- 求边双连通分量：先求出所有桥，再在删掉这些桥的图上 DFS 染色，每个连通块就是一组边双。
- 递归实现，依赖 C++23 的显式对象参数。链长接近 $n$ 时注意栈深度。
- 例题：洛谷 P1656 炸铁路。
