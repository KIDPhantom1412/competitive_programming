# 数据结构模板

## 树状数组

### 单点修改，区间查询

```cpp
const int N = int(1e5) + 5;

int n;
int tr[N];

void update(int x, int d) { // 单点修改：A[x] += d
    for (int i = x; i <= n; i += i & -i) {
        tr[i] += d;
    }
}

int sum(int x) { // 前缀和查询：A[1..x]
    int res = 0;
    for (int i = x; i; i -= i & -i) {
        res += tr[i];
    }
    return res;
}

int sum(int l, int r) { // 区间查询：A[l..r]
    return sum(r) - sum(l - 1);
}
```

- 多测时记得清空：`std::fill(tr, tr + n + 5, 0);`

### 区间修改，单点查询

设 `D` 为 `A` 的差分数组（`D[i] = A[i] - A[i - 1]`）。区间加 `[l, r]` 等价于 `D[l] += d`、`D[r + 1] -= d`，单点值即差分前缀和：`A[x] = D[1] + ... + D[x]`。

```cpp
const int N = int(1e5) + 5;

int n;
int tr[N];

void update(int x, int d) {
    for (int i = x; i <= n; i += i & -i) {
        tr[i] += d;
    }
}

int sum(int x) {
    int res = 0;
    for (int i = x; i; i -= i & -i) {
        res += tr[i];
    }
    return res;
}

void update(int l, int r, int d) { // 区间修改：A[l..r] += d
    update(l, d), update(r + 1, -d);
}

// 单点查询：sum(x) 即 A[x] 的最终值
```

- 多测时记得清空：`std::fill(tr, tr + n + 5, 0);`

### 区间修改，区间查询

设 `D` 为 `A` 的差分数组，`PS(x) = A[1] + ... + A[x]` 为前缀和。展开可得 `PS(x) = Σ D[j]·(x - j + 1)`，用两个树状数组分别维护：

- `tr1` 存 `D[j]` 的前缀和，记 `S1(x) = Σ D[j]`（`j ≤ x`）
- `tr2` 存 `(j - 1) * D[j]` 的前缀和，记 `S2(x) = Σ (j - 1)·D[j]`（`j ≤ x`）

则前缀和公式：`PS(x) = x * S1(x) - S2(x)`，区间和 `[l, r] = PS(r) - PS(l - 1)`。

```cpp
const int N = int(1e5) + 5;

using LL = long long;

int n;
LL tr1[N], tr2[N];

void update(LL* tr, int x, LL d) {
    for (int i = x; i <= n; i += i & -i) {
        tr[i] += d;
    }
}

LL sum(LL* tr, int x) {
    LL res = 0;
    for (int i = x; i; i -= i & -i) {
        res += tr[i];
    }
    return res;
}

LL sum(int x) { // 前缀和查询：A[1..x]
    return x * sum(tr1, x) - sum(tr2, x);
}

void update(int l, int r, LL d) { // 区间修改：A[l..r] += d
    update(tr1, l, d), update(tr1, r + 1, -d);
    update(tr2, l, (l - 1) * d), update(tr2, r + 1, -r * d);
}

LL sum(int l, int r) { // 区间查询：A[l..r]
    return sum(r) - sum(l - 1);
}
```

- 建树时直接 `update(i, i, A[i])`，不要再手动差分。
