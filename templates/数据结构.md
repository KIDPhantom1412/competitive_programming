# 数据结构模板

## 树状数组（单点修改，前缀和查询）

```cpp
const int N = int(1e5) + 5;

int n;
int tr[N];

void update(int x, int d) {
    for (int i = x; i <= n; i += i & -i) {
        tr[i] += d;
    }
}

int sum(int x) {
    int res = 0;
    for (int i = x; i; i -= i & -i) {
        res += tr[i];
    }
    return res;
}
```

- `update(x, d)`：单点修改，给 `a[x]` 加上 `d`。
- `sum(x)`：前缀和查询，返回 `a[1..x]` 的和。
- 多测时记得清空：`std::fill(tr, tr + n + 5, 0);`

### 区间修改，单点查询

维护差分数组即可：

```cpp
update(l, v);      // 差分 [l]   +v
update(r + 1, -v); // 差分 [r+1] -v
// sum(i) 即位置 i 的最终值
```
