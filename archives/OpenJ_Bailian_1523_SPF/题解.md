- **标签**：图论、Tarjan、割点、点双连通分量

## 一句话题目

多组无向网络，找出所有**割点**（单点故障，SPF），并对每个割点输出删掉它之后网络被分成多少个连通块。

## 一句话题解

一遍 Tarjan 求割点，同时统计每个点满足 `low[v] >= dfn[u]` 的**儿子个数** `sub[u]`：非根割点删掉后有 `sub[u] + 1` 块（还要加上与父亲同属的那一块），根节点删掉后有 `sub[u]` 块。

## 题目描述

假设数据只能在直接相连的节点之间以点对点方式传输。若一个原本连通的网络中，某个节点一旦故障，会导致至少一对**仍然可用**的节点无法通信，则称该节点为单点故障（Single Point of Failure，简称 SPF）。严格来说，删掉它之后，剩余可用节点被分成的连通块数不少于 2。

- **输入**：
  - 输入包含多个网络的描述，每个网络由若干对整数构成，每行一对，表示相互连接的节点。
  - 每对整数的顺序无关紧要，`1 2` 与 `2 1` 表示同一条连接。
  - 所有节点编号在 $1$ 到 $1000$ 之间。
  - 仅包含一个 `0` 的行表示当前网络的连接列表结束。
  - 一个空的网络描述（即上一行 `0` 之后紧跟的一行 `0`）表示整个输入结束。
  - 输入文件中的空行应忽略。
- **输出**：
  - 对第 $k$ 个网络先输出一行 `Network #k`。
  - 对其中每个 SPF 节点输出一行 `  SPF node <编号> leaves <连通块数> subnets`。
  - 若该网络不存在 SPF 节点，则输出一行 `  No SPF nodes`。
  - 每个网络输出结束后跟一个空行。
- **数据范围**：$1 \le v \le 1000$。

## 解法 1：Tarjan 求割点 + 块计数

### 思路

对图做一遍 DFS，得到访问时间戳 $dfn_u$ 与回溯值 $low_u$：

$$
low_u = \min\big(\{dfn_u\} \cup \{dfn_w \mid w \text{ 是 } u \text{ 子树中某点经一条后向边到达的点}\} \cup \{low_v \mid v \text{ 是 } u \text{ 的树边儿子}\}\big)
$$

即 $low_u$ 表示 $u$ 及其子树内的点，**不经过 $u$ 的父亲**能回到的最早时间戳。

对 $u$ 的每个树边儿子 $v$（`dfn[v] == 0`，遍历时跳过父亲 `fa`）：

1. 递归进入 $v$，回溯后 `low[u] = min(low[u], low[v])`；
2. 若 `low[v] >= dfn[u]`，说明 $v$ 的子树无法绕过 $u$ 回到 $u$ 的祖先，删掉 $u$ 后**整个子树自成一个连通块**。此时 `sub[u]++`，且对 $u$ 做割点标记（根节点要求 `cnt >= 2`）。

对非树边（后向边），用 `low[u] = min(low[u], dfn[v])` 更新。

**连通块数的计算**（这是本题与「只数割点个数」的区别）：

设删掉割点 $u$。DFS 树上，每个满足 `low[v] >= dfn[u]` 的儿子 $v$ 的子树各自成为一块；剩下的部分（$u$ 的祖先侧 + 那些 `low[v] < dfn[u]` 的儿子所在的部分）依然连在一起，合成一块。因此

$$
\text{subnets}(u) = sub_u + \begin{cases} 0, & u \text{ 是 DFS 树根} \\ 1, & \text{否则} \end{cases}
$$

根节点之所以不用加 $1$，是因为它没有祖先侧；而它的每个儿子都必然满足 `low[v] >= dfn[root]`（`dfn[root]` 全局最小），所以此时 $sub_{root}$ 恰好等于儿子数。

另一种等价理解：$\text{subnets}(u)$ 就是**包含 $u$ 的点双连通分量个数**，即圆方树（block-cut tree）上 $u$ 的度数。因此也可以用「点双分量 + 弹栈」来数，但对本题只需计数，用 `sub[]` 更省事。

判断 $u$ 是不是根，可以用一个 `ans[]`（下文代码中的数组名）在 DFS 入口处记录「所在 DFS 树的根编号」：`ans[u] = root`，则 `ans[u] == u` 当且仅当 $u$ 是某棵 DFS 树的根。

### 复杂度

- 时间：每组 $O(V + E)$。
- 空间：$O(V + E)$（链式前向星）。

### 坑点

1. **把「割点个数」当成了「某个割点的连通块数」**。
   最初用 `unordered_map<int, vector<vector<int>>> vdcc` 存每个割点包含的块，输出时写成 `int(vdcc.size())` —— 这是 **map 的键数（有多少个割点）**，不是某个割点的块数。应为 `vdcc[u].size()` 或直接改用一个计数数组。

2. **多组数据之间状态没清空**。
   `vdcc` 在 `solve()` 里没有 `clear()`，键会跨网络累积，于是后面网络的答案被前面网络污染。题目原样例中 `Network #3` 的正确答案是 `2 subnets`，错误代码输出了 `3 subnets`，正是被前两组残留的键（`1`、`3`、`2`）凑成了 $3$。

3. **块数少算了「父亲那一块」**。
   用点双弹栈统计时，块是在 `low[v] >= dfn[u]` 成立、回溯到**父节点 $u$** 时被记到 `vdcc[u]` 名下，因此 `vdcc[u]` 只包含 $u$ **子树方向**的块，漏掉了 $u$ 与父亲同属的那一块。非根割点必须 $+1$。
   注意：题目原样例的 `Network #1` 恰好因「少算一块」与「`vdcc.size()` 数成 2」两个错误互相抵消，输出了正确的 `2 subnets`，**样例通过不能作为正确性判据**。

4. **`while (std::cin >> a, a)` 的逗号表达式**。
   逗号表达式只取 `a` 的值，`cin` 读失败时 `a` 保留的是**未初始化**的值，在输入末尾 EOF 处会带着垃圾值继续 `add()`，属于未定义行为，可能死循环或数组越界。应写成 `while (std::cin >> a && a)`。

5. **空间与前提**。
   链式前向星按简单图开：最多 $\binom{1000}{2} = 499500$ 条边、$999000$ 条有向边，取 `M = N * (N - 1)` 刚好够用；若输入中出现大量重复边则可能越界。此外本题题意保证网络连通，若真出现不连通数据，删除某点后的块数还需加上其它连通分量。

## 样例

### Sample 1（基本功能，题目原样例）

**输入：**
```
1 2
5 4
3 1
3 2
3 4
3 5
0

1 2
2 3
3 4
4 5
5 1
0

1 2
2 3
3 4
4 6
6 3
2 5
5 1
0

0
```

**输出：**
```
Network #1
  SPF node 3 leaves 2 subnets

Network #2
  No SPF nodes

Network #3
  SPF node 2 leaves 2 subnets
  SPF node 3 leaves 2 subnets
```

**说明：** 第 1 组是 $3$ 连接 $1,2,4,5$ 且 $4-5$ 相连的图，删掉 $3$ 得 $\{1,2\}$、$\{4,5\}$ 两块；第 2 组是纯环，无割点；第 3 组是两个三元环（$1-2-5$、$3-4-6$）经边 $2-3$ 相连，$2$ 与 $3$ 各删去后都留下 $2$ 块。

### Sample 2（边界：单边 / 链 / 星形 / 端点顺序颠倒）

**输入：**
```
1 2
0

1 2
2 3
3 4
0

1 2
1 3
1 4
1 5
0

4 1
5 4
2 1
3 1
0

0
```

**输出：**
```
Network #1
  No SPF nodes

Network #2
  SPF node 2 leaves 2 subnets
  SPF node 3 leaves 2 subnets

Network #3
  SPF node 1 leaves 4 subnets

Network #4
  SPF node 1 leaves 3 subnets
  SPF node 4 leaves 2 subnets
```

**说明：** 第 1 组只有两个点，删掉任一点都只剩一个块，故无 SPF；第 2 组链 $1-2-3-4$ 中 $2,3$ 是割点，各留下 $2$ 块；第 3 组以 $1$ 为中心的星形图，删掉 $1$ 留下 $4$ 个孤立点；第 4 组输入把每条边的两个端点顺序任意颠倒（$4\ 1$、$5\ 4$ 等），用来检验读入不依赖端点顺序，$1$ 删掉后为 $\{2\},\{3\},\{4,5\}$ 三块。
