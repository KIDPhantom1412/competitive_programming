# CF_1579D_Productive_Meeting

- **来源**：Codeforces 1579D（Codeforces Round 744, Div. 3），难度 1400
- **标签**：贪心、构造、优先队列
- **日期**：2026-11-02

## 一句话题目

$n$ 个人，第 $i$ 个人最多和他人交谈 $a_i$ 次，每次两人私聊一次，求最多能进行多少次交谈并给出一种方案。

## 一句话题解

每次取当前剩余次数最大的两个人交谈，答案的上界是 $\min\left(\left\lfloor S/2 \right\rfloor,\ S - \max a_i\right)$（$S = \sum a_i$），取两最大反复匹配恰好能达到这个上界。

## 题目描述

有 $n$ 个人参加一场会议。任意时刻，任意两个人可以退到一边单独交谈；同一对人在一次会议中可以交谈任意多次。

第 $i$ 个人有社交值 $a_i$（非负整数）：他与别人交谈恰好 $a_i$ 次后就会离场，不再与任何人交谈。$a_i = 0$ 的人会议一开始就立即离场。

若一场会议中的交谈次数达到最大可能值，则称为最有效率的会议。给定数组 $a$，求哪些人应该互相交谈，使总交谈次数最大。

**输入格式**：第一行一个整数 $t$（$1 \le t \le 1000$）。接下来 $2t$ 行描述每组数据：第一行一个整数 $n$（$2 \le n \le 2 \cdot 10^5$），第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$（$0 \le a_i \le 2 \cdot 10^5$）。保证所有测试的 $n$ 之和不超过 $2 \cdot 10^5$，所有 $a_i$ 之和也不超过 $2 \cdot 10^5$。

**输出格式**：每组数据第一行输出最大交谈次数 $k$，接下来 $k$ 行每行输出两个整数 $i$ 和 $j$（$1 \le i, j \le n$，$i \neq j$），表示这两个人交谈一次。若有多组解，输出任意一组。

## 解法 1：优先队列贪心

### 思路

记 $S = \sum_{i=1}^{n} a_i$，$M = \max_i a_i$，$k$ 表示这场会议的最大交谈次数（也就是本组数据的答案）。每次交谈需要两个不同的人各消耗一次机会，所以 $k$ 有两个上界：

- **每次交谈消耗 $2$ 个单位**，全部机会加起来只有 $S$ 个，故 $k \le \left\lfloor S/2 \right\rfloor$。
- **每次交谈至少消耗「除最大者以外的人」$1$ 个单位**。设 $p$ 是社交值为 $M$ 的那个人。一次交谈要么不涉及 $p$，要么只涉及 $p$ 一个单位的机会，因此不论哪种情况，这一次交谈都至少要用掉其他人（除 $p$ 外的任意人）的 $1$ 个单位。其他所有人加起来只有 $S - M$ 个单位，故 $k \le S - M$。

所以

$$
k \le \min\left(\left\lfloor \frac{S}{2} \right\rfloor,\ S - M\right).
$$

贪心策略就是让这个上界被取到：每次在当前剩余次数仍为正的人里取出最大的两个，让他们交谈一次，各自剩余次数减 $1$；若某人的剩余次数变成 $0$，就让他离场。重复到剩余正次数的人不足两个为止。

为什么这样最优：分两种情况说明贪心能分别取到两个上界。

- 若 $M \le S - M$（最大者不超过其余人之和）：可归纳证明，只要还有至少两个人剩余次数为正，贪心始终保持「最大剩余次数 $\le$ 其余人剩余次数之和」。于是只要剩余总次数不少于 $2$，场上就必然还有至少两个正次数的人，贪心不会停下；它一直消到剩余总次数为 $0$ 或 $1$，取得 $\lfloor S/2 \rfloor$ 次，恰好等于这个上界。
- 若 $M > S - M$（最大者超过其余人之和）：最大者的剩余次数始终大于其余人之和，因此它永远在堆顶，贪心每一步都让它和「剩下最大的另一个人」交谈，直到其他人全部耗尽，共 $S - M$ 次，也恰好等于这个上界。

两种情况分别取到两个上界中较小的那个，说明贪心取得的次数就是 $k$（最大值）。因此题目允许多种方案，本算法任意输出其中一种即可。

实现上用大根堆 `priority_queue<pair<int,int>>` 存 `(剩余次数, 编号)`，按次数排序。由于 $\sum a_i \le 2 \cdot 10^5$，堆操作总量与答案同阶，不会超时。

### 复杂度

- 时间：$O(S \log n)$，其中 $S = \sum a_i \le 2 \cdot 10^5$；每次交谈对应一次弹出两个元素、至多压入两个元素。
- 空间：$O(n + S)$，堆大小不超过 $n$，方案数组长度等于答案。

### Sample 2（边界）

只有两人时只能聊一次；只有一人有正次数时一次也聊不了；四人次数相同时检验交替匹配的对称情形。

**输入：**

```
3
2
1 1
4
5 0 0 0
4
3 3 3 3
```

**输出：**

```
1
2 1
0
6
4 3
2 1
4 3
2 1
4 3
2 1
```

**说明：** 只有一人有正次数时一次交谈也做不了，答案为 $0$；四个人各有 $3$ 次时，$S = 12$，$M = 3$，上界为 $\min(6, 9) = 6$，贪心恰好完成 $6$ 次。
