## 一句话题目

按顺序在一段墙上贴 `n` 张海报，求最后能看到几张海报。

## 一句话题解

把海报端点离散化后，用线段树做区间赋值，最后统计树上出现的不同颜色数量。

## 题目描述

Bytetown 的市民们决定在竞选墙上贴海报，规则如下：

- 每位候选人只能贴一张海报；
- 海报高度与墙相同，宽度为任意整数个字节；
- 墙被划分为长度为 1 的字节段；
- 每张海报必须完全覆盖一段连续的字节段。

墙总长为 `10,000,000` 字节。给定 `n` 张海报的左右端点 `li, ri`，按输入顺序依次贴上，后贴的海报会覆盖先贴的。问最后能看到多少张海报。

**输入格式：**

第一行一个整数 `c`，表示测试组数。  
每组第一行一个整数 `n`，表示海报数量。  
接下来 `n` 行，每行两个整数 `li ri`。

**输出格式：**

每组数据输出一行，表示能看到的不同海报数量。

**数据范围：**

- `1 ≤ c ≤ 未知`
- `1 ≤ n ≤ 10000`
- `1 ≤ li ≤ ri ≤ 10^7`

## 解法 1：线段树 + 离散化

### 思路

坐标范围到 `10^7`，直接建树会超时，因此先离散化：

1. 收集所有海报的左右端点，排序去重；
2. 对排序后相邻但不相邻的两个端点之间，插入一个代表点（如左端点 + 1），避免 `[1,2]` 与 `[4,5]` 这种中间有空隙的区间被压缩后错误相邻；
3. 用线段树维护每个压缩位置最终被哪张海报覆盖；
4. 按输入顺序依次做区间赋值；
5. 最后遍历线段树，统计出现的不同颜色数。

线段树节点只保存一个赋值标记（lazy tag）。查询时，如果当前节点有统一颜色，直接计数；否则下传标记并递归到子树。

### 复杂度

- 时间：`O(n log n)`
- 空间：`O(n)`

### 代码

见 `correct_code_01.cpp`。

### 坑点

`sum` 函数只在节点有统一颜色时返回，若递归到叶子节点但该位置没有被任何海报覆盖（标记为 `0`），会因为没有终止条件而继续访问非法子节点，导致 **Segmentation Fault（RE）**。  
修复方法：在 `sum` 中判断完统一颜色后，若 `L == R` 直接返回。

## 样例

### Sample 1（基本功能）

**输入：**

```
1
5
1 4
2 6
8 10
3 4
7 10
```

**输出：**

```
4
```

**说明：** 题目样例，最终能看到 4 张海报。

### Sample 2（坑点：叶子节点无颜色）

**输入：**

```
1
3
12 14
10 14
20 20
```

**输出：**

```
2
```

**说明：** 第一张海报被第二张完全覆盖，第三张独立可见；该用例会触发原始代码的递归越界/段错误。
