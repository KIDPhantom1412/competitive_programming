## 一句话题目

给定一棵带点权的树，从节点 1 出发最多走 K 步，求能经过的节点权值和最大是多少。

## 一句话题解

树形 DP：`f[u][j][0/1]` 表示在 $u$ 的子树内走 $j$ 步且最终回到/不回到 $u$ 的最大苹果数，按树上背包合并子树。

## 题目描述

Wshxzt 非常喜欢苹果。某天 HX 带她到一棵苹果树下，树上有 $N$ 个节点，每个节点有一定数量的苹果。她从某个节点出发，到达的节点上的苹果都可以吃掉。HX 不让她走超过 $K$ 步（每经过一条边算一步）。问她最多能吃多少个苹果。

**输入格式**

多组测试数据，直到 EOF。

每组数据：
1. 第一行两个整数 $N\ K$。
2. 第二行 $N$ 个整数，第 $i$ 个表示节点 $i$ 的苹果数。
3. 接下来 $N-1$ 行，每行两个整数 $A\ B$，表示一条边。

**数据范围**：$1 \le N \le 100,\ 0 \le K \le 200$，苹果数非负且不超过 1000。

**注意**：起点固定为节点 1。

**输出格式**：对每组数据输出一行最大苹果数。

## 解法 1：树形 DP

### 思路

设：
- `f[u][j][0]`：从 $u$ 出发，在 $u$ 的子树内恰好走 $j$ 步，**最终回到 $u$** 的最大苹果数。
- `f[u][j][1]`：从 $u$ 出发，在 $u$ 的子树内恰好走 $j$ 步，**最终不回到 $u$** 的最大苹果数。

初始化：`f[u][0][0] = W[u]`，其余为 $-\infty$。

合并子节点 $v$（设在其子树内用 $k$ 步）：
- 到 $v$ 并返回，代价 2：`f[u][j][0] = max(f[u][j][0], f[u][j-k-2][0] + f[v][k][0])`。
- 到 $v$ 不返回，之前都返回，代价 1：`f[u][j][1] = max(f[u][j][1], f[u][j-k-1][0] + max(f[v][k][0], f[v][k][1]))`。
- 到 $v$ 返回，但之前已经不返回，代价 2：`f[u][j][1] = max(f[u][j][1], f[u][j-k-2][1] + f[v][k][0])`。

$j$ 倒序、$k$ 正序，保证每个子节点只被使用一次。

最终答案：$\max_{0 \le j \le K} \max(f[1][j][0], f[1][j][1])$。

### 复杂度

- 时间：$O(N \cdot K^2)$，$100 \times 200^2 = 4 \times 10^6$
- 空间：$O(N \cdot K)$

### 代码

见 `correct_code_01.cpp`。

### 坑点

1. `f[u]` 的初始化范围是 `M * 2`（$M = 210$ 为最大步数），而不是 `N * 2`。$K$ 最大为 200，若只初始化到 $N \times 2$ 会遗漏 $j \ge 110$ 的状态，导致大 $K$ 或多组数据时残留脏值。
2. 状态 1 只能存放“不回到 $u$”的路径，不能把“访问子节点并返回 $u$”的转移也塞进状态 1。

## 样例

### Sample 1（基本功能）

**输入：**
```
2 1
0 11
1 2
3 2
0 1 2
1 2
1 3
```

**输出：**
```
11
2
```

**说明：** 第一组从 1 走 1 步到 2 吃 11；第二组从 1 出发最多 2 步，最优是 1→3 或 1→2 往返，得到 2。

---

### Sample 2（边界：大 K 多组数据）

**输入：**
```
2 200
0 100
1 2
2 200
0 50
1 2
2 200
0 1
1 2
```

**输出：**
```
100
50
1
```

**说明：** 多组数据中 $K$ 达到 200，必须保证 `f[u][j]` 对所有 $j \le K$ 都正确初始化，否则上一组数据会污染下一组。
