# 洛谷 P5658 括号树

- **来源**：洛谷 P5658 [CSP-S 2019] 括号树
- **标签**：树、DFS、栈、递推、括号匹配
- **日期**：2026-07-05

## 一句话题目

对树上根到每个节点路径形成的括号串，求其中有多少个**不同的子串**是合法括号串，并输出 $i \times k_i$ 的异或和。

## 一句话题解

DFS 遍历树，用栈维护当前路径上未匹配的左括号；当右括号与栈顶匹配时，以当前节点结尾的合法子串数等于父节点匹配位置结尾的合法子串数加 1，前缀和即为该节点答案。

## 题目描述

一个大小为 $n$ 的树，根为 1 号节点，每个节点上恰有一个括号 `(` 或 `)`。设 $s_i$ 为根到 $i$ 号节点路径上括号按顺序组成的字符串。对所有 $i$（$1\le i\le n$），求 $s_i$ 中有多少个**不同的子串**是合法括号串。设这个数量为 $k_i$，输出：

$$(1\times k_1)\ \text{xor}\ (2\times k_2)\ \text{xor}\ \cdots\ \text{xor}\ (n\times k_n)$$

**输入格式**

第一行一个整数 $n$。
第二行一个长为 $n$ 的括号串，第 $i$ 个字符表示 $i$ 号节点的括号。
第三行包含 $n-1$ 个整数，第 $i$ 个整数表示 $i+1$ 号节点的父亲编号。

**输出格式**

仅一行一个整数表示答案。

**数据范围**

$n\le 5\times 10^5$。

## 解法 1：DFS + 栈递推

### 思路

根到每个节点 $u$ 的路径串 $s_u$ 是唯一的，可以按 DFS 顺序维护。

- 用栈保存当前路径中尚未匹配的左括号下标（在树中的节点编号）。
- 遍历到节点 $u$ 时：
  - 若 $u$ 上是 `(`，入栈。
  - 若 $u$ 上是 `)` 且栈非空，弹出栈顶节点 $t$。此时以 $u$ 结尾、以 $t$ 处左括号开头形成了一个合法括号串 `(...)`。同时，若 $t$ 的父节点位置也对应一个合法串结尾，则 `fa[t]` 到 $u$ 也构成合法串，依此类推。
  - 设 $last[u]$ 表示以节点 $u$ 结尾的合法括号子串数量，则 $last[u] = last[fa[t]] + 1$。
- 设 $sum[u]$ 表示路径 $s_u$ 中合法子串总数，则 $sum[u] = sum[fa[u]] + last[u]$。
- DFS 回溯时恢复栈的现场，避免影响兄弟子树。

最终答案为 $\bigoplus_{i=1}^{n} (i \times sum[i])$。

### 复杂度

- 时间：$O(n)$，每个节点最多入栈、出栈一次。
- 空间：$O(n)$。

## 样例

### Sample 1（基本功能）

**输入：**
```
5
(()()
1 1 2 2
```

**输出：**
```
6
```

**说明：** 各节点路径分别为 `(`, `((`, `()`, `(((`, `(()`，合法子串数分别为 0,0,1,0,1，异或和为 $1\times0\ \text{xor}\ 2\times0\ \text{xor}\ 3\times1\ \text{xor}\ 4\times0\ \text{xor}\ 5\times1 = 6$。
