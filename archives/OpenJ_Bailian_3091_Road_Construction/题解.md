# OpenJ_Bailian_3091_Road_Construction

- **来源**：OpenJ_Bailian 3091（Road Construction）
- **标签**：图论、Tarjan 求桥、边双连通分量、缩点
- **日期**：2026-11-19

## 一句话题目

给定一张 $n$ 个点、$r$ 条边的连通无向图，求最少新增多少条边，使得无论哪一条边被封闭，任意两个景点之间仍然存在通路。

## 一句话题解

加边后整张图必须**不含桥**；把所有桥缩掉得到一棵树，答案为 $\left\lceil \dfrac{\text{叶子数}}{2} \right\rceil$，即 `(叶子数 + 1) / 2`。

## 题目描述

道路连接岛屿上的景点，任意两景点间最多一条道路，道路只在景点处相交（不会在交叉口相遇）。维修期间某条道路会双向封闭，游客仍需能通过其他道路在任意两点间往返。目标是设计新路，使任意一条路施工时，其余道路依然能让任意两点互相到达。求最少需要修建的道路条数。

- 输入：第一行两个整数 $n, r$；接下来 $r$ 行，每行两个整数 $v, w$，表示景点 $v$ 与 $w$ 之间有一条双向道路。保证初始图中任意两点间都能通行。
- 输出：一个整数，表示最少需要新增的道路数量。
- 数据范围：$3 \le n \le 1000$，$2 \le r \le 1000$，任意两点之间最多一条道路。

## 解法 1：Tarjan 求桥 + `low[]` 缩点统计叶子

### 思路

"任意一条路封闭后任意两点仍连通" 等价于：加边之后的图**删去任意一条边仍然连通**，即图中不能存在桥。因此问题化为：用最少的边消掉所有桥。

1. **求桥**：用 Tarjan 求 `dfn` / `low`。对 DFS 树边 $(u, v)$，若 `low[v] > dfn[u]`，则它是桥。回退边只更新一次 `low[u] = min(low[u], dfn[v])`。
2. **缩点**：在上述 `low` 定义下，同一个**边双连通分量**内的所有点 `low` 值完全相同，因此可以直接把 `low[u]` 当成分量编号，省掉并查集或二次 DFS 染色。
3. **统计缩点树的度数**：若一条边两端 `low[u] != low[v]`，它必然是桥。由于链式前向星把每条边双向存储，一条桥会被枚举两次（方向各一次），恰好给两端所在的分量各 `+1`，于是 `indegree[low[v]]` 正是该分量在缩点树上的度数。
4. **答案**：度数为 $1$ 的分量即叶子。

$$
\text{ans} = \left\lceil \frac{L}{2} \right\rceil = \left\lfloor \frac{L + 1}{2} \right\rfloor
$$

其中 $L$ 为缩点树的叶子数。

**正确性直觉**：在树上连接两个叶子，它们之间的树上路径就变成一个环，路径上所有桥同时被消掉，所以一次加边最多消掉两条叶子引出的桥，故至少需要 $\lceil L/2 \rceil$ 条；把叶子两两配对即可达到该下界。若整张图只有一个分量（$L = 0$），公式给出 $0$，无需特判。

### 复杂度

- 时间：$O(n + r)$
- 空间：$O(n + r)$

### 代码

见 `correct_code_01.cpp`。

### 坑点

1. **答案是叶子数，不是桥的条数**。最容易写的错误就是 Tarjan 过程中统计桥的边数直接输出：样例 1 有 $3$ 条桥，但答案是 $2$；链 `1-2-3` 有 $2$ 条桥，答案却是 $1$。只有在缩点树恰好是"每个内部点度数都为 $2$"的特殊结构时两量才相等，一般情况一律 WA。
2. **父边必须用边编号判断**，不能写 `if (v != fa)`。按顶点判父边时，若两点之间存在重边，走到重边会被误判成"回到父节点的反向边"而跳过，导致桥漏判。本题题面保证无重边，但用边编号判法更稳。
3. **`low[]` 缩点要求回退边只更新一次**：`else low[u] = min(low[u], dfn[v]);`，不能写成 `low[v]`，否则同一分量内 `low` 不再一致，缩点就错了。
4. **静态数组大小与编号技巧**：双向存边需要 $2r$ 的空间，取 `M = N * (N - 1)` 足够；`idx` 从 $1$ 开始且边成对编号（`2/3`、`4/5`…），才能用 `i != (fa ^ 1)` 找到反向边。

## 样例

### Sample 1（基本功能）

**输入：**
```
10 12
1 2
1 3
1 4
2 5
2 6
5 6
3 7
3 8
7 8
4 9
4 10
9 10
```

**输出：**
```
2
```

**说明：** 边双连通分量分别为 $\{1\}$、$\{2,5,6\}$、$\{3,7,8\}$、$\{4,9,10\}$，缩点后是"点 $1$ 连着三个分量"的星形树，叶子数 $L = 3$，答案 $(3+1)/2 = 2$；而桥有 $3$ 条，正是"输出桥数"会 WA 的典型样例。

---

### Sample 2（边界：已经边双连通）

**输入：**
```
3 3
1 2
2 3
1 3
```

**输出：**
```
0
```

**说明：** 三角形本身无桥，缩点树只有 $1$ 个点，$L = 0$，答案 $0$。

---

### Sample 3（坑点：链状图，桥数 $\ne$ 答案）

**输入：**
```
3 2
1 2
2 3
```

**输出：**
```
1
```

**说明：** 有 $2$ 条桥，但叶子只有 $2$ 个，加一条边 $1-3$ 即成环，答案 $1$。输出桥数的写法会得到 $2$。

---

### Sample 4（极端数据：星形树）

**输入：**
```
7 6
1 2
1 3
1 4
1 5
1 6
1 7
```

**输出：**
```
3
```

**说明：** 缩点树为 $7$ 个点的星形，叶子数 $L = 6$，答案 $(6+1)/2 = 3$，需要 $3$ 条边把 $6$ 个叶子两两接起来。
