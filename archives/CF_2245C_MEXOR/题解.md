# CF_2245C_MEXOR

- **来源**：Codeforces 2245C（Codeforces Round 1110, Div. 1 + Div. 2），难度 1400
- **标签**：位运算、构造、数学
- **日期**：2026-09-17

## 一句话题目

构造 $0 \sim n-1$ 的排列，使所有前缀的 mex 之异或等于 $k$，或判断无解。

## 一句话题解

末位前缀 mex 恒为 $n$，目标等价于前 $n-1$ 个 mex 之异或 $t = n \oplus k$；$t$ 可达当且仅当 $t < 2^L$（$L$ 为 $n-1$ 的二进制位数），按 $t = 0$、$t \le n-1$、$n \le t < 2^L$ 三种情况构造排列即可。

## 题目描述

给定正整数 $n$ 和非负整数 $k$，构造一个长为 $n$ 的排列 $p$（$0 \sim n-1$ 各出现一次）。令 $f(i) = \mathrm{mex}(p_0, \dots, p_i)$，要求 $f(0) \oplus f(1) \oplus \dots \oplus f(n-1) = k$。无解输出 "NO"；否则输出 "YES" 并给出任意一个合法排列。

**输入格式**：第一行一个整数 $t$（$1 \le t \le 10^4$）表示测试组数。每组一行两个整数 $n, k$（$1 \le n \le 2 \cdot 10^5$，$0 \le k \le 10^9$）。保证 $\sum n \le 2 \cdot 10^5$。

**输出格式**：对每组数据，若不存在这样的排列输出 "NO"；否则输出 "YES"，下一行输出 $n$ 个整数表示构造的排列。

## 解法 1：打表找规律 + 位运算构造

### 思路

暴力枚举小 $n$ 的所有排列、统计可达的 $k$ 找规律，再用位运算解释并构造：

1. **化简目标**：排列含全部 $0 \sim n-1$，故末位前缀 mex 恒为 $n$。设前 $n-1$ 个前缀 mex 之异或为 $t$，则 $k = t \oplus n$，即 **$t = n \oplus k$**。
2. **可达充要条件**：每个前缀 mex 都满足 $m_i \le n-1 < 2^L$（$L$ 为 $n-1$ 的二进制位数），而异或不会引入比操作数更高的位，故 $t < 2^L$ 是必要条件；下面的构造说明它也是充分的。
3. **构造**（每种情况的 mex 序列如所列，异或结果均为 $t \oplus n = k$）：
   - **$t = 0$**：排列 $[1..n-1, 0]$，mex 序列 $0,\dots,0, n$。
   - **$1 \le t \le n-1$**：排列 $[1..n-1] \setminus \{t\}$ 接上 $[0, t]$，mex 序列 $0,\dots,0, t, n$。
   - **$n \le t < 2^L$**：此时 $t$ 与 $n-1$ 的最高位（第 $L-1$ 位）均为 $1$，故 $v = t \oplus (n-1)$ 满足 $0 < v < n-1$。排列 $[1..n-2] \setminus \{v\}$ 接上 $[0, v, n-1]$，mex 序列 $0,\dots,0, v, n-1, n$，异或 $= v \oplus (n-1) \oplus n = t \oplus n$。
   - **$t \ge 2^L$**：无解，输出 NO。

### 复杂度

- 时间：$O(n)$ 每组，共 $O(\sum n)$
- 空间：$O(1)$

### 代码

见 `correct_code_01.cpp`。

### 坑点

**$t = 0$（即输入 $k = n$）时会重复输出 $0$**。若统一按 $[1..n-1]\setminus\{t\}, 0, t$ 的格式输出，$t = 0$ 时中间的 $0$ 与末尾的 $t$ 都是 $0$，排列出现重复元素且总长为 $n+1$，直接 WA。修复：$t = 0$ 时跳过中间那个 $0$，排列为 $[1..n-1, 0]$。

## 样例

### Sample 1（基本功能）

题目样例。

**输入：**

```
6
1 0
1 1
3 0
4 8
5 1
9 12
```

**输出：**

```
NO
YES
0
YES
0 1 2
NO
YES
3 0 2 1 4
YES
1 4 0 8 2 3 7 5 6
```

**说明**：第 4 组 $n=4, k=8$ 时 $t = 4 \oplus 8 = 12 \ge 2^2$，无解；其余组按三种情况构造合法排列（答案不唯一）。

### Sample 2（坑点：$k = n$ 时 $t = 0$）

**输入：**

```
3
2 2
3 3
5 5
```

**输出：**

```
YES
1 0
YES
1 2 0
YES
1 2 3 4 0
```

**说明**：$k = n$ 时 $t = 0$，排列取 $[1..n-1, 0]$：前缀 mex 全为 $0$、末位为 $n$，异或 $= n = k$。此用例曾触发重复输出 $0$ 的 bug（如 `1 2 0 0`）。
