# P1273 [CHCI 2002 Final Exam #2] 有线电视网

- **来源**：洛谷
- **标签**：树形 DP、DFS 序、背包
- **日期**：2026-07-22

## 一句话题目

一棵树，边有传输费用，叶子（用户）有愿付金额，选择若干用户使总支付 ≥ 总传输费用，求最多能选多少用户。

## 一句话题解

后序 DFS 序上做树形背包：`f[i][j]` 表示后序前 i 个结点中选 j 个用户的最大净收益，内部结点可整体跳过子树，最终找最大的 j 使 `f[cnt][j] >= 0`。

## 题目描述

收费有线电视网为树状结构，根结点 1 为转播现场，叶子为用户终端。每条边有传输费用，每个用户有愿付金额。总费用为所选用户到根路径上所有边的费用之和。求在不亏本（用户总支付 ≥ 总传输费用）的前提下，观看转播的最大用户数。

输入：第一行 N、M（$2 \le N \le 3000$，$1 \le M \le N-1$），用户编号为 $N-M+1$ 到 $N$。接下来 $N-M$ 行，第 i 行为转播站 i 的数据：`K A1 C1 A2 C2 ...`，表示下接 K 个结点及对应传输费用。最后一行为 M 个用户愿付金额。费用均不超过 10。

输出：一个整数，最大用户数。

## 解法 1：后序 DFS 序树形背包

### 思路

把每个结点的"代价/收益"合并到点权 `W[u]` 上：边 `(fa,u)` 的费用计入 `W[u] = -cost`，叶子再加上愿付金额，即 `W[leaf] = pay - cost`。这样问题变为：选若干叶子，使其到根路径上所有点的点权之和 ≥ 0，最大化叶子数。

DFS 后序遍历得序列 `pos[1..cnt]`，性质：u 的子树占据 `pos` 中连续一段并以 u 结尾。定义 `f[i][j]` = 后序前 i 个结点中恰好选 j 个用户的最大净收益：

- 初始化：`f[i][0] = 0`，其余 `-INF`（**注意下标要覆盖到 m**）。
- u = pos[i] 为内部结点：
  - 整体跳过 u 的子树：`f[i][j] = f[i - size[u]][j]`
  - 保留 u（子树部分任意）：`f[i][j] = f[i-1][j] + W[u]`
- u 为叶子（选它消耗 1 个用户名额）：
  - `f[i][j] = max(f[i-1][j-1] + W[u], f[i-1][j])`

根在后序最后，答案为最大的 j 使 `f[cnt][j] >= 0`。

### 复杂度

- 时间：O(N·M)
- 空间：O(N·M)

见 `correct_code_01.cpp`。

### 坑点

原始错误代码见 `main.cpp.orig`（已删除，以下凭调试记录）：

1. **初始化区间漏掉下标 m**：`std::fill(f[i] + 1, f[i] + m, -INF)` 半开区间不含 `f[i][m]`，全局数组零初始化使"选满 m 个用户且收益 0"被误判合法，导致样例 1 输出 3（期望 2）、样例 3 输出 6（期望 5）。修复：`f[i] + m + 1`。
2. **答案读错行**：`f[pos[1]][j]` 中 `pos[1]` 是后序首结点的**编号**（某个叶子），并非 DP 最后一行；且按编号当行下标本就是误解。根在后序最后，应读 `f[cnt][j]`。

## 样例

### Sample 1（基本功能 / 坑点：f[i][m] 未初始化会多算）

**输入：**
```
5 3
2 2 2 5 3
2 3 2 4 3
3 4 2
```

**输出：**
```
2
```

**说明：** 全选 3 个用户费用 10 > 支付 9 亏本，最多选 2 个；初始化 bug 会错输出 3。

---

### Sample 2（边界：恰好不亏本可全选）

**输入：**
```
5 3
2 2 2 5 3
2 3 2 4 3
4 4 2
```

**输出：**
```
3
```

**说明：** 用户 3 愿付 4，总支付 10 = 总费用 10，恰好不亏本，可全选。

---

### Sample 3（极端数据 / 坑点：答案行取错会漏子树）

**输入：**
```
9 6
3 2 2 3 2 9 3
2 4 2 5 2
3 6 2 7 2 8 2
4 3 3 3 1 1
```

**输出：**
```
5
```

**说明：** 多分枝树，6 个用户最多选 5 个；`f[pos[1]]` 只统计部分子树会得到错误答案。
