# HDU_4578_Transformation

- **来源**：HDU 4578
- **标签**：线段树、懒标记
- **日期**：2026-08-11

## 一句话题目

维护一个长度为 n 的序列，支持区间加、区间乘、区间赋值、区间 p 次幂和查询（p = 1, 2, 3），答案对 10007 取模。

## 一句话题解

用线段树同时维护区间的 `sum(a_i)`、`sum(a_i^2)`、`sum(a_i^3)`，配合 `set / mul / add` 三层懒标记；查询前必须把当前节点的懒标记下放到子树。

## 题目描述

初始有 n 个整数，值均为 0。共有 m 个操作：

- `1 x y c`：对 `[x, y]` 中每个数加 c。
- `2 x y c`：对 `[x, y]` 中每个数乘 c。
- `3 x y c`：把 `[x, y]` 中每个数赋值为 c。
- `4 x y p`：求 `sum_{k=x}^{y} a_k^p`（p = 1, 2, 3）。

对每个操作 4 输出结果，结果对 10007 取模。

数据范围：最多 10 组测试，每组 `1 <= n, m <= 100,000`，`1 <= c <= 10,000`，`1 <= p <= 3`。

## 解法 1：线段树 + 三层懒标记

### 思路

对每个线段树节点维护：

- `v1 = sum(a_i)`
- `v2 = sum(a_i^2)`
- `v3 = sum(a_i^3)`

懒标记用三元组 `(set, mul, add)` 表示：先赋值 `set`（若 set ≠ 0），再乘 `mul`，最后加 `add`。三种操作的节点更新公式可由二项式/立方展开得到。

`pushdown` 顺序固定为 `set -> mul -> add`。

### 复杂度

- 时间：单次操作 `O(log n)`，每组数据 `O(m log n)`。
- 空间：`O(n)`。

### 代码

见 `correct_code_01.cpp`。

### 坑点

1. **查询必须 `pushdown`**。`query` 在区间部分覆盖时，进入子树前必须先把当前节点的懒标记下放；否则子节点仍是旧值，导致 WA。
2. **set 标记的哨兵值**。代码用 `if (tr[u].set)` 判断是否存在赋值标记，因此默认题目保证 `c >= 1`，即 set 不会为 0。若允许赋值为 0，需要额外增加一个布尔标记来区分“无 set 标记”和“set 值为 0”。
3. **懒标记组合顺序**。`set` 会覆盖之前的 `mul/add`；`mul` 会同时缩放已有的 `add`；`add` 直接叠加。

## 样例

### Sample 1（基本功能）

**输入：**

```
5 5
3 3 5 7
1 2 4 4
4 1 5 2
2 2 5 8
4 3 5 3
0 0
```

**输出：**

```
307
7489
```

**说明：** 题目官方样例，覆盖 set / add / mul / query 的基本组合。

---

### Sample 2（坑点：查询前必须 pushdown）

**输入：**

```
5 3
3 1 4 8331
1 2 5 6071
4 1 4 1
0 0
```

**输出：**

```
1502
```

**说明：** 先对 `[1,4]` 赋值，再对 `[2,5]` 加法，最后查 `[1,4]`；会触发父节点 `[4,5]` 上只挂 `add` 标记而子节点 `[4,4]` 未更新的情况，必须 `pushdown` 才能得到正确结果。
