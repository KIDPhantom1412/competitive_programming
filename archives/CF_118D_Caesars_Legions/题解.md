# CF_118D_Caesars_Legions

- **来源**：Codeforces 118D（Codeforces Beta Round 89 (Div. 2)）
- **标签**：动态规划、计数
- **日期**：2026-11-06

## 一句话题目

有 $n_1$ 个步兵和 $n_2$ 个骑兵，要求任意连续段中步兵不超过 $k_1$ 个、骑兵不超过 $k_2$ 个，求合法的排列数对 $10^8$ 取模。

## 一句话题解

记忆化搜索，状态记录剩余步兵数、剩余骑兵数和末尾连续同兵种个数，按"末尾是否与将要放置的兵种相同"分情况转移，状态只保留必要的四个维度。

按「整块」而不是「单个士兵」转移：一次枚举一整段同兵种的块走完，连续段约束在枚举块长时即被保证，于是连"当前连续长度"也不必记录，状态进一步降为 $(剩余步兵数,\ 剩余骑兵数,\ 末尾块兵种)$ 三维。

## 题目描述

罗马将军凯撒喜欢把士兵排成一列。军队共有 $n_1$ 个步兵和 $n_2$ 个骑兵。若某一排列中没有任何连续超过 $k_1$ 个的步兵，也没有任何连续超过 $k_2$ 个的骑兵，则称该排列是"美观"的。求美观排列的数量。

所有士兵都必须被使用；同兵种的士兵之间不可区分。

**输入格式**：一行四个整数 $n_1, n_2, k_1, k_2$（$1 \le n_1, n_2 \le 100$，$1 \le k_1, k_2 \le 10$）。

**输出格式**：一行一个整数，表示美观排列数对 $10^8$ 取模的结果。

## 解法 1：记忆化搜索（计数 DP）

### 思路

因为同兵种不可区分，一个排列只由"每个位置放步兵还是骑兵"决定，可以用计数 DP 统计方案数。

状态设为 $\mathrm{dfs}(l_1, l_2, j, k)$：

- $l_1, l_2$：还剩多少个步兵 / 骑兵；
- $j$：当前末尾连续步兵的个数（若末尾是骑兵则为 $0$）；
- $k$：当前末尾连续骑兵的个数（若末尾是步兵则为 $0$）。

由于每次只在末尾追加一个兵种，$j$ 与 $k$ 至多一个非零，所以 $(j,k)$ 的合法组合数是 $O(k_1 + k_2)$ 而非 $O(k_1 k_2)$。

转移时考虑在末尾放哪一种兵：

- **放步兵**（需 $l_1 > 0$）：要么当前末尾就是步兵（$k = 0$）且延续后不超过 $k_1$，即 $j + 1 \le k_1$；要么末尾不是步兵（$j = 0$），此时新开一段长度为 $1$，只要 $k \le k_2$（恒成立）即可。
- **放骑兵**（需 $l_2 > 0$）：与上面对称。

终止条件为 $l_1 = l_2 = 0$，返回 $1$。

所有加法对 $10^8$ 取模。

### 复杂度

- 时间：$O(n_1 n_2 (k_1 + k_2))$（只遍历可达状态；$j$、$k$ 互斥，二者组合数为 $O(k_1 + k_2)$；另有对整块数组 `memset` 的 $O(n_1 n_2 k_1 k_2)$ 一次性初始化，$k \le 10$ 下为常数级）
- 空间：$O(n_1 n_2 k_1 k_2)$（按数组 `memo[j][k][l1][l2]` 的实际规模计，$j$、$k$ 各占一维；可达状态实际上只有 $O(n_1 n_2 (k_1 + k_2))$，把 $(j,k)$ 合并成一维即可达到该上界）

### 代码

见 `correct_code_01.cpp`。

### 坑点

- 最初把"已放置总数" $i$ 也作为记忆化维度，数组开成 $210 \times 15 \times 15 \times 110 \times 110$，约 $2.13\ \text{GiB}$，直接 MLE。实际上 $i = (n_1 - l_1) + (n_2 - l_2)$ 完全由 $l_1, l_2$ 决定，是冗余维度；去掉后空间降到约 $10.9\ \text{MB}$。
- 去掉 $i$ 不改变任何状态的含义，逐字对应原转移即可，正确性不受影响（与原实现及暴力枚举对拍一致）。
- 取模时两个加数都 $< 10^8$，和 $< 2 \times 10^8$，不会溢出 `int`。

## 解法 2：按「块」转移的记忆化搜索

### 思路

解法 1 一次放一个兵，为了判断"还能不能继续放同兵种"必须记录末尾连续长度。换一种状态表示即可去掉这个维度：**一次放同兵种的一整块**。

记 $z(a,b,t)$ 为还剩 $a$ 个步兵、$b$ 个骑兵，且最后放置的一整块是 $t$ 兵种（$0$ 步兵、$1$ 骑兵）的方案数。由于一整块内部全是同兵种，只要枚举块长 $l \le k$，连续段约束就自动满足：

$$
z(a,b,0) = \sum_{l=1}^{\min(k_1,a)} z(a-l,b,1), \qquad
z(a,b,1) = \sum_{l=1}^{\min(k_2,b)} z(a,b-l,0)
$$

含义是：最后一块是步兵（长度 $l$），它前面必然是骑兵块，故从 $z(a-l,b,1)$ 转移；骑兵对称。边界 $z(0,0,t)=1$（空排列可接任意块）。答案为 $z(n_1,n_2,0)+z(n_1,n_2,1)$，两种末尾块互斥且覆盖所有合法排列，不重不漏。

> 等价理解：每个合法排列唯一分解为若干「最长同兵种块」，$t$ 记录末尾那一块的兵种。

### 复杂度

- 时间：$O(n_1 n_2 (k_1 + k_2))$（每个状态枚举块长）
- 空间：$O(n_1 n_2)$（末尾块只有 $2$ 种类型，不再记录连续长度）

### 代码

见 `correct_code_02.cpp`。

### 坑点

- 状态数从 $O(n_1 n_2 (k_1 + k_2))$ 降到 $O(n_1 n_2)$，数组只需 `110*110*2`，约 $96\ \text{KB}$。
- 枚举块长时上界要取 $\min(k, \text{剩余数})$，否则会递归到负数下标。
- 答案两项各 $< 10^8$，相加仍 $< 2 \times 10^8$，`int` 不溢出，最后再取模一次即可。

## 样例

### Sample 1（基本功能）

**输入：**

```
2 1 1 10
```

**输出：**

```
1
```

**说明：** 只有 `121` 一种排列（步兵不能相邻，因此两个步兵必须被骑兵隔开）。

---

### Sample 2（基本功能）

**输入：**

```
2 3 1 2
```

**输出：**

```
5
```

**说明：** 合法排列为 `12122`、`12212`、`21212`、`21221`、`22121`。

---

### Sample 3（边界：无解）

**输入：**

```
2 4 1 1
```

**输出：**

```
0
```

**说明：** 步兵与骑兵都不能相邻，交替排列最多只能放下 $2$ 个同兵种，无法容纳 $2$ 个步兵和 $4$ 个骑兵。
