# 洛谷 P1040 加分二叉树

- **来源**：洛谷 P1040 / NOIP 2003 提高组
- **标签**：区间 DP、记忆化搜索、二叉树
- **日期**：2026-06-27

## 一句话题目

给定中序遍历为 `1,2,…,n` 的二叉树每个节点的分数，求加分最高的二叉树的最大加分及其前序遍历。

## 一句话题解

区间 DP：枚举每个区间 `[l,r]` 的根节点，记忆化搜索求左右子树最大加分，同时记录根表用于输出前序遍历。

## 题目描述

设一个 `n` 个节点的二叉树 `tree` 的中序遍历为 `(1,2,3,…,n)`，其中数字 `1,2,3,…,n` 为节点编号。每个节点都有一个分数（均为正整数），记第 `i` 个节点的分数为 `d_i`，`tree` 及它的每个子树都有一个加分，任一棵子树 `subtree`（也包含 `tree` 本身）的加分计算方法如下：

> `subtree` 的左子树的加分 × `subtree` 的右子树的加分 ＋ `subtree` 的根的分数。

若某个子树为空，规定其加分为 1，叶子的加分就是叶节点本身的分数。不考虑它的空子树。

试求一棵符合中序遍历为 `(1,2,3,…,n)` 且加分最高的二叉树 `tree`。要求输出：

1. `tree` 的最高加分
2. `tree` 的前序遍历

### 输入格式

- 第 1 行：一个整数 `n`，为节点个数。
- 第 2 行：`n` 个用空格隔开的整数，为每个节点的分数。

### 输出格式

- 第 1 行：一个整数，为最高加分。
- 第 2 行：`n` 个用空格隔开的整数，为该树的前序遍历。

### 数据范围

- 节点个数 `n < 30`
- 每个节点的分数 `< 100`
- 最高加分结果不会超过 `4,000,000,000`

## 解法 1：区间 DP + 记忆化搜索

### 思路

因为中序遍历固定为 `1..n`，所以任意子树对应一个连续区间 `[l,r]`。设 `f[l][r]` 表示中序遍历为 `l..r` 的子树能获得的最大加分，`root[l][r]` 记录取得最大加分时该子树的根节点编号。

转移时枚举根节点 `i ∈ [l,r]`：

```
f[l][r] = max{ f[l][i-1] * f[i+1][r] + d[i] }
```

其中空子树的加分规定为 1。初始时 `f[i][i] = d[i]`，`root[i][i] = i`。

由于同一个区间会被多次访问，使用记忆化搜索（`dfs(l,r)`）避免重复计算。

求出最大加分后，再根据 `root` 表递归输出前序遍历：先输出根，再递归左子树 `[l, root-1]`，最后递归右子树 `[root+1, r]`。

### 复杂度

- 时间：`O(n³)`（共 `O(n²)` 个区间，每个区间枚举 `O(n)` 个根）
- 空间：`O(n²)`（`f` 和 `root` 两个二维数组）

### 坑点

1. **加分公式误用加法**：题目规定加分规则是「左子树加分 × 右子树加分 + 根的分数」，初学者容易写成 `lt + d[i] + rt` 的加法形式，导致结果错误。
2. **空子树加分应为 1**：当某个子树为空时，其加分为 1 而不是 0。在递归实现中可以通过 `if (l > r) return 1;` 来处理，或者在调用前将左右初值设为 1。
3. **前序遍历输出**：要根据 `root` 表递归输出，不要直接按中序输出。
