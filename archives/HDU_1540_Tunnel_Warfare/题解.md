## 一句话题目

一条线上 n 个村庄，支持破坏一个村庄、修复最近被破坏的村庄、查询某个村庄所在连续存活段的长度。

## 一句话题解

用线段树维护每个区间最左/最右连续存活长度，区间合并得到查询点所在最长连续段；用栈记录破坏历史实现 R 操作。

## 题目描述

n 个村庄排成一排，编号 1..n，初始全部连通。共有 m 个操作：

- `D x`：摧毁第 x 个村庄。
- `Q x`：查询第 x 个村庄能到达的村庄数量（包括自己），即所在连续存活段长度。
- `R`：修复最近一次被摧毁的村庄。

数据范围：n, m ≤ 50000。多组输入直到 EOF。

**输入格式**：第一行两个整数 n 和 m；接下来 m 行，每行一个操作。

**输出格式**：对每个 Q 操作输出一行答案。

## 解法 1：线段树（区间最大前缀/后缀连续长度）

### 思路

把每个村庄看成 1（存活）或 0（被摧毁）。Q x 的答案就是包含位置 x 的最长连续 1 段的长度。

线段树每个节点维护：

- `pre`：区间左端点开始的最长连续 1 长度。
- `suf`：区间右端点结束的最长连续 1 长度。

合并左右子节点 `[L,mid]` 和 `[mid+1,R]` 时：

- `pre`：若左子树全为 1，则 `pre = (mid-L+1) + 右.pre`；否则为 `左.pre`。
- `suf`：若右子树全为 1，则 `suf = (R-mid) + 左.suf`；否则为 `右.suf`。

查询位置 p 所在连续段长度时，从根往下走。设当前区间 `[L,R]`，中点 `mid`：

- 若 `p ≤ mid`：
  - 若左子树的右后缀能覆盖到 p（即 `mid - 左.suf < p`），说明 p 位于跨越左右子树的段中，答案为 `左.suf + 右.pre`。
  - 否则递归查询左子树。
- 若 `p > mid`：对称处理。

单点修改把对应叶子设为 0（摧毁）或 1（修复）。`R` 操作使用栈记录每次 `D` 的位置，出栈后单点修复即可。

### 复杂度

- 时间：O((n + m) log n)
- 空间：O(n)

## 样例

### Sample 1（基本功能）

**输入：**

```
7 9
D 3
D 6
D 5
Q 4
Q 5
R
Q 4
R
Q 4
```

**输出：**

```
1
0
2
4
```

**说明：** 摧毁 3、6、5 后，村庄 4 孤立成段长度为 1；村庄 5 被摧毁输出 0；`R` 修复 5 后 4-5 连通长度为 2；再 `R` 修复 6 后 4-6 连通长度为 4。

---

### Sample 2（边界：单个村庄）

**输入：**

```
1 3
Q 1
D 1
Q 1
```

**输出：**

```
1
0
```

**说明：** 单点情况下，摧毁前后分别输出 1 与 0。
