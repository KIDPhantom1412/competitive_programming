## 一句话题目

维护一个 n×m 的矩阵，支持矩形区域整体加一个值、查询矩形区域元素和。

## 一句话题解

二维差分 + 树状数组：矩形加转化为差分数组 4 个角点更新，前缀和展开后需要维护 `D`、`i·D`、`j·D`、`i·j·D` 四个量，各用一个二维树状数组。

## 题目描述

有一个初始全 0 的 n×m 矩阵，支持两种操作：

- `L a b c d delta` —— 将 (a,b),(c,d) 为顶点的矩形区域内所有数字加上 delta。
- `k a b c d` —— 求 (a,b),(c,d) 为顶点的矩形区域内所有数字的和（k 为小写）。

输入第一行为 `X n m`。对每个 `k` 操作输出一行答案。

数据范围：1 ≤ n, m ≤ 2048，-500 ≤ delta ≤ 500，操作数不超过 2×10⁵。保证最终结果不超过 32 位带符号整数范围，但**运算过程可能超过**（需开 long long）。

## 解法 1：二维树状数组（维护差分的四个矩）

### 思路

设 D 为矩阵 A 的二维差分数组，即 `A[i][j] = Σ_{p≤i, q≤j} D[p][q]`。矩形加 (a,b)-(c,d) 等价于对 D 做 4 个单点更新：

```
D[a][b] += delta, D[a][d+1] -= delta, D[c+1][b] -= delta, D[c+1][d+1] += delta
```

A 的二维前缀和展开：

```
S(x,y) = Σ_{i≤x, j≤y} (x-i+1)(y-j+1) · D[i][j]
       = (x+1)(y+1)·ΣD - (y+1)·Σ(i·D) - (x+1)·Σ(j·D) + Σ(i·j·D)
```

因此用 4 个二维树状数组分别维护 `D`、`i·D`、`j·D`、`i·j·D` 的前缀和，每次矩形加对 4 个树状数组各做 4 次单点更新，矩形求和用前缀和容斥。每次操作 4×4 = 16 次树状数组更新/查询，单次 O(log n · log m)。

### 复杂度

- 时间：O(q · log n · log m)
- 空间：O(n · m)

### 代码

见 `correct_code_01.cpp`。

### 坑点

- **前缀和公式系数**：`(y+1)`、`(x+1)` 是查询点坐标，与矩阵大小 n、m 无关。调试时曾误写成 `(m+1)`、`(n+1)`，导致样例输出 48 而非 12。
- **符号一致性**：若 `i·D`、`j·D` 两个树状数组在更新时存的是标准差分更新的相反数（首项为 `-a*delta`、`-b*delta`），则求和公式中对应两项符号要取 `+`。更新与求和的符号约定必须一致。
- **溢出**：题目保证最终结果在 int 范围内，但运算过程可能超出，所有树状数组与求和均需使用 long long。

## 样例

### Sample 1（基本功能）

**输入：**

```
X 4 4
L 1 1 3 3 2
L 2 2 4 4 1
k 2 2 3 3
```

**输出：**

```
12
```

**说明：** 两次矩形加后，(2,2)-(3,3) 四个格子均为 3，和为 12。

---

### Sample 2（坑点：前缀和公式系数）

**输入：**

```
X 3 3
L 1 1 2 2 3
k 1 1 3 3
k 2 2 3 3
```

**输出：**

```
12
3
```

**说明：** 查询范围超出实际被修改的矩形，前缀和系数若误用 n、m 而非查询点坐标，此样例立即出错。
