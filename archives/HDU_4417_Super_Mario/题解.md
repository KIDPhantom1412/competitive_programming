# HDU 4417 Super Mario

- **来源**：HDU 4417
- **标签**：主席树（可持久化线段树）、离散化、区间统计
- **日期**：2026-08-24

## 一句话题目

路上 `n` 个位置各有高度 `h[i]` 的砖块，每次询问区间 `[L, R]` 内有多少块砖的高度不超过 `H`。

## 一句话题解

离散化砖块高度后按值域建主席树：`root[i]` 表示前 `i` 块砖对应的值域线段树，询问时两棵前缀树相减并在 `[1, find(H)]` 上求和。

## 题目描述

Mario 要救公主。把通往 boss 城堡的路看作一条长度为 `n` 的线，每个整数点 `i` 上有一块高度为 `h[i]` 的砖。问：如果 Mario 最大跳跃高度为 `H`，他在区间 `[L, R]` 内能打到多少块砖（即高度 `≤ H` 的砖块数）。

**输入：**

- 第一行一个整数 `T`，测试数据组数。
- 每组数据第一行两个整数 `n, m`（`1 <= n <= 10^5`，`1 <= m <= 10^5`），`n` 为路长，`m` 为询问数。
- 下一行 `n` 个整数，每块砖的高度，范围 `[0, 10^9]`。
- 接下来 `m` 行，每行三个整数 `L, R, H`（`0 <= L <= R < n`，`0 <= H <= 10^9`）。

**输出：**

- 每组数据先输出 `Case X:`（`X` 从 1 开始），随后 `m` 行，第 `i` 行为第 `i` 次询问能打到的砖块数。

**限制：** Time Limit 2000/1000 MS，Memory Limit 32768/32768 K。

## 解法 1：主席树（可持久化线段树）

### 思路

经典的「区间 <= H 计数」问题，与区间第 k 小（洛谷 P3834）同型：

1. 把所有 `h[i]` 离散化到值域下标 `1..S`（`S` 为去重后的元素个数，`find(x)` 用 `upper_bound` 返回 `<= x` 的元素个数）。
2. 以值域建可持久化线段树，依次插入 `h[1..n]` 得到 `n+1` 个版本 `root[0..n]`，每个节点记录子树内元素个数 `sum`。
3. 每次询问 `[L, R]`、`H`：在 `root[R+1]` 与 `root[L]` 上做差，查询值域区间 `[1, find(H)]` 的 `sum` 之差，即为区间内高度 `<= H` 的砖块数。

### 复杂度

- 时间：O((n + m) log n)
- 空间：O(n log n)

### 代码

见 `correct_code_01.cpp`。

### 坑点

1. **节点池大小（MLE/RE 主因）**：主席树每次 `update` 新建一条根到叶的路径。值域大小 `S = 10^5` 时叶子深度为 16 或 17（深度 17 的叶子有 68928 个），单次插入最多新建 18 个节点，`n = 10^5` 最坏共需 `1 + 18 × 10^5 = 1,800,001` 个节点。开 `N * 4`（甚至 `N * 17 = 1,700,085`，随机数据期望也要约 177 万个）都会越界写，OJ 上表现为 MLE/RE。节点数必须开到 `N * 20`（2×10^6 节点 × 12B ≈ 23MB，小于 32MB 限制）。

2. **空区间查询无限递归**：当 `H` 小于所有砖块高度时 `find(H) = 0`，查询值域区间变为 `[1, 0]`（空区间）。递归到叶子 `L == R` 时 `mid == L`，`l <= mid` 恒成立，导致无限递归爆栈。需在 `querySum` 开头加守卫 `if (l > r) return 0;`（或在调用处特判 `find(H) == 0` 直接输出 0）。题目样例中 `H = 0` 恰好存在于离散化数组，无法暴露此 bug。

### Sample 2（坑点：H 小于所有砖块高度，空区间查询）

**输入：**

```
1
3 3
2 868616383 2
2 2 4
1 2 923680070
2 2 0
```

**输出：**

```
Case 1:
1
2
0
```

**说明：** 第三次询问 `H = 0` 小于所有砖块高度，`find(0) = 0`，查询区间为 `[1, 0]`；若 `querySum` 没有空区间守卫会无限递归爆栈（RE）。此样例中 `0` 不在离散化数组里，能稳定触发该 bug。
