## 一句话题目

统计二进制串中，能通过「相邻相同字符替换成相反字符」反复缩短到长度 1 的非空子串个数。

## 一句话题解

操作保持权值（$0 \to 2$，$1 \to 1$）模 3 不变；优美子串恰为权和 $\not\equiv 0$ 且非严格交替的子串。用前缀模 3 计数第一类，再按交替后缀长 $y$ 减去 $(y-1)/2$ 去掉奇数长交替串。

## 题目描述

二进制串 $t$ 称为**美丽**的，当且仅当可以通过任意次（可为零）如下操作，将其缩短为长度恰好为 1 的串：

- 选两个**相同**的相邻字符，删掉它们，并在原位置插入一个相反字符（`00` $\to$ `1`，`11` $\to$ `0`）。

例如 `10001` $\to$ `1101` $\to$ `001` $\to$ `11` $\to$ `0`，故美丽；`111` $\to$ `01` 后无法再操作，故不美丽。长度为 1 的串无需操作，一定美丽。

给定二进制串 $s$，求 $s$ 的非空美丽**子串**个数。

**输入格式**：第一行整数 $t$（$1 \le t \le 10^4$）。每组两行：整数 $n$（$1 \le n \le 10^6$）和长度为 $n$ 的二进制串 $s$。保证 $\sum n \le 10^6$。

**输出格式**：对每组输出一个整数，即美丽子串个数。

## 解法 1：权和模 3 + 交替后缀计数

### 思路

令 $0$ 的权为 $2$、$1$ 的权为 $1$（模 3 下与 $0 \to -1$、$1 \to +1$ 等价）。则：

- `00` $\to$ `1`：$2+2 \equiv 1$
- `11` $\to$ `0`：$1+1 \equiv 2$

操作保持整段权和模 3 不变，最终那个字符的权即原子串权和。长度为 1 时权和必为 $1$ 或 $2$，故 **权和 $\equiv 0 \pmod 3$ 的串一定不美丽**（长度至少为 2，且无法变成单个字符）。

反过来，权和 $\not\equiv 0$ 仍可能不美丽：严格交替串（`0101…` / `1010…`）没有任何相邻相同对，无法操作。其中：

- 偶数长交替：每对 `01`/`10` 权和 $\equiv 0$，整段 $\equiv 0$，已被上一条件排除；
- 奇数长 $\ge 3$ 的交替：权和 $\not\equiv 0$，需要额外减掉。

因此：优美子串 =「权和 $\not\equiv 0$」减去「长度 $\ge 3$ 的奇数长严格交替子串」。

从左到右扫，维护前缀权和 $x$ 以及每种余数出现次数 `cnt[]`（含空前缀）。以 $i$ 结尾、权和 $\not\equiv 0$ 的子串数为「余数 $\ne x$ 的前缀个数」。同时维护以 $i$ 结尾的最长严格交替后缀长度 $y$（相邻相同则 $y \leftarrow 1$，否则 $y \leftarrow y+1$）。这些交替后缀中，长度为 $3,5,\dots,\le y$ 的恰好有 $\lfloor (y-1)/2 \rfloor$ 个，全部不美丽，从答案里减去。

注意 **$y$ 为偶数时仍要减**：长度为 $y$ 的那一段本身权和 $\equiv 0$，第一段不会计入；但以 $i$ 结尾的更短奇数交替后缀（如 $y=4$ 时长度为 3 的那段）已经被第一段加进去了。

### 复杂度

- 时间：$O(n)$ 每组，共 $O(\sum n)$
- 空间：$O(n)$（存字符串；计数数组 $O(1)$）

### 代码

见 `correct_code_01.cpp`。

### 坑点

**$y$ 为偶数时不能跳过减法。** 误以为偶数长交替权和已是 $0$、第一段不会计数，于是写成 `if (y % 2) res -= (y-1)/2`。实际上 $(y-1)/2$ 统计的是**以当前位置结尾的所有奇数长交替后缀**，与 $y$ 本身奇偶无关。例如 `0101` 扫到末位时 $y=4$，长度为 4 的 `0101` 不会计入，但长度为 3 的后缀 `101` 已被计入且不美丽，必须减 1。

错误代码：

```cpp
y = S[i] == S[i - 1] ? 1 : y + 1;
if (y > 1 && y % 2) {
    res -= (y - 1) / 2;
}
```

修复：每个位置都执行 `res -= (y - 1) / 2`（$y=1,2$ 时该项为 0）。

### Sample 2（坑点：$y$ 为偶数时漏减奇数交替后缀）

**输入：**

```
2
4
0101
9
010110110
```

**输出：**

```

30
```

**说明**：`0101` 只有 4 个长度为 1 的子串美丽。扫到末位 $y=4$ 时，若因 $y$ 为偶数而不减，会把后缀 `101` 算进去，答案变成 5。第二组同理，漏减后会得到 31。
