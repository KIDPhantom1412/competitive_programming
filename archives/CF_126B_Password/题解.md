# CF_126B_Password

- **来源**：Codeforces 126B（Codeforces Beta Round 93 (Div. 1 Only)）
- **标签**：字符串、KMP、前缀函数
- **日期**：2026-10-23

## 一句话题目

给定小写字母串 $s$，求最长的子串 $t$，使得 $t$ 同时是 $s$ 的前缀和后缀，且在 $s$ 的中间（出现位置既非开头也非结尾）出现过；若不存在则输出 `Just a legend`。

## 一句话题解

用 KMP 前缀函数求出 $s$ 的最长 border $p$，在 $s$ 的中间跑 KMP 匹配 $p$，得到其前缀在中间出现的最大长度 $\mathit{innerLen}$；答案即 border 链上最长的不超过 $\mathit{innerLen}$ 的 border，不存在则输出 `Just a legend`。

## 题目描述

Asterix、Obelix 和临时伙伴 Prefix、Suffix 找到了和谐神庙，但大门紧锁。他们在门下的岩石上发现了刻着的字符串 $s$。Asterix 猜密码是 $s$ 的某个子串 $t$；Prefix 认为 $t$ 应该是 $s$ 的开头，Suffix 认为 $t$ 应该是 $s$ 的结尾，Obelix 认为 $t$ 应该出现在 $s$ 的中间（既不是开头也不是结尾）。Asterix 要选出满足所有人要求的最长子串 $t$。

求这个 $t$；若不存在，输出 `Just a legend`（不含引号）。

**输入格式**：一行一个字符串 $s$（$1 \le |s| \le 10^6$），只含小写拉丁字母。

**输出格式**：一行一个字符串 $t$；若不存在输出 `Just a legend`。

## 解法 1：KMP 前缀函数 + border 链

### 思路

$t$ 必须同时是 $s$ 的前缀和后缀，即 $t$ 是 $s$ 的 border。$s$ 的所有 border 长度构成一条链：$\pi(n), \pi(\pi(n)), \ldots$，其中 $\pi$ 是前缀函数，$n = |s|$。

一个长度为 $L$ 的 border 在中间出现，当且仅当它有一个出现位置 $q$ 满足 $2 \le q \le n - L$（$q = 1$ 是开头那次，$q = n - L + 1$ 是结尾那次）。

分三步：

1. **求最长 border**。对 $s$ 求前缀函数，$\pi(n)$ 即最长 border $p$ 的长度，记作 $\mathit{borderLen}$。若 $\mathit{borderLen} = 0$，$s$ 没有任何 border，直接输出 `Just a legend`。

2. **在中间匹配 $p$**。把 $p$ 作为模式串在 $s$ 上跑 KMP，只统计终点 $i \le n - 1$ 的匹配。因为匹配段长度 $j \le i - 1$，其起点 $i - j + 1 \ge 2$，所以这样的匹配段恰好落在 $[2, n - L]$，即中间出现。令 $\mathit{res}$ 为匹配过程中 $p$ 的前缀被匹配到的最大长度，则：
   令 $\mathit{innerLen}$ 为匹配过程中 $p$ 的前缀被匹配到的最大长度，则：

    $$
    \text{长度 } L \text{ 在中间出现} \iff L \le \mathit{innerLen}
    $$

    （$L \le \mathit{innerLen}$ 时取该匹配段的前 $L$ 个字符即得一个中间出现；反之任何中间出现都会使 $\mathit{innerLen} \ge L$。）

3. **在 border 链上取答案**。$p$ 的 border 恰好是 $s$ 的长度不超过 $|p|$ 的 border，沿 $p$ 的 border 链从长到短找第一个不超过 $\mathit{res}$ 的长度：
   沿 $p$ 的 border 链从长到短找第一个不超过 $\mathit{innerLen}$ 的长度：

    $$
    \mathit{res} = \max\{L \mid L \text{ 是 } s \text{ 的 border},\ L \le \mathit{innerLen}\}
    $$

    $\mathit{res} > 0$ 则输出 $s$ 的长度 $\mathit{res}$ 前缀，否则输出 `Just a legend`。

正确性：合法答案必须是中间出现的 border，其长度不超过 $\mathit{innerLen}$，不会漏掉更优候选；而 $\mathit{res}$ 既是 border 又满足 $\mathit{res} \le \mathit{innerLen}$，即在中间出现过，所以它就是最长的合法答案。

### 复杂度

- 时间：$O(n)$（两次前缀函数 + 一次 KMP 扫描）
- 空间：$O(n)$

## 样例

### Sample 1（基本功能）

**输入：**

```
fixprefixsuffix
```

**输出：**

```
fix
```

**说明：** `fix` 是 $s$ 的 border（前缀 `fix` 与后缀 `fix`），且在中间的 `prefix` 里出现过，是满足条件的最长子串。

---

### Sample 2（坑点：内部匹配段不一定是 border）

**输入：**

```
abcdabc
```

**输出：**

```
Just a legend
```

**说明：** 最长 border `abc` 只在开头和结尾出现；内部虽能匹配到 `ab`（$\mathit{innerLen} = 2$），但 `ab` 不是 $s$ 的 border（border 链为 $3 \to 0$），故无解。

---

### Sample 3（边界：border 只在首尾出现）

**输入：**

```
aa
```

**输出：**

```
Just a legend
```

**说明：** 唯一真 border `a` 只在位置 $1$（开头）和位置 $2$（结尾）出现，没有中间出现。

---

### Sample 4（坑点：最长 border 无中间出现，需沿 border 链回退）

**输入：**

```
ababa
```

**输出：**

```
a
```

**说明：** 最长 border `aba` 的出现位置为 $1$ 和 $3$，其中 $3 = n - 3 + 1$ 是结尾那次，没有中间出现；沿 border 链回退到 `a`，它在位置 $3$（$2 \le 3 \le n - 1$）出现，处于中间，故输出 `a`。
