# CF_2248D_Good_Pair_Queries

- **来源**：[Codeforces Round 1113 (Div. 2) D - Good Pair Queries](https://codeforces.com/problemset/problem/2248D)（rating 1400）
- **标签**：构造、贪心、前缀和
- **日期**：2026-09-16

## 一句话题目

给两个等长 01 串 $s$、$t$，每次操作可同时从两串中删除同一组下标（要求某个字符 $c$ 在被删除的两段子序列中都是众数）；回答若干询问：区间内的子串对能否被删空。

## 一句话题解

把每个下标按 $(s_i, t_i)$ 分成四类列，对四类分别做前缀和；区间内「两种混合列数量之差的绝对值」不超过「两种纯列数量之和」，即 $|x - y| \le u + v$ 时可删空。

## 题目描述

给定两个长度为 $n$ 的二进制串 $s$、$t$。称等长的串对 $(a, b)$ 是好的，如果可以通过若干次以下操作把两个串都删空：

- 任选非空下标集合 $1 \le i_1 < i_2 < \ldots < i_k \le |a|$ 和字符 $c \in \{0, 1\}$；
- 设 $x$ 为 $a$ 中这些下标的字符组成的串，$y$ 为 $b$ 中对应的串；
- $c$ 必须同时是 $x$ 和 $y$ 的众数（在 01 串中两个字符可以同时是众数，即出现次数 $\ge \left\lceil \frac{|z|}{2} \right\rceil$）；
- 从两个串中同时删除这些下标的字符，剩余字符保持相对顺序拼接。

回答 $q$ 个询问，每次给定 $l, r$，判断子串对 $(s_l \ldots s_r,\ t_l \ldots t_r)$ 是否好的。询问相互独立。

**输入格式**：第一行 $t$ 表示测试组数。每组：第一行 $n, q$；接下来两行分别是 $s$、$t$；随后 $q$ 行每行 $l\ r$。

**输出格式**：对每个询问输出 `YES` 或 `NO`。

**数据范围**：$1 \le t \le 10^4$；$1 \le n, q \le 2 \cdot 10^5$；$\sum n$、$\sum q \le 2 \cdot 10^5$。

## 解法 1：四类列前缀和（结论 + 构造）

### 思路

**第一步：观察一次操作到底在干什么。**

把每个下标 $i$ 看成一列 $(s_i, t_i)$。一列只有 4 种可能：

| 类型 | $(0,0)$ | $(1,1)$ | $(0,1)$ | $(1,0)$ |
|------|---------|---------|---------|---------|
| 记为 | $u$ | $v$ | $x$ | $y$ |
| 形象叫法 | 纯 0 列 | 纯 1 列 | 混合列 | 混合列 |

由于操作总是**同时删两串的同一组下标**，整道题就是在问：区间里的这些列，能不能划分成若干组，每组都能被一次操作删掉。

**第二步：观察一次操作删掉的列满足什么限制。**

设某次操作删了 $k$ 列，其中四类列分别有 $u_0, v_0, x_0, y_0$ 个。

- 若 $c = 0$：$s$ 侧被删的 0 来自 $(0,0)$ 和 $(0,1)$ 列，共 $u_0 + x_0$ 个；$t$ 侧的 0 来自 $(0,0)$ 和 $(1,0)$ 列，共 $u_0 + y_0$ 个。众数条件要求两者都 $\ge \lceil k/2 \rceil$。
- 两式相加：$2u_0 + x_0 + y_0 \ge k = u_0 + v_0 + x_0 + y_0$，推出 $u_0 \ge v_0$（删的纯 0 列不少于纯 1 列）；两式相减推出 $|x_0 - y_0| \le u_0 + v_0$。
- $c = 1$ 完全对称：$v_0 \ge u_0$，且 $|x_0 - y_0| \le u_0 + v_0$。

也就是说，**无论怎么操作，删掉的混合列失衡度 $|x_0 - y_0|$ 永远不会超过删掉的纯列总数 $u_0 + v_0$**。

**第三步：从"终点倒推"得到必要条件。**

盯着量 $\Phi = |x - y| - (u + v)$（混合列的失衡度超出纯列库存的部分）。一次操作中，$|x - y|$ 最多下降 $|x_0 - y_0|$（三角不等式），而 $u + v$ 恰好下降 $u_0 + v_0$，由第二步知 $|x_0 - y_0| \le u_0 + v_0$，所以 **$\Phi$ 在一次操作后不会变小**。

删空后 $\Phi = 0$，因此一开始就必须有 $\Phi \le 0$，即必要条件：

$$
|x - y| \le u + v
$$

**第四步：验证这个条件也是充分的（构造删法）。**

先看哪些小组能一次删掉：

- **单个纯列**可以单独删：$(0,0)$ 配 $c=0$，$(1,1)$ 配 $c=1$，众数条件平凡成立；
- **两列一起删**：只要不是两个相同的混合列就都可以——纯列和任何列搭配都行（$k=2$ 时众数只需出现 $\ge 1$ 次）；两个不同的混合列 $(0,1) + (1,0)$，无论选 $c=0$ 还是 $c=1$，两侧都恰好各有一个 $c$，也都行。

于是构造删法：先把 $\min(x, y)$ 个 $(0,1)$ 列和同样多的 $(1,0)$ 列两两配对删去；剩下 $|x - y|$ 个混合列全是同一种，每个搭一个纯列删去——这一步**恰好需要纯列库存 $u + v \ge |x - y|$**；剩下的纯列两两任意配对删去；如果剩下奇数个纯列，最后单独剩一个纯列，单独删即可（总列数为奇数时剩下的必然是纯列）。所有组都是合法操作，故条件充分。

**第五步：落实到代码。**

对四类列分别求前缀和，每个询问 $O(1)$ 取出四个计数，判断 $|x - y| \le u + v$ 即可。

### 复杂度

- 时间：$O(n + q)$ 每组数据，总计 $O(\sum n + \sum q) \le 4 \cdot 10^5$
- 空间：$O(n)$

### 代码

见 `correct_code_01.cpp`。

### 坑点

- 调试过程未留存错误代码（未记录）。本题的主要陷阱是只推必要性不敢写充分性：样例 3（`00011` / `01111`）提示了"一次删不完可以分多次"，必须想清楚多次操作的构造（纯列当缓冲）才能确认条件充分。
- 多测记得清空四类前缀和；串读入后转为 $1$ 下标方便做前缀。

## 样例

### Sample 1（基本功能，题面样例）

**输入：**
```
3
2 2
01
10
1 1
1 2
5 1
11111
11111
1 3
5 1
00011
01111
1 5
```

**输出：**
```
NO
YES
YES
YES
```

**说明：** 询问 1 是 $(0,1)$：单个混合列，没有公共众数字符，删不掉 → NO；询问 2 是 $(01, 10)$：$x=y=1$，一次全选、任选 $c$ 都成立 → YES；询问 4 中 $x=2$、$u+v=3$，$2 \le 3$，按"先混合互配、再混合配纯列"分三次删空 → YES。
