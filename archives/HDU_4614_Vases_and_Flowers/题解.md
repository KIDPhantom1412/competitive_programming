## 一句话题目

维护一排花瓶的插花/清理操作，查询每次插花的首尾位置和每次清理丢弃的花朵数。

## 一句话题解

用线段树维护区间已插花数量，支持区间置 0/1 与区间求和；插 F 朵花时二分找到第 1 个和第 F 个空瓶位置。

## 题目描述

Alice 有 N 个花瓶，编号 `0 ~ N-1`。每天进行 M 个操作：

- `1 A F`：收到 F 朵花，从花瓶 A 开始依次向后尝试放置，每个空瓶放一朵，遇到有花的则跳过。花要么放完，要么到达 N-1 时剩下的丢弃。输出第一朵和最后一朵放到的花瓶编号；一朵都没放到则输出 `Can not put any one.`。
- `2 A B`：清空花瓶 A 到 B，输出丢弃的花朵数。

每个测试 case 结束后输出一个空行。

**数据范围**：多组测试，`1 < N, M < 50001`。

## 解法 1：线段树 + 二分

### 思路

把花瓶是否插花看成 0/1 数组。需要支持：

1. 区间赋值为 1（插花）
2. 区间赋值为 0（清理）
3. 区间求和（查询区间内已插花数量）

这三个操作都可以用带懒标记的线段树在 `O(log N)` 完成。由于 vase 编号是 0-based，代码内部用 1-based 方便线段树。

对于操作 1：

- 先查询 `[A, N-1]` 中有多少个空瓶 `remainEmpty`。
- 如果为 0，输出 `Can not put any one.`。
- 否则实际要放 `b = min(F, remainEmpty)` 朵。
- 二分查找第 1 个空瓶位置 `l` 和第 `b` 个空瓶位置 `r`。
- 输出 `l-1` 和 `r-1`，并把 `[l, r]` 置 1。

查找第 k 个空瓶：区间 `[start, mid]` 的空瓶数 = `(mid - start + 1) - query(start, mid)`，利用这个单调性二分即可。

### 复杂度

- 时间：`O(M log N)`
- 空间：`O(N)`

### 代码

见 `correct_code_01.cpp`。

### 坑点

1. **懒标记无法区分“清空”与“无标记”**  
   原错误代码只用 `tr[u].d` 表示懒标记值，`d = 0` 既表示“无标记”也表示“清空（赋 0）”。`pushdown` 写成 `if (tr[u].d)` 时，会把清空操作当成无标记忽略，导致子节点残留旧值。修复方法是增加独立的 `tag` 标志位，按 `tag` 决定是否下传。

2. **查找最后一个空瓶的二分条件写反**  
   原错误代码使用 upper_bound 风格，找“空瓶数 ≤ cnt 的最右位置”。当空瓶不连续、后面还有满瓶时，会把满瓶也错误地包含进来。应改为 lower_bound，找“空瓶数 ≥ cnt 的最左位置”，即第 `cnt` 个空瓶的准确位置。

原始错误代码片段（供对照）：

```cpp
struct TreeNode {
    int v, d;
} tr[N * 4];

void pushdown(int u, int L, int R) {
    if (tr[u].d) {              // 错误：d=0 也可能是“清空”懒标记
        int mid = (L + R) / 2;
        int lc = u * 2, rc = u * 2 + 1;
        tr[lc].v = mid - L + 1, tr[rc].v = R - mid; // 只能下传 1
        tr[lc].d = tr[rc].d = 1;
        tr[u].d = 0;
    }
}

void set(int u, int L, int R, int l, int r, int v) {
    if (L >= l && R <= r) {
        tr[u].v = (R - L + 1) * v;
        tr[u].d = v;            // v=0 时与“无标记”混淆
        return;
    }
    // ...
}

int findLastEmpty(int start, int cnt) {
    int l = start, r = n;
    while (l < r) {
        int mid = (l + r + 1) / 2;
        int remainEmpty = mid - start + 1 - query(1, 1, n, start, mid);
        if (remainEmpty <= cnt) {   // 错误：会越过第 cnt 个空瓶
            l = mid;
        } else {
            r = mid - 1;
        }
    }
    return l;
}
```
