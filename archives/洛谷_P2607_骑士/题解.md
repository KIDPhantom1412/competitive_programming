# 洛谷_P2607_骑士

- **来源**：洛谷 P2607 [ZJOI2008] 骑士
- **标签**：基环树、最大权独立集、树形 DP
- **日期**：2026-07-09

## 一句话题目

从骑士中选出没有矛盾（即不存在互相痛恨的两人）的军团，使战斗力总和最大。

## 一句话题解

每个骑士恰好痛恨一人，因此原图是若干基环树的集合；对每棵基环树断环成树后做最大权独立集 DP，并分别强制断开边的两个端点不选，取最大值。

## 题目描述

$n$ 名骑士，第 $i$ 名骑士有战斗力 $a_i$，并痛恨另一名骑士 $b_i$（$b_i \neq i$）。要求选出若干骑士，使得任意被选中的骑士与其痛恨的骑士不能同时被选中，并最大化战斗力总和。

**输入格式：**
- 第一行一个整数 $n$。
- 接下来 $n$ 行，每行两个整数 $a_i, b_i$。

**输出格式：**
- 一行一个整数，表示最大战斗力总和。

**数据范围：** $1 \le n \le 10^6$，$a_i \le 10^6$。

## 解法 1：基环树 + 树形 DP

### 思路

1. 按无向图建图：每名骑士 $i$ 与其痛恨对象 $b_i$ 连一条无向边。
2. 每个连通块都是一棵基环树（有且仅有一个环）。
3. 找到环上任意一条边 $(u, v)$ 并删除，得到一棵树。
4. 在这棵树上分别做两次树形 DP：
   - 强制 $u$ 不选：$f[u][0]$。
   - 强制 $v$ 不选：$f[v][0]$。
5. 该连通块的答案为 $\max(f[u][0], f[v][0])$。

树形 DP 转移：

```text
f[x][0] = Σ max(f[y][0], f[y][1])   // x 不选，子节点可选可不选
f[x][1] = a_x + Σ f[y][0]            // x 选，子节点必须不选
```

### 复杂度

- 时间：$O(n)$
- 空间：$O(n)$

### 坑点

**漏判已删除边导致 WA**：原代码 `findCircle` 中只判断了 `v != fa`，没有判断 `v == -1`（已删边）。在找到环并执行 `E[i].v = E[i ^ 1].v = -1` 后，继续遍历同一条邻接表时仍会遇到 `v = -1` 的边。此时执行 `if (st[v])` 会访问 `st[-1]`（未定义行为），若该内存恰好为真，`circle` 会被覆盖成类似 `{8, -1}` 的非法值，随后 `dfs(-1)` 被调用并贡献 0，导致答案偏小。

修复：把 `if (v != fa)` 改为 `if (v != fa && v != -1)`。
