## 一句话题目

从 $1$ 出发，可以任意次把当前数乘 $a$ 或加 $b$，判断能否得到 $n$。

## 一句话题解

集合中的数都能写成 $a^k + b \cdot t$。枚举不超过 $n$ 的 $a^k$，检查是否有 $a^k \equiv n \pmod b$；$a = 1$ 时乘法无效，退化为判断 $(n - 1)$ 能否被 $b$ 整除。

## 题目描述

有一个无限集合，按如下规则生成：

- $1$ 在集合中；
- 若 $x$ 在集合中，则 $x \cdot a$ 和 $x + b$ 也都在集合中。

例如 $a = 3$、$b = 6$ 时，最小的五个元素是 $1$、$3$、$7$、$9$、$13$。

给定正整数 $n, a, b$，判断 $n$ 是否在集合中。

**输入格式**：第一行一个整数 $t$（$1 \le t \le 10^5$）。接下来 $t$ 行，每行三个整数 $n, a, b$（$1 \le n, a, b \le 10^9$）。

**输出格式**：每组数据输出一行 `Yes` 或 `No`，大小写不限。

## 解法 1：枚举乘 $a$ 的次数

### 思路

从 $1$ 出发，设一共做了 $k$ 次「乘 $a$」。一次「加 $b$」如果后面还要再乘 $r$ 次 $a$，它对最终结果的贡献是 $b \cdot a^r$。因此集合里的每个数都可以写成

$$
n = a^k + b \sum_{i=0}^{k} c_i a^i, \quad c_i \ge 0.
$$

右边除 $a^k$ 外每一项都含因子 $b$，所以

$$
n \equiv a^k \pmod b, \quad a^k \le n.
$$

反过来，只要存在这样的 $k$，就先把 $1$ 连乘 $k$ 次 $a$ 得到 $a^k$，再把 $b$ 加 $\dfrac{n - a^k}{b}$ 次。加法不必插在乘法中间，最后统一加即可。

于是只需枚举 $k = 0, 1, 2, \ldots$，直到 $a^k > n$。$a \ge 2$ 时幂次指数增长，每个测试最多约 $\log n$ 次。

$a = 1$ 时乘 $a$ 不改变数值，$a^k$ 恒为 $1$，条件变成 $(n - 1) \bmod b = 0$。这一支必须单独处理，否则循环里执行 $i \gets i \cdot a$ 不会终止。

$b = 1$ 时任何整数模 $1$ 都是 $0$，从 $1$ 不断加 $1$ 能到达所有正整数，枚举到 $k = 0$ 就会得到 `Yes`。

幂次用 64 位整数保存。约束下 $a^k \le n \le 10^9$，下一次乘法的结果不超过 $10^{18}$，不会溢出。

### 复杂度

- 时间：$O(t \log n)$
- 空间：$O(1)$

## 样例

### Sample 1（基本功能）

题目样例。第一组由 $1 \xrightarrow{\times 3} 3 \xrightarrow{+5} 8 \xrightarrow{\times 3} 24$ 得到；第二组在 $a = 3$、$b = 6$ 时最小的五个元素是 $1, 3, 7, 9, 13$，其中没有 $10$。

**输入：**

```
5
24 3 5
10 3 6
2345 1 4
19260817 394 485
19260817 233 264
```

**输出：**

```
Yes
No
Yes
No
Yes
```

**说明：** 第三组 $a = 1$，$(2345 - 1)$ 能被 $4$ 整除，只能靠反复加 $b$。

---

### Sample 2（边界）

$a = 1$ 时乘 $a$ 无效，只能从 $1$ 反复加 $b$。

**输入：**

```
2
5 1 3
7 1 3
```

**输出：**

```
No
Yes
```

**说明：** $5 - 1 = 4$ 不能被 $3$ 整除；$7 = 1 + 3 + 3$。
