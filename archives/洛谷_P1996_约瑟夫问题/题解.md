# 洛谷_P1996_约瑟夫问题

- **来源**：洛谷 P1996
- **标签**：模拟、链表、约瑟夫问题
- **日期**：2026-07-13

## 一句话题目

$n$ 个人围成一圈，从 1 开始报数，数到 $m$ 的人出圈，求所有人的出圈顺序。

## 一句话题解

用静态双向链表维护环形结构，每次从当前位置沿 next 指针走 $m$ 步（跳过哨兵节点），输出并删除该节点，重复 $n$ 次即可。

## 题目描述

$n$ 个人围成一圈，从第一个人开始报数，数到 $m$ 的人出列，再由下一个人重新从 $1$ 开始报数，数到 $m$ 的人再出圈，依次类推，直到所有的人都出圈，请输出依次出圈人的编号。

**输入格式**：输入两个整数 $n, m$。

**输出格式**：输出一行 $n$ 个整数，按顺序输出每个出圈人的编号。

**数据范围**：$1 \le m, n \le 100$。

## 解法 1：双向链表模拟

### 思路

约瑟夫问题最直接的实现就是维护一个环形结构，反复找到第 $m$ 个存活的人并将其移除。这里用数组实现的静态双向链表：

- 数组下标作为节点编号；
- `node[i].v` 表示该位置对应的人的原始编号；
- `node[i].p` 和 `node[i].n` 分别表示前驱和后继；
- 下标 `0` 和 `N-1` 作为头尾哨兵，真正的节点在两者之间，形成一个逻辑上的环。

初始化时把 $1 \sim n$ 依次插入到尾哨兵之前。然后执行 $n$ 轮：

1. 从当前位置出发，调用 `next(iter)` 走 $m$ 次；
2. `next` 函数中先走到 `node[iter].n`，如果落到了头或尾哨兵，则跳回第一个真实节点；
3. 输出该节点的 `v`；
4. 将该节点从链表中删除。

由于删除节点后，当前迭代器仍保存着被删节点的下标，下一轮再调用 `next(iter)` 时，先取被删节点的 `n` 指针。因为删除操作只修改了前后节点的指针，被删节点自身的 `n` 指针仍然指向原来下一个真实节点，所以不会访问到无效位置。

### 复杂度

- 时间：$O(n \cdot m)$，每一轮最多走 $m$ 步，共 $n$ 轮；即使跳过哨兵，总步数仍为线性级别。
- 空间：$O(n)$，静态链表数组。

### 坑点

- **`next` 函数要同时处理 head 和 tail 两个哨兵节点**：当 `node[iter].n` 落到哨兵时，必须跳回到第一个真实节点 `node[head].n`，否则会把不存在的 `0` 或 `N-1` 当作答案输出。
- **删除节点后仍能从被删节点的 `n` 指针出发**：删除操作只修改前后节点的指针，被删节点自身的 `n` 值仍指向原来下一个真实节点，因此下一轮直接对 `iter` 再调用一次 `next` 即可，不需要额外保存“下一个位置”。但如果 `next` 函数里跳过哨兵的逻辑写漏了（例如只判断 tail 没判断 head），在边界数据下就会出错。

## 样例

### Sample 1（基本功能）

**输入：**
```
10 3
```

**输出：**
```
3 6 9 2 7 1 8 5 10 4
```

```
1 1
```

**输出：**
```
1
```
