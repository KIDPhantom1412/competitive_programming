# 洛谷 P2585 三色二叉树

- **来源**：洛谷 P2585
- **标签**：树形 DP、二叉树
- **日期**：2026-07-02

## 一句话题目

给定一棵二叉树的序列化串，求在满足颜色约束时，绿色节点的最多和最少数量。

## 一句话题解

从后往前扫描序列，用栈维护每棵子树；对每个节点维护“根为绿色/非绿色”时的最大/最小绿色数，合并双儿子时注意两者必须一绿一非绿。

## 题目描述

一棵二叉树按如下规则表示成由 `0`、`1`、`2` 组成的字符串：

- `0`：该节点没有子节点
- `1S1`：该节点有一个子节点，`S1` 为其子树的二叉树序列
- `2S1S2`：该节点有两个子节点，`S1`、`S2` 分别为左右子树的二叉树序列

每个节点可染成红、绿、蓝之一，满足：

1. 一个节点与其子节点颜色必须不同；
2. 若节点有两个子节点，这两个子节点颜色也必须不同。

给定二叉树序列，求最多和最少有多少个节点能被染成绿色。

## 解法 1：树形 DP

### 思路

1. 字符串从后往前扫描，遇到 `0` 直接入栈；
2. 遇到 `1` 弹出一个子节点，计算合并后的 DP 值再入栈；
3. 遇到 `2` 弹出左右两个子节点，合并后再入栈。

设 `mn[i][0/1]`、`mx[i][0/1]` 分别表示以位置 `i` 为根的子树中，根节点非绿色 / 绿色时的最少、最多绿色节点数。

状态转移：

- **叶子节点 `0`**：
  - 非绿：0；绿：1。
- **单儿子节点 `1`**：
  - 当前绿：子节点必须非绿 → `dp[child][0] + 1`
  - 当前非绿：子节点可绿或非绿 → `min/max(dp[child][0], dp[child][1])`
- **双儿子节点 `2`**：
  - 当前绿：两个儿子必须都非绿，且颜色不同（一个红一个蓝） → `dp[lc][0] + dp[rc][0] + 1`
  - 当前非绿：两个儿子必须一个绿、一个非绿（且非绿的儿子颜色与父不同） → `min/max(dp[lc][0] + dp[rc][1], dp[lc][1] + dp[rc][0])`

最后答案为：

```text
最多 = max(mx[root][0], mx[root][1])
最少 = min(mn[root][0], mn[root][1])
```

注意输出顺序是**先最多，后最少**。

### 复杂度

- 时间：O(|s|)
- 空间：O(|s|)

### 代码

见 `correct_code_01.cpp`。

### 坑点

1. 双儿子节点且父节点非绿时，不能简单地让两个儿子各自取最优。必须强制一绿一非绿，否则会出现“两个儿子同为绿色”或“两个儿子同为非绿色”的非法状态。
2. 最终输出顺序是先“最多”后“最少”，容易写反。
3. 原始错误代码中：
   - `mn[i][0] = min(mn[lc][0], mn[lc][1]) + min(mn[rc][0], mn[rc][1])` 允许两子同绿，导致最小值偏小；
   - `mx[i][0] = max(...) + max(...)` 同样允许两子同绿，导致最大值偏大；
   - 输出顺序写反，使得样例输出 `0 6` 而非 `5 2`。
