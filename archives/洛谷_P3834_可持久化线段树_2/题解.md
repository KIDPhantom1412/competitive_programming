# 可持久化线段树 2（静态区间第 k 小）

- **来源**：洛谷 P3834
- **标签**：可持久化线段树、主席树、离散化
- **日期**：2026-08-23

## 一句话题目

给定长度为 $n$ 的序列 $a$，$m$ 次询问闭区间 $[l, r]$ 内的第 $k$ 小值。

## 一句话题解

离散化后按下标顺序建立可持久化权值线段树（主席树），查询时用 `root[r]` 与 `root[l-1]` 两个版本做前缀和差分，在线段树上二分定位第 $k$ 小。

## 题目描述

给定 $n$ 个整数构成的序列 $a$，对于指定的闭区间 $[l, r]$ 查询其区间内的第 $k$ 小值。

**输入：** 第一行两个整数 $n, m$；第二行 $n$ 个整数 $a_i$；接下来 $m$ 行每行三个整数 $l, r, k$。

**输出：** 对于每次询问，输出一行一个整数表示答案。

**数据范围：** $1 \le n, m \le 2\times10^5$，$0 \le a_i \le 10^9$，$1 \le l \le r \le n$，$1 \le k \le r-l+1$。

## 解法 1：可持久化权值线段树（主席树）

### 思路

1. 对 $a$ 离散化，将值域压缩到 $[1, S]$（$S$ 为去重后的元素个数）。
2. 按下标 $i = 1 \dots n$ 依次在上一版本的线段树上插入 `find(a[i])`，得到版本 `root[i]`。`root[i]` 记录了前缀 $a[1..i]$ 中每个值的出现次数。动态开点，每次插入只新建 $\log S$ 个节点，无需 `build`（空节点用 0 表示）。
3. 查询 $[l, r]$ 第 $k$ 小：令 `u = root[l-1]`、`v = root[r]`，则任意值域区间内元素个数 = `tr[v子树].sum - tr[u子树].sum`。从根出发，若左子树计数 `ls >= k` 则进入左子树，否则进入右子树并令 `k -= ls`，直到叶子，返回离散化排名，再用 `disc[rank - 1]` 映射回原值。

### 复杂度

- 时间：$O((n + m) \log n)$
- 空间：$O(n \log n)$（节点数约 $n \times (\log n + 1) \approx 3.8\times10^6$）

### 坑点

本次调试共发现 3 处错误（均不影响建树部分，集中在查询入口和叶子判断）：

1. **输出未映射回原值**：`query` 返回的是离散化排名，却直接用 `A[rank]` 输出（`A` 按下标存储，与排名无关），应改为 `disc[rank - 1]`。表现为样例全输出 0。
2. **查询版本参数顺序颠倒**：`query(u, v, ...)` 内部计算 `tr[v] - tr[u]` 的差分，调用时误写为 `query(root[r], root[l-1], ...)`，导致左子树计数为负、查询走错子树。正确写法是 `query(root[l-1], root[r], ...)`。
3. **叶子判断多此一举**：写成 `return k == 1 ? L : -1;`。有重复元素时多个元素共享同一排名，叶子 `sum > 1`，递归到叶子时 $k$ 可以大于 1（例如 `[0,0,0,2,1,5]` 查第 3 小，到叶子时 $k=3$），此时应直接 `return L;`，否则返回 -1 导致越界读取垃圾值。**该 bug 样例无法暴露（样例无重复值），必须靠含重复值的随机数据对拍发现**。

## 样例

---

### Sample 2（坑点：重复元素，叶子处 k > 1）

**输入：**

```
6 1
0 0 0 2 1 5
1 6 3
```

**输出：**

```
0
```

**说明：** 值 0 出现 3 次，查第 3 小时递归到叶子 $k=3$。若叶子判断写成 `k == 1 ? L : -1` 会返回 -1 导致错误，必须直接返回 `L`。
