# CF_1497C2_k-LCM_hard_version

- **来源**：Codeforces 1497C2（Codeforces Round #708, Div. 2）
- **标签**：构造、数学、数论
- **日期**：2026-10-21

## 一句话题目

给定 $n$ 和 $k$（$3 \le k \le n$），找出 $k$ 个正整数，使其和为 $n$ 且最小公倍数不超过 $\frac{n}{2}$。

## 一句话题解

先在 $m = n - k + 3$ 上构造三个和为 $m$、$\operatorname{lcm} \le \frac{m}{2}$ 的数（奇数拆 $\lfloor\frac{m}{2}\rfloor, \lfloor\frac{m}{2}\rfloor, 1$；$m \bmod 4 = 2$ 拆 $\frac{m}{2}-1, \frac{m}{2}-1, 2$；$m \bmod 4 = 0$ 拆 $\frac{m}{4}, \frac{m}{4}, \frac{m}{2}$），其余 $k-3$ 个位置全部填 $1$。

## 题目描述

这是 easy version（$k = 3$）的加强版，唯一区别是本题 $3 \le k \le n$。

给定正整数 $n$，求 $k$ 个正整数 $a_1, a_2, \ldots, a_k$，满足：

- $a_1 + a_2 + \ldots + a_k = n$
- $\operatorname{lcm}(a_1, a_2, \ldots, a_k) \le \frac{n}{2}$

题目保证答案一定存在。

**输入格式**：第一行一个整数 $t$（$1 \le t \le 10^4$），表示测试组数。接下来每行两个整数 $n, k$（$3 \le n \le 10^9$，$3 \le k \le n$）。保证所有测试的 $k$ 之和不超过 $10^5$。

**输出格式**：每组输出一行 $k$ 个正整数，满足上述两个条件。若有多个合法解，输出任意一个即可。

## 解法 1：三元构造 + 补 1

### 思路

关键观察：如果能在某个 $m$ 上构造出三个和为 $m$ 且 $\operatorname{lcm} \le \frac{m}{2}$ 的正整数，那么对任意 $k \ge 3$，取 $m = n - k + 3$ 构造出这三个数，再补 $k - 3$ 个 $1$ 即可：

- 和为 $m + (k - 3) = n$；
- $1$ 不影响最小公倍数，故 $\operatorname{lcm} \le \frac{n - k + 3}{2} \le \frac{n}{2}$（因为 $k \ge 3$）。

于是问题归结为三元构造（即 easy version）。对 $m$ 按奇偶、模 $4$ 分类：

1. $m$ 为奇数：取

$$
\frac{m-1}{2},\ \frac{m-1}{2},\ 1
$$

和为 $m$，$\operatorname{lcm} = \frac{m-1}{2} < \frac{m}{2}$。

2. $m \equiv 2 \pmod 4$：取

$$
\frac{m}{2}-1,\ \frac{m}{2}-1,\ 2
$$

此时 $\frac{m}{2}$ 为奇数，故 $\frac{m}{2}-1$ 为偶数，$\operatorname{lcm} = \frac{m}{2}-1 < \frac{m}{2}$，和为 $m$。

3. $m \equiv 0 \pmod 4$：取

$$
\frac{m}{4},\ \frac{m}{4},\ \frac{m}{2}
$$

和为 $m$，$\operatorname{lcm} = \frac{m}{2}$，恰好取到上界。

三种情况覆盖所有 $m \ge 3$（$m = n - k + 3 \ge 3$），且每个数都是正整数，构造合法。

### 复杂度

- 时间：$O(\sum k)$（输出主导）
- 空间：$O(1)$

## 样例

### Sample 1（基本功能）

**输入：**

```
2
6 4
9 5
```

**输出：**

```
2 2 1 1
3 3 1 1 1
```

**说明：** 与题目样例的 `1 2 2 1` / `1 3 3 1 1` 是同一组数的不同顺序；答案不唯一，输出任意合法解即可。

---

### Sample 2（边界）

**输入：**

```
4
3 3
5 5
8 3
12 3
```

**输出：**

```
1 1 1
1 1 1 1 1
2 2 4
3 3 6
```

**说明：** $k = 3$ 时直接输出三元组；$k = n$ 时全为 $1$；$n = 12,\ k = 3$ 命中 $m \bmod 4 = 0$ 分支，$\operatorname{lcm} = 6 = \frac{n}{2}$，恰好取到上界。

---

### Sample 3（极端数据）

**输入：**

```
1
1000000000 3
```

**输出：**

```
250000000 250000000 500000000
```

**说明：** $n = 10^9$ 且 $k = 3$ 时 $m = 10^9 \equiv 0 \pmod 4$，$\operatorname{lcm} = 5 \times 10^8 = \frac{n}{2}$。
