## 一句话题目

给一棵 $n$ 个点的树的 $n-1$ 条边分配互不相同的 $0 \sim n-2$ 的标签，使所有点对 $(u, v)$ 路径标签集合的 MEX 的最大值尽可能小，输出每条边的标签。

## 一句话题解

找到任意一个度数 $\ge 3$ 的点，先把它连出的边依次标 $0, 1, 2, \dots$，其余边随便往后递增编号；这样任何路径经过该点最多只用它两条邻边，取不到 $\{0,1,2\}$，MEX 最大值必为 $2$。若不存在这样的点，整棵树是一条链，答案只能是 $n-1$，按输入顺序编号即可。

## 题目描述

给定一棵 $n$ 个节点的树。要求给每条边打上标签，满足：

- 每个标签是 $0$ 到 $n-2$（含）之间的整数；
- 所有标签互不相同；
- 所有点对 $(u, v)$ 的 $MEX(u, v)$ 的最大值尽可能小。

这里 $MEX(u, v)$ 表示 $u$ 到 $v$ 的唯一简单路径上**没有出现过**的最小非负整数。

### 输入格式

第一行一个整数 $n$（$2 \le n \le 10^5$），表示节点数。

接下来 $n-1$ 行，每行两个整数 $u, v$（$1 \le u, v \le n$），表示一条边；保证给出的图是一棵树。

### 输出格式

输出 $n-1$ 个整数，第 $i$ 个数表示输入中第 $i$ 条边上的标签（可与样例不同，任何合法方案均可）。

## 解法 1：构造（把最小标签堆在一个度数 $\ge 3$ 的点上）

### 思路

记 $k$ 为最优解中 $\max_{(u,v)} MEX(u,v)$ 的取值。

**上界**：设存在结点 $v$ 度数 $\ge 3$。把 $v$ 连出的边依次标成 $0, 1, 2, \dots$（先标这些，再给剩下的边递增编号）。任意一条简单路径经过 $v$ 时，最多用到 $v$ 的两条邻边（一进一出），因此路径上最多包含 $\{0, 1, 2\}$ 中的两个数，绝不可能同时拿到 $0, 1, 2$，于是 $MEX(u, v) \le 2$，即 $k \le 2$。

**下界**：若存在度数 $\ge 3$ 的点 $v$，它有三条邻边 $e_1, e_2, e_3$。三对邻边的远端之间各有一条路径经过 $v$ 并使用对应的两条边。三个标签中必有两个被路径同时取到；只要 $0$ 和 $1$ 被同一条路径取到，该路径 MEX 就 $\ge 2$。所以无论如何 $k \ge 2$。

结合上下界，只要树中存在度数 $\ge 3$ 的点，答案恒为 $2$，而且 $0, 1, 2$ 是否贴在同一个点的三条邻边上是唯一的关键——只要它们被同一个点的三条不同邻边分走（或更一般地，全部分配给该点的邻边），构造就合法。代码里把该点**所有**邻边都顺序编号，同样满足「路径最多取其中两条」的性质。

**不存在度数 $\ge 3$ 的点**时，树是一条链（$n \ge 2$ 时每个点度数 $\le 2$ 且连通）。链的两个端点之间的唯一路径包含全部 $n-1$ 条边，也就包含全部标签 $0 \sim n-2$，MEX 必为 $n-1$，此时怎么编号都无法变小，直接按输入顺序编号输出即可。

实现上只要扫一遍度数，找到第一个度数 $\ge 3$ 的点，用计数器 `idx` 顺序给它的邻边赋值，剩下的边再按输入顺序接在后面编号。

### 复杂度

- 时间：$O(n)$
- 空间：$O(n)$

## 样例

### Sample 1（基本功能）

**输入：**

```
3
1 2
1 3
```

**输出：**

```
0
1
```

**说明：** 整棵树就是链 $2 - 1 - 3$，唯一的路径包含两条边，标签必为 $0$ 和 $1$，MEX 恒为 $2$。

---

### Sample 2（一般树，含度数 $3$ 的点）

**输入：**

```
6
1 2
1 3
2 4
2 5
5 6
```

**输出：**

```
0
3
2
4
1
```

**说明：** 结点 $2$ 度数 $3$（邻边 $1-2$、$2-4$、$2-5$），把 $0, 2, 4$ 放在它上面即可保证最大 MEX 为 $2$；样例中的 $0, 1, 2$ 集中在它的三条邻边上是更标准的写法，本题多解。

---

### Sample 3（极端数据：菊花图，$\deg = n-1$）

**输入：**

```
4
1 2
1 3
1 4
```

**输出：**

```
0
1
2
```

**说明：** 中心点度数为 $3$，三条边直接拿 $0, 1, 2$；任取两片叶子，路径只含两条边，MEX 最大为 $2$。当 $n$ 更大时把中心点的所有边顺序编号依然合法。

---

### Sample 4（边界：$n = 2$）

**输入：**

```
2
1 2
```

**输出：**

```
0
```

**说明：** 只有一条边，唯一路径的 MEX 为 $1$；也是「链」的退化情形，代码中找不到度数 $\ge 3$ 的点，因此按输入顺序输出 $0$。
