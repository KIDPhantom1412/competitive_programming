## 一句话题目

在不超过 n 的正整数中，按照“约数之和”规则转换且数字不重复，求最多能变换多少步。

## 一句话题解

先筛出每个数的真约数之和并建成森林，再对每个连通块求树的直径，直径最大值即为答案。

## 题目描述

如果一个数 x 的约数之和 y（不包括它本身）比它本身小，那么 x 可以变成 y，y 也可以变成 x。

限定所有数字变换在不超过 n 的正整数范围内进行，求不断进行数字变换且不出现重复数字的最多变换步数。

**输入格式：**

输入一个正整数 n。

**输出格式：**

输出不断进行数字变换且不出现重复数字的最多变换步数。

**数据范围：**

1 ≤ n ≤ 50000

## 解法 1：筛法 + 树形 DP 求树的直径

### 思路

1. **计算真约数之和**：对于每个 i，枚举它的所有倍数 j（j = 2i, 3i, ...），将 i 累加到 sd[j] 中。时间复杂度为 O(n log n)。

2. **建图**：如果 sd[i] < i，说明 i 与 sd[i] 可以互相转换。由于每个数只会有一个“真约数之和”sd[i]，且 sd[i] < i，因此把边从 sd[i] 指向 i 会形成一片有根森林（以 1 及真约数和小于 1 的数为根）。忽略方向后是一片无向森林。

3. **求最长路径**：在树中，不重复经过节点的最长路径就是该树的直径。对每个连通块做 DFS，维护每个节点向下的最长链 d1 和次长链 d2，则经过该节点的最长路径为 d1 + d2，全局取最大值即可。

### 复杂度

- **时间**：O(n log n)
- **空间**：O(n)
