## 一句话题目

给定一棵带权树，求每个节点到最远节点的距离。

## 一句话题解

两遍 DFS 求出每个节点向下的最长/次长距离以及来源子树，再用一次 DFS 换根求出每个节点向上的最长距离，三者取最大即为答案。

## 题目描述

学校买了一台编号为 1 的电脑，之后又买了 $N-1$ 台新电脑。每台新电脑都会连接到一台已有的电脑上，连接电缆有长度。现在管理员想知道每台电脑 $i$ 发送信号能到达的最远距离 $S_i$（即到最远电脑的路径长度）。

**输入格式：**
输入包含多组测试数据。每组数据第一行一个自然数 $N$（$N \le 10000$），接下来 $N-1$ 行，第 $i$ 行包含两个自然数：第 $i$ 台电脑连接到的电脑编号以及电缆长度。电缆总长度不超过 $10^9$。

**输出格式：**
对于每组数据输出 $N$ 行，第 $i$ 行输出第 $i$ 台电脑的 $S_i$。

## 解法 1：树形 DP（换根 DP）

### 思路

把网络看成一棵以 1 为根的带权树。对每个节点 $u$，它到其他节点的最远距离只可能来自两个方向：

1. **向下**：$u$ 的某个子树中的最远节点；
2. **向上**：$u$ 经过父节点能够到达的最远节点。

第一遍 DFS（`dfs1`）计算向下的最长距离 `dn1[u]`、次长距离 `dn2[u]`，以及最长距离来自哪个子节点 `dc[u]`。

第二遍 DFS（`dfs2`）利用父节点已经算好的向上距离 `up[u]`，推导出子节点 $v$ 的向上距离 `up[v]`：

- 如果 $v$ 是 $u$ 的最远距离来源子节点，那么 $v$ 不能再用 `dn1[u]`，只能用 `dn2[u] + w` 或 `up[u] + w`；
- 否则，$v$ 可以使用 `dn1[u] + w` 或 `up[u] + w`。

最终每个节点 $u$ 的答案为 $\max(up[u], dn1[u])$。

### 复杂度

- 时间：$O(N)$
- 空间：$O(N)$

见 `correct_code_01.cpp`。

### 坑点

1. **多组数据直到 EOF**：题目明确说明 `Input file contains multiple test cases`，需要用 `while (std::cin >> n)` 持续读取，否则只能过第一组数据。
2. **每组数据清空图**：链式前向星数组 `H` 和 `idx` 必须在每组数据开始时清空，否则上一组数据的边会干扰当前计算。
3. **最远距离来源子节点不能重复使用**：换根时若子节点恰好是父节点向下最长路径的来源，则只能用次长路径或向上路径更新，否则会导致路径重复经过同一条边。

## 样例

### Sample 1（基本功能）

**输入：**

```
5
1 1
2 1
3 1
1 1
```

**输出：**

```
3
2
3
4
4
```

**说明：** 样例对应题目图片中的树，$S_1=3$、$S_2=2$、$S_3=3$、$S_4=4$、$S_5=4$。

### Sample 2（坑点：多组数据）

**输入：**

```
5
1 1
2 1
3 1
1 1
3
1 2
1 3
```

**输出：**

```
3
2
3
4
4
3
5
5
```

**说明：** 输入包含两组数据，第一组对应题目图片中的树；第二组是以 1 为中心、链长分别为 2 和 3 的星形树，节点 2、3 的最远距离都需经过节点 1 到达对方。若只处理一组数据会漏掉第二组输出。
