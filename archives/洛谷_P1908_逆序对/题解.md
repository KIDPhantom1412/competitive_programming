# 洛谷 P1908 逆序对

- **来源**：洛谷 P1908
- **标签**：逆序对、树状数组、离散化
- **日期**：2026-07-31

## 一句话题目

给定长度为 n 的正整数序列（可能有重复数字，aᵢ ≤ 10⁹），求逆序对（aᵢ > aⱼ 且 i < j）的数目。

## 一句话题解

离散化后用树状数组维护出现次数，从后往前遍历序列，对每个元素查询右侧严格小于它的元素个数并累加。

## 题目描述

猫猫 TOM 和小老鼠 JERRY 比赛统计逆序对。逆序对定义：对于给定的一段正整数序列，逆序对是序列中 aᵢ > aⱼ 且 i < j 的有序对。注意序列中可能有重复数字。

**输入格式**：第一行一个数 n，表示序列中有 n 个数；第二行 n 个数，表示给定的序列，序列中每个数字不超过 10⁹。

**输出格式**：输出序列中逆序对的数目。

**数据范围**：
- 对于 25% 的数据，n ≤ 2500
- 对于 50% 的数据，n ≤ 4×10⁴
- 对于所有数据，1 ≤ n ≤ 5×10⁵

## 解法 1：离散化 + 树状数组

### 思路

1. 由于 aᵢ ≤ 10⁹ 无法直接开数组，先将所有值离散化：排序、去重后用 `lower_bound` 把每个值映射到 `[1, 不同值个数]` 的秩。
2. 树状数组维护每个秩对应值的出现次数。
3. 从后往前遍历序列：对于当前元素 `A[i]`（秩为 x），查询 `sum(x - 1)` 即右侧已经遍历过的元素中**严格小于** `A[i]` 的个数——它们恰好都是以 `A[i]` 为左端的逆序对的右端。累加后执行 `update(x, 1)` 将当前元素加入树状数组。
4. 注意逆序对总数最大约为 n²/2 ≈ 1.25×10¹¹，必须用 `long long` 统计。

### 复杂度

- 时间：O(n log n)（离散化排序 O(n log n) + 每次查询/更新 O(log n)）
- 空间：O(n)

### 坑点

**逆序对是严格大于 `aᵢ > aⱼ`，从后往前遍历时要把当前元素自身排除。**

最初代码写的是 `res += sum(x);`：遍历时当前元素尚未加入树状数组，`sum(x)` 统计的是右侧"小于等于"当前元素的个数，把等于自己的元素也错误计入了逆序对。由于样例 `5 4 2 6 3 1` 没有重复元素，输出恰好正确，极具迷惑性；但题面明确"序列中可能有重复数字"，实际数据中含重复值时出错（如 `1 1 1` 错误输出 3，正确答案为 0）。

**修复**：改为 `res += sum(x - 1);`，只统计严格小于当前元素的个数。

错误代码片段：

```cpp
res += sum(x);  // 错误：包含等于自身的元素
```

正确代码片段：

```cpp
res += sum(x - 1);  // 正确：只统计严格小于当前元素的
```

```
6
5 4 2 6 3 1
```

**输出：**


### Sample 2（坑点：重复元素）

**输入：**
```
3
1 1 1
```

**输出：**
```
0
```

**说明：** 全部元素相等时不存在逆序对；若查询写成 `sum(x)` 会错误输出 3。
