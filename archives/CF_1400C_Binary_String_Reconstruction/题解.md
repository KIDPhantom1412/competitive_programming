# CF 1400C Binary String Reconstruction

- **来源**：Codeforces 1400C（Educational Codeforces Round 94, Div. 2），难度 1500
- **标签**：构造、贪心、2-SAT（题目标签）
- **日期**：2026-11-03

## 一句话题目

给定整数 $x$ 和由 $w$ 按规则生成的 $01$ 串 $s$，还原出原来的串 $w$（多解输出任意一个，无解输出 $-1$）。

## 一句话题解

先由每个 $s_i = 0$ 把 $w_{i-x}$、$w_{i+x}$ 强制置 $0$；再对每个 $s_i = 1$ 检查两个位置中是否至少有一个没被强制置 $0$，有则填 $1$，否则无解。

## 题目描述

有一个长度为 $n$ 的二进制串 $w$ 和一个整数 $x$。按如下方式构造长度同为 $n$ 的二进制串 $s$，$s$ 的第 $i$ 个字符取值规则为：

- 若 $w_{i-x}$ 存在且等于 $1$（即 $i > x$ 且 $w_{i-x} = 1$），则 $s_i = 1$；
- 若 $w_{i+x}$ 存在且等于 $1$（即 $i + x \le n$ 且 $w_{i+x} = 1$），则 $s_i = 1$；
- 若上述两个条件都不满足，则 $s_i = 0$。

现在给出整数 $x$ 和构造结果 $s$，要求还原出 $w$。

### 输入格式

第一行一个整数 $t$（$1 \le t \le 1000$），表示测试组数。

每组数据两行：第一行为串 $s$（$2 \le |s| \le 10^5$，只含 `0` 和 `1`）；第二行为整数 $x$（$1 \le x \le |s| - 1$）。

所有 $s$ 的长度之和不超过 $10^5$。

### 输出格式

每组数据输出一行：

- 若不存在能生成 $s$ 的串 $w$，输出 `-1`；
- 否则输出任意一个长度为 $|s|$ 的二进制串 $w$。

## 解法 1：强制置 0 + 贪心填 1

### 思路

以下下标从 $1$ 开始（与题面一致）；代码中改为从 $0$ 开始，判断条件相应写成 $i - x \ge 0$、$i + x < n$。

$s_i = 0$ 是**强约束**：只要 $i - x \ge 1$，则必有 $w_{i-x} = 0$；只要 $i + x \le n$，则必有 $w_{i+x} = 0$。先把所有这类位置标记为强制 $0$（用 `'-'` 表示尚未确定）。

$s_i = 1$ 是**弱约束**：$w_{i-x}$ 与 $w_{i+x}$ 中至少有一个为 $1$，并且只要有一个为 $1$ 就满足。因此逐个处理 $s_i = 1$，若 $w_{i-x}$ 未被强制置 $0$ 就填 $1$，否则尝试 $w_{i+x}$；若两个位置都被强制置 $0$，说明矛盾，输出 $-1$。

最后把仍未确定的位置统一填 $1$：某个位置 $j$ 仍是 `'-'`，说明所有合法的 $j-x$、$j+x$ 处都满足 $s = 1$（否则它早被强制置 $0$），所以 $w_j = 1$ 不会把任何 $s$ 中的 $0$ 变成 $1$，是安全的。填 $0$ 同样可行，两者等价。

贪心不会造成误判：算法只把位置从 `'-'` 改成 `1`，从不主动写入 $0$（$0$ 只来自强制约束），而把某个位置改成 $1$ 只会让 $s$ 中更多位置变成 $1$，不会破坏已满足的 $s_i = 0$。所以一旦报 $-1$，一定是某个 $s_i = 1$ 的两个来源都被强制置 $0$，确属无解。

### 复杂度

- 时间：$O(n)$ 每组数据，总计 $O\left(\sum |s|\right) \le 10^5$
- 空间：$O(n)$

## 样例

### Sample 1（基本功能）

**输入：**

```
3
101110
2
01
1
110
1
```

**输出：**

```
111011
10
-1
```

**说明：** 第一组中 $s_2 = s_6 = 0$ 共同迫使 $w_4 = 0$，其余位置填 $1$ 即可满足；第二组是 $n = 2, x = 1$ 的最小规模；第三组因 $s_3 = 0$ 迫使 $w_2 = 0$，而 $s_1 = 1$ 的唯一来源就是 $w_2$，故无解。

---

### Sample 2（边界：全部为 0）

**输入：**

```
2
000
1
00
1
```

**输出：**

```
000
00
```

**说明：** 全 $0$ 时 $w$ 也必须全 $0$；$n = 2, x = 1$ 时两个位置互相覆盖，恰好可行。

---

### Sample 3（极端数据：$x = n - 1$）

**输入：**

```
2
10
1
11
1
```

**输出：**

```
01
11
```

**说明：** $x$ 取到最大值 $n - 1$ 时每个 $s_i$ 至多只有一个来源（$s_1$ 依赖 $w_n$，$s_n$ 依赖 $w_1$，中间的 $s_i$ 没有来源、必为 $0$），因此 $s_i = 1$ 必须靠唯一来源满足。
