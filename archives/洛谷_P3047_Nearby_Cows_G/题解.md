# 洛谷 P3047 Nearby Cows G

- **来源**：洛谷 P3047（USACO 2008 Dec Gold）
- **标签**：树形 DP、换根 DP
- **日期**：2026-07-02

## 一句话题目

给定一棵 $N$ 个点的树，每个点上有 $C_i$ 头奶牛，求每个点周围距离不超过 $K$ 的奶牛总数。

## 一句话题解

先用一次 DFS 计算以 1 为根时每棵子树内的贡献，再用一次 DFS 换根，把父亲方向的信息合并到每个点。

## 题目描述

Farmer John 有 $N$ 块田地，由 $N-1$ 条无向边连成一棵树。第 $i$ 块田初始有 $C_i$ 头奶牛。奶牛最多可以经过 $K$ 条边移动。对每块田 $i$，求可能到达它的奶牛数最大值 $M_i$，即树上距离 $i$ 不超过 $K$ 的所有点的 $C$ 之和。

### 输入格式

- 第 1 行：$N$ 和 $K$
- 第 2 行到第 $N$ 行：每条边的两个端点
- 第 $N+1$ 行到第 $2N$ 行：$C_1, C_2, \dots, C_N$

### 输出格式

- 输出 $N$ 行，第 $i$ 行输出 $M_i$

### 数据范围

- $1 \le N \le 100\,000$
- $1 \le K \le 20$
- $0 \le C_i \le 1000$

## 解法 1：换根 DP

### 思路

设 `f[u][j]` 表示距离点 $u$ 恰好为 $j$ 的奶牛数之和。

第一次 DFS（以 1 为根）计算每棵子树内的信息：

```
f[u][0] = C_u
f[u][j] = Σ f[v][j-1]   (v 是 u 的子节点)
```

第二次 DFS 换根：当把根从父亲 $fa$ 转移到儿子 $u$ 时，$u$ 需要获得 $fa$ 方向的信息。转移式为：

```
f'[u][j] = f[u][j] + f[fa][j-1] - f[u][j-2]
```

其中减去 `f[u][j-2]` 是为了去掉 $u$ 自己的子树对 `f[fa][j-1]` 的重复贡献。

最终答案：

```
M_u = Σ f[u][j]  (j = 0..K)
```

### 复杂度

- 时间：$O(NK)$
- 空间：$O(NK)$

### 代码

见 `correct_code_01.cpp`。

### 坑点

1. **输出要包含自身**：`std::accumulate(f[i], f[i] + 1 + m, 0)` 必须累加 `f[i][0]`，一开始写成 `f[i]+1` 漏掉了自己。
2. **换根时必须倒序**：循环 `for (int j = m; j >= 2; j--)`。若正序遍历，后面用到 `f[u][j-2]` 时，这个值已经被本轮修改过，会产生震荡的错误值，导致非根节点答案出错。在星形图上尤其明显。
3. **递归深度**：链状数据可能爆栈，建议注意栈空间或改用迭代。
