# 样例

## Sample 1（基本功能：1 个机器人）

**输入：**
```
3 1 1
1 2 1
1 3 1
```

**输出：**
```
3
```

**说明：** 路径 `1->2->1->3`，花费 3。

---

## Sample 2（2 个机器人）

**输入：**
```
3 1 2
1 2 1
1 3 1
```

**输出：**
```
2
```

**说明：** 机器人分别走 `1->2` 和 `1->3`，花费 2。

---

## 原始测试数据

**input.txt：**
```
3 1 1
1 2 1
1 3 1
3 1 2
1 2 1
1 3 1
```

**output.txt：**
```
3
2
```
