# HDU 4003 - Find Metal Mineral

- **来源**：HDU 4003
- **标签**：树形 DP、背包、树
- **日期**：2026-06-25

## 一句话题目

给定一棵带权树，k 个机器人从 S 出发遍历所有边，求最小总花费。

## 一句话题解

树形 DP：`f[u][j]` 表示 u 子树中放置 j 个机器人且最终停在子树内的最小费用；每条子边要么被走两次（无机器人停留），要么被走 k 次（k 个机器人停留）。

## 题目描述

给一棵 n 个节点的树，节点编号为 1~n，每条边都有一个花费值。有 k 个机器人从 S 点出发，问让机器人遍历所有边，最少花费值是多少？

**输入格式：** 多组数据测试。每组数据：
- 第一行输入 N, S, K 分别表示节点数、起点、可放置机器人数。
- 接下来 n-1 行，每行三个值 x, y, w，分别表示每条边的起点、终点、花费。

**输出格式：** 每组测试点输出最小的消耗量。

**数据范围：** $1 \le N \le 10000$，$1 \le S \le N$，$1 \le K \le 10$，$1 \le w \le 10000$

## 解法 1：树形 DP + 背包

### 思路

设 `f[u][j]` 表示以 `u` 为根的子树中，放置 `j` 个机器人，且这 `j` 个机器人最终停留在该子树内，遍历子树中所有边的最小费用。

对于 `u` 的每个子节点 `v`，边 `(u, v)` 的权值为 `w`：

- 如果 `v` 子树中分配 `k ≥ 1` 个机器人，则这些机器人会经过边 `(u, v)` 一次并停留在 `v` 子树内，边 `(u, v)` 的费用为 `k·w`。
- 如果 `v` 子树中分配 0 个机器人，则需要从 `u` 派人去 `v` 子树遍历并返回，边 `(u, v)` 的费用为 `2·w`。

转移方程：

```
f[u][j] = min over k {
    f[u][j-k] + f[v][k] + k·w   (k ≥ 1)
    f[u][j]   + f[v][0] + 2·w   (k = 0, 派人覆盖)
}
```

对每个子节点 `v` 做一次 0/1 背包合并。

### 复杂度

- 时间：$O(n \cdot m^2)$，$n \le 10000, m \le 10$，约 $10^6$ 次操作。
- 空间：`f[N][15]` 约 600 KB，邻接表约 20000 条边。

### 代码

见 `correct_code_01.cpp`。

### 坑点

1. **DP 转移遗漏基础费用**：原代码只把 `f[u][0]` 更新了"派人去子树再返回"的基础费用 `2·w`，却漏掉了 `f[u][j≥1]` 同样需要加上这笔费用。修复方式：对每个子节点，先默认加上 `f[v][0] + 2·w`，再尝试用 `k ≥ 1` 个机器人替代。

2. **I/O 未优化导致 TLE**：算法复杂度本身只有约 $10^6$ 操作，但 `std::cin` 未关闭同步时在大量输入下会被卡常。修复方式：在 `main()` 开头加上 `std::ios::sync_with_stdio(false); std::cin.tie(nullptr);`。

## 样例

### Sample 1（基本功能：1 个机器人）

**输入：**
```
3 1 1
1 2 1
1 3 1
```

**输出：**
```
3
```

**说明：** 路径 `1->2->1->3`，花费 3。

---

### Sample 2（2 个机器人）

**输入：**
```
3 1 2
1 2 1
1 3 1
```

**输出：**
```
2
```

**说明：** 机器人分别走 `1->2` 和 `1->3`，花费 2。
