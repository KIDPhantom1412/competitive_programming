# 坑点总结

1. **DP 转移遗漏基础费用**

   原代码只把 `f[u][0]` 更新了"派人去子树再返回"的基础费用 `2·w`，却漏掉了 `f[u][j≥1]` 同样需要加上这笔费用。

   这会导致 `f[u][j]` 在计算时未覆盖某些子树，得到错误的小值。

   修复方式：对每个子节点，先默认加上 `f[v][0] + 2·w`，再尝试用 `k ≥ 1` 个机器人替代。

2. **I/O 未优化导致 TLE**

   算法复杂度为 O(n·m²)，本身只有约 10^6 操作。但 `std::cin` 未关闭同步时，在大量输入下会被卡常。

   修复方式：在 `main()` 开头加上：

   ```cpp
   std::ios::sync_with_stdio(false);
   std::cin.tie(nullptr);
   ```
