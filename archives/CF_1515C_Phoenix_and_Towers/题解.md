# CF_1515C_Phoenix_and_Towers

- **来源**：[Codeforces 1515C — Phoenix and Towers](https://codeforces.com/problemset/problem/1515/C)，Codeforces Global Round 14
- **标签**：贪心、构造、优先队列（堆）
- **日期**：2026-10-29

## 一句话题目

把 $n$ 个高度不超过 $x$ 的块分成 $m$ 座非空塔，使任意两座塔的高度差不超过 $x$，输出每块所在的塔编号。

## 一句话题解

按输入顺序把每个块放到当前最矮的塔上（小根堆维护塔高），因为每块高度都不超过 $x$，两塔高差始终不超过 $x$，所以答案恒为 YES。

## 题目描述

Phoenix 有 $n$ 个高度为 $h_1, h_2, \dots, h_n$ 的块，且所有 $h_i$ 都不超过某个值 $x$。他要把全部 $n$ 个块堆成 $m$ 座塔，塔高为塔内块高之和。为了让塔看起来美观，任意两座塔的高度差不能严格大于 $x$。

请帮忙构造满足要求的 $m$ 座塔。每座塔至少含一个块，所有块都必须使用。

**输入格式：**

- 第一行一个整数 $t$（$1 \le t \le 1000$），表示测试组数。
- 每组第一行三个整数 $n, m, x$（$1 \le m \le n \le 10^5$，$1 \le x \le 10^4$）。
- 每组第二行 $n$ 个整数 $h_1, \dots, h_n$（$1 \le h_i \le x$）。
- 所有测试的 $n$ 之和不超过 $10^5$。

**输出格式：** 若无解输出 `NO`；否则输出 `YES`，再输出 $n$ 个整数 $y_1, \dots, y_n$，其中 $y_i \in [1, m]$ 表示第 $i$ 个块放在第 $y_i$ 座塔中。多解输出任意一个。

**数据范围与限制：** 时间 $2$ 秒，内存 $256$ MB。

## 解法 1：小根堆贪心

### 思路

**1. 无解的情况其实不存在。**

只需要一个任意简单策略让所有塔高差可控。注意到块高 $h_i \le x$ 这一条件非常强：它说明**任意单个块本身就在允许的差值范围内**。

**2. 贪心策略。**

用一个小根堆维护 $m$ 座塔的当前高度。处理顺序如下：

- 第 $1$ 到第 $m$ 块：分别放进第 $1$ 到第 $m$ 座塔（这样保证每座塔非空，且 $m \le n$ 保证不会越界）。
- 第 $m+1$ 到第 $n$ 块：取出当前**最矮**的塔，把这一块放上去，再把新高度压回堆中。

**3. 正确性证明：不变式「任意两塔高差 $\le x$」。**

初始时前 $m$ 块各占一塔，任两塔高差 $\le \max h_i - \min h_i \le x - 1 < x$，不变式成立。

设处理第 $i$ 块前不变式成立。取最矮塔高 $H_{\min}$，最高塔高 $H_{\max}$，有 $H_{\max} - H_{\min} \le x$。

- 新塔高 $H_{\min} + h_i \le H_{\min} + x \le H_{\max} + x$，所以新塔高不超过「旧最高 $+ x$」。
- 新塔高与原最小塔高之差为 $h_i \le x$。

因此放完后任意两塔高差仍 $\le x$，不变式保持。归纳完毕，且每座塔都至少接过一块（前 $m$ 块），块全部用完，故输出恒为 `YES`。

这个证明还说明了一件事：**任何时刻把块放在最矮塔上都不会失败**，所以题目无所谓「无解」，判 `NO` 的代码一定是想复杂了。

### 复杂度

- 时间：$O(n \log m)$，每块一次堆操作。
- 空间：$O(n + m)$，存块高、答案和堆。

### 坑点

**1. 手写 `operator<` 反转比较时必须严格。** 为了把 `priority_queue` 变成小根堆，常见写法是把比较反过来：

```cpp
bool operator<(const Node& ct) const { return height > ct.height; }
```

若顺手写成 `>=`，则 `a < a` 为真，违反了 `std::priority_queue` 要求的**严格弱序**，属于未定义行为：本机可能"看起来能跑"，但堆序会错乱（甚至提前 `pop` 到空堆），交上去可能 WA 或 RE。要么写严格 `>`，要么直接用 `priority_queue<pair<int,int>, vector<pair<int,int>>, greater<>>`。

**2. 必须保证每座塔非空。** 若直接把所有块都按「丢给最矮塔」处理而先不给每座塔垫底，高度为 $0$ 的塔会一直被选中，最后存在空塔，答案非法。所以前 $m$ 块必须一对一占位。$m \le n$ 保证这一步不会越界。

**3. 塔编号要在 $[1, m]$ 内。** 用块的下标当塔编号只在 $i \le m$ 时成立，处理剩余块时必须复用被弹出塔的编号，不能重新分配新编号。

**4. 多解无需与样例一致。** 输出任意合法方案即可，样例输出不必逐字节匹配；自测时应用校验脚本检查（塔非空、最大高差 $\le x$），而不是比对样例。

## 样例

### Sample 1（基本功能）

**输入：**

```
2
5 2 3
1 2 3 1 2
4 3 3
1 1 2 3
```

**输出：**

```
YES
1 1 1 2 2
YES
1 2 2 3
```

**说明：** 第一组两塔高 $1+2+3=6$ 与 $1+2=3$，差 $3 \le x=3$；第二组三塔高 $1, 1+2=3, 3$，最大差 $2 \le 3$。这是官方样例输出，贪心会得到另一组合法方案（如 `1 2 1 2 2` / `1 2 3 2`）。

---

### Sample 2（边界：$n = m = 1$）

**输入：**

```
1
1 1 1
1
```

**输出：**

```
YES
1
```

**说明：** 只有一座塔，任意两塔高差为 $0$，恒合法；用于检查数组上界和输出格式。

---

### Sample 3（边界：$m = n$ 与 $x = 1$ 全相等）

**输入：**

```
3
4 4 5
5 4 3 1
5 2 1
1 1 1 1 1
3 1 7
7 7 7
```

**输出：**

```
YES
1 2 3 4
YES
1 2 1 2 1
YES
1 1 1
```

**说明：** $m = n$ 时每块独占一塔（高差为 $5-1=4 \le 5$）；$x=1$ 时所有块高相等，贪心交替分配后两塔高为 $3$ 与 $2$，差恰为 $1$；$m=1$ 时全部堆进唯一一座塔。
