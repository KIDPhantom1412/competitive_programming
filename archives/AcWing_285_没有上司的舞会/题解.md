# AcWing_285_没有上司的舞会

- **来源**：AcWing 285
- **标签**：树形 DP
- **日期**：2026-07-15

## 一句话题目

在一棵有根树上选择一些点，使得任意相邻父子节点不能同时被选，最大化被选点的权值和。

## 一句话题解

树形 DP：对每个节点维护「选 / 不选」两种状态，自底向上合并子树答案。

## 题目描述

Ural 大学有 $N$ 名职员，编号为 $1 \sim N$。

他们的关系就像一棵以校长为根的树，父节点就是子节点的直接上司。

每个职员有一个快乐指数，用整数 $H_i$ 给出，其中 $1 \le i \le N$。

现在要召开一场周年庆宴会，不过，没有职员愿意和直接上司一起参会。

在满足这个条件的前提下，主办方希望邀请一部分职员参会，使得所有参会职员的快乐指数总和最大，求这个最大值。

**输入格式**

第一行一个整数 $N$。

接下来 $N$ 行，第 $i$ 行表示 $i$ 号职员的快乐指数 $H_i$。

接下来 $N-1$ 行，每行输入一对整数 $L, K$，表示 $K$ 是 $L$ 的直接上司。（注意一下，后一个数是前一个数的父节点，不要搞反）。

**输出格式**

输出最大的快乐指数。

**数据范围**

$1 \le N \le 6000$，
$-128 \le H_i \le 127$

## 解法 1：树形 DP

### 思路

把职员关系看作一棵树。由于上司不能和下属同时参会，每个节点只有「参加」或「不参加」两种状态。

设 $f[u][0]$ 表示不选 $u$ 时，以 $u$ 为根的子树能获得的最大快乐指数；
$f[u][1]$ 表示选 $u$ 时，以 $u$ 为根的子树能获得的最大快乐指数。

初始化：
- $f[u][0] = 0$
- $f[u][1] = H_u$

转移时枚举 $u$ 的每个子节点 $v$：
- 如果 $u$ 不选，则 $v$ 可选可不选，贡献 $\max(f[v][0], f[v][1])$。
- 如果 $u$ 选，则 $v$ 一定不选，贡献 $f[v][0]$。

最终答案为 $\max(f[root][0], f[root][1])$。

由于把树按无向图处理，并从任意节点（如 1）开始 DFS，用父节点参数避免回退，即可正确完成树形 DP。树的根选择不影响答案。

### 复杂度

- 时间：$O(N)$
- 空间：$O(N)$
