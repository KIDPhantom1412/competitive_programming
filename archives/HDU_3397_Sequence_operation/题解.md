## 一句话题目

维护一个长度为 n 的 01 序列，支持区间赋 0、区间赋 1、区间翻转、查询区间 1 的个数、查询区间最长连续 1 的长度。

## 一句话题解

用线段树同时维护 0/1 的前缀、后缀、最长连续段以及 1 的个数，用懒标记处理三种区间修改，查询最长连续段时返回区间长度并合并跨中点的连续段。

## 题目描述

给定一个只包含字符 `0` 和 `1` 的序列，长度为 n。

支持以下 5 种操作（`0 <= a <= b < n`）：

- `0 a b`：把 `[a, b]` 区间内所有字符变成 `0`
- `1 a b`：把 `[a, b]` 区间内所有字符变成 `1`
- `2 a b`：把 `[a, b]` 区间内所有字符翻转（`0` 变 `1`，`1` 变 `0`）
- `3 a b`：输出 `[a, b]` 区间内 `1` 的个数
- `4 a b`：输出 `[a, b]` 区间内最长连续 `1` 子串的长度

**输入格式：**

第一行一个整数 `T`（`T <= 10`），表示测试组数。

每组数据：

- 第一行两个整数 `n, m`（`1 <= n, m <= 100000`）
- 第二行 n 个字符（`0` 或 `1`，空格分隔），表示初始序列
- 接下来 m 行，每行一个操作 `op a b`

**输出格式：**

对于每个 `3` 或 `4` 操作，输出一行结果。

## 解法 1：线段树

### 思路

线段树的每个节点维护以下信息：

- `sum`：`1` 的个数
- `pre1 / suf1 / mx1`：区间内最长前缀连续 `1`、后缀连续 `1`、最长连续 `1` 子串
- `pre0 / suf0 / mx0`：对应的全 `0` 信息（翻转时需要）
- `op`：懒标记，`-1` 表示无标记，`0/1` 表示赋值为 `0/1`，`2` 表示翻转

`pushup` 时按常规线段树方式合并左右子树。

`pushTag` 时：

- 赋值 `0/1` 直接把节点全部置成对应状态；
- 翻转时交换 `0/1` 信息，并叠加或抵消懒标记。

`push` 时必须**先判断父节点是否有标记**，下传后清空父节点标记，否则会把 `-1` 当作赋值操作破坏整棵树。

查询最长连续 `1` 时，递归返回的 `Node` 必须带上区间长度 `len`，合并时根据 `left.pre == left.len` 和 `right.suf == right.len` 判断是否能跨中点延伸。

### 复杂度

- 时间：$O((n + m) \log n)$
- 空间：$O(n)$

### 代码

见 `correct_code_01.cpp`。

### 坑点

1. **`push` 没有判空标记**：原代码每次访问非完全覆盖节点都无条件下传 `tr[u].op`，当 `op == -1` 时会调用 `set(-1)`，导致整棵树被污染成负数。
2. **下标 0-based / 1-based 混用**：题目操作下标是 0-based，原代码按 1-based 建树，导致区间整体偏移。
3. **`queryMax` 合并没有带长度**：原代码只取 `max(left, right)`，漏掉了跨中点的 `left.suf + right.pre`；重写后必须记录返回区间的实际长度，才能正确合并前缀和后缀。
