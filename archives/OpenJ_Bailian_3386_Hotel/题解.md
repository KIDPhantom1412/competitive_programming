## 一句话题目

维护 N 个房间，支持入住（找最早连续 D 个空房并占用）和退房（清空连续 D 个房间），输出每次入住的起始房间号。

## 一句话题解

用线段树维护每个区间的最长连续空房段、左端最长空房前缀、右端最长空房后缀，支持区间清空/占用，查询时优先往左子树找。

## 题目描述

一家酒店有 N 个房间排成一排，编号 1 到 N。初始所有房间都空着。接下来处理 M 个请求：

- `1 D`：入住请求。需要找到最靠左的连续 D 个空房间并占用，输出起始房间编号 r。如果无法满足，输出 0。
- `2 X D`：退房请求。将房间 X 到 X+D-1 清空（这些房间可能已经有部分或全部是空的）。

### 输入格式

第一行两个整数 N、M。

接下来 M 行，每行一个请求：

- `1 D`：入住请求。
- `2 X D`：退房请求。

### 输出格式

对于每个入住请求，输出一行一个整数表示最靠左的起始房间号，无法满足输出 0。

### 数据范围

- 1 ≤ N ≤ 50,000
- 1 ≤ M < 50,000
- 1 ≤ D_i ≤ N
- 1 ≤ X_i ≤ N - D_i + 1

## 解法 1：线段树维护连续空房段

### 思路

线段树的每个节点维护三个值：

- `pre`：该区间左端开始的最长连续空房长度。
- `suf`：该区间右端结束的最长连续空房长度。
- `mx`：该区间内的最长连续空房长度。

另外用 `tag` 做懒标记，表示整个区间被统一置为空（1）或占用（0）。

合并两个子节点时：

- `pre`：若左子树全空，则 `pre = 左子树长度 + 右子树.pre`；否则为左子树.pre。
- `suf`：若右子树全空，则 `suf = 右子树长度 + 左子树.suf`；否则为右子树.suf。
- `mx`：取左右子树的 mx，以及左子树.suf + 右子树.pre 三者最大值。

入住查询时优先走左子树，再考虑跨中点的段，最后走右子树，保证找到最靠左的位置。

### 复杂度

- 时间：O(M log N)
- 空间：O(N)
