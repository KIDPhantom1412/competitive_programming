# CF_1506D_Epic_Transformation

- **来源**：Codeforces 1506D（Codeforces Round 710, Div. 3），难度 1400
- **标签**：贪心、构造、优先队列
- **日期**：2026-09-27

## 一句话题目

每次删掉两个不同的数，求数组最短能剩多长。

## 一句话题解

最大出现次数记为 $mx$。答案是 $\max(2mx - n,\ n \bmod 2)$：下界来自奇偶性，以及众数每次最多删掉一个；每次把当前出现次数最大的两个值各减 $1$，归纳可证这一步不改变该式，因此贪心做到下界。

## 题目描述

给定长度为 $n$ 的数组 $a$。可以执行任意次（含 $0$ 次）如下操作：选出两个**值不同**的元素，把它们都删掉。求操作之后数组长度的最小值。

**输入格式**：第一行一个整数 $t$（$1 \le t \le 10^4$）。每组数据第一行一个整数 $n$（$1 \le n \le 2 \cdot 10^5$），第二行 $n$ 个整数 $a_i$（$1 \le a_i \le 10^9$）。保证所有测试的 $n$ 之和不超过 $2 \cdot 10^5$。

**输出格式**：每组数据输出一行，为最短剩余长度。

## 解法 1：每次削减两个最大次数

### 思路

操作只看值是否相同，具体下标无关。把数组换成各值的出现次数 $f_1, f_2, \ldots, f_k$，总和为 $n$。一次操作就是选两个正的 $f_i, f_j$（$i \ne j$），各减 $1$。

还剩至少两个不同的值时，操作就能继续。因此结束时最多只剩一种值，剩余长度就是这个值剩下的个数；一种值都不剩时长度为 $0$。

设 $mx = \max f_i$。结论是

$$
ans = \max(2mx - n,\ n \bmod 2).
$$

下面先证这是下界，再证明「每次把当前最大的两个正次数各减 $1$」得到的长度恰好等于该式。

#### 下界

每次操作删掉 $2$ 个元素，剩余长度与 $n$ 同奇偶，所以

$$
ans \ge n \bmod 2.
$$

再看一个出现了 $mx$ 次的值 $v$。每次操作最多删掉一个 $v$，而且必须同时消耗一个不是 $v$ 的元素。不是 $v$ 的元素一共只有 $n - mx$ 个，所以 $v$ 至少剩下

$$
mx - (n - mx) = 2mx - n
$$

个（这个差为负时，下界改成 $0$）。于是 $ans \ge \max(0,\ 2mx - n)$。

$2mx$ 是偶数，故 $2mx - n \equiv n \pmod 2$。因此：

- $2mx - n \ge 0$ 时，它本身已经不小于 $n \bmod 2$，下界就是 $2mx - n$；
- $2mx - n < 0$ 时，起作用的是奇偶性，下界是 $n \bmod 2$。

两段合在一起就是 $ans \ge \max(2mx - n,\ n \bmod 2)$。

#### 上界：贪心保持该式

策略：只要至少还有两个正的出现次数，就把当前最大的两个各减 $1$。对 $n$ 归纳，证明这个策略结束时的剩余长度等于 $\max(2mx - n,\ n \bmod 2)$。

正次数不足两个时，这一步已经不能再做，这是归纳的基础情形，分两种：

- 一种值都不剩，剩余长度是 $0$，公式也是 $0$。
- 只剩一种值，不能再操作，剩余长度就是当前的 $n$。此时 $mx = n$，公式等于 $2n - n = n$。

否则执行一步，新的长度和最大次数记为 $n' = n - 2$、$mx'$。归纳假设在新实例上，策略的结果等于 $\max(2mx' - n',\ n' \bmod 2)$。由于 $n' \equiv n \pmod 2$，只要这一步不改变公式的值，即

$$
\max(2mx' - n',\ n \bmod 2) = \max(2mx - n,\ n \bmod 2),
$$

归纳就成立。

设操作前 $f_1 \ge f_2 \ge \cdots \ge f_k > 0$，操作把 $f_1$ 和 $f_2$ 各减 $1$。

**情形 A：** $f_1 > f_2$。减完之后最大次数是 $f_1 - 1$，其余次数原来都不超过 $f_2$，减过的 $f_2 - 1$ 更小，所以 $mx' = mx - 1$。代入得

$$
2mx' - n' = 2(mx - 1) - (n - 2) = 2mx - n.
$$

公式的值不变。

**情形 B：** $f_1 = f_2 = mx$。这时 $2mx > n$ 不可能出现，否则 $f_1 + f_2 > n$。所以原公式等于 $n \bmod 2$，需要证明新公式也是 $n \bmod 2$。

- 没有第三个数的次数等于 $mx$ 时，$mx' = mx - 1$，于是 $2mx' - n' = 2mx - n \le 0$。它不大于 $n \bmod 2$，新公式仍是 $n \bmod 2$。
- 至少三个数的次数都等于 $mx$ 时，$n \ge 3mx$，从而 $2mx - n \le -mx \le -1$，原公式确实是 $n \bmod 2$。新的最大次数仍是 $mx$，

$$
2mx' - n' = 2mx - n + 2 \le 2 - mx \le 1,
$$

并且 $2mx' - n' \equiv n \pmod 2$。$n$ 为偶数时，这个与 $n$ 同奇偶且不超过 $1$ 的数只能 $\le 0$，新公式为 $0$；$n$ 为奇数时，它是不超过 $1$ 的奇数，新公式为 $1$。两种子情形都等于 $n \bmod 2$。

因此每一步之后，公式的值都和操作前相同。过程每次让 $n$ 减少 $2$，必然会停。停下来时的剩余长度等于当时的公式，也就等于最初的 $\max(2mx - n,\ n \bmod 2)$。它达到了下界，所以最优。

同一个等式也说明不必真的模拟删数：数出 $mx$ 之后直接输出 $\max(2mx - n,\ n \bmod 2)$ 即可。下面的代码按上述策略用大根堆模拟，答案与该式相同。

### 复杂度

- 时间：$O(n \log n)$。哈希统计次数期望线性；堆上每次取两个最大值，操作次数是 $O(n)$。
- 空间：$O(n)$。

## 样例

### Sample 1（基本功能）

题目样例。五组分别对应：可以全部配对清空、两个不同值清空、两个相同值无法操作、众数压过其余元素后剩 $1$、三种值各出现两次后清空。

**输入：**

```
5
6
1 6 1 1 4 4
2
1 2
2
1 1
5
4 5 4 5 4
6
2 3 2 1 3 1
```

**输出：**

```
0
0
2
1
0
```

**说明：** 第四组次数为 $3, 2$，$mx = 3$，$2mx - n = 1$。第五组每个值都出现 $2$ 次，$2mx - n = -2$，由奇偶性得到 $0$。

---

### Sample 2（边界）

$n = 1$ 时无法操作；全部元素相同时 $mx = n$，答案就是 $n$。

**输入：**

```
2
1
7
4
3 3 3 3
```

**输出：**

```
1
4
```

**说明：** 第一组 $\max(2 \cdot 1 - 1,\ 1 \bmod 2) = 1$；第二组 $\max(2 \cdot 4 - 4,\ 0) = 4$。
