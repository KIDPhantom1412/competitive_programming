# CF_161D_Distance_in_Tree

- **日期**：2026-11-11

## 一句话题目

给定一棵 $n$ 个点的树和正整数 $k$，求距离恰好为 $k$ 的无序点对数量。

## 一句话题解

以任意点为根做树形 DP，用 $f[u][d]$ 记录子树中到 $u$ 距离为 $d$ 的点数；合并儿子时先按距离配成 $k$，再把儿子的点数并入父亲。

## 题目描述

树是不含环的连通图。两点距离是它们之间最短路径的边数。

给定 $n$ 个点的树和正整数 $k$，求距离恰好为 $k$ 的不同点对个数。$(v, u)$ 与 $(u, v)$ 视为同一对。

**输入格式**：第一行两个整数 $n, k$（$1 \le n \le 50000$，$1 \le k \le 500$）。接下来 $n - 1$ 行，每行两个整数 $a_i, b_i$（$1 \le a_i, b_i \le n$，$a_i \ne b_i$），表示一条边。所有边互不相同。

**输出格式**：输出一个整数，表示距离恰好为 $k$ 的点对数。

**限制**：时限 3 秒，内存 512 MB。

## 解法 1：树形 DP

### 思路

把点 $1$ 当作根。设 $f[u][d]$ 为 $u$ 的子树中到 $u$ 距离恰好为 $d$ 的点数，只保留 $0 \le d \le k$。$f[u][0] = 1$，表示 $u$ 自己。

每对距离恰好为 $k$ 的点都有唯一的最近公共祖先。在这个祖先处、把较晚访问的那棵子树并进来时统计一次，每对就恰好被计入一次。子树内部的点对在递归儿子时已经计过。

处理儿子 $v$ 时，先用 $u$ 上已经合并好的部分与 $v$ 的子树配对。$v$ 子树中到 $v$ 距离为 $i - 1$ 的点，到 $u$ 的距离是 $i$，它和 $u$ 当前子树中到 $u$ 距离为 $k - i$ 的点组成距离为 $k$ 的点对：

$$
res \leftarrow res + \sum_{i=1}^{k} f[u][k - i] \cdot f[v][i - 1]
$$

$i = k$ 时配对的是 $f[u][0]$，也就是点 $u$ 自己，对应一个端点就是 $u$ 的点对。

配对结束后，再把 $v$ 并入 $u$：

$$
f[u][i + 1] \leftarrow f[u][i + 1] + f[v][i] \quad (0 \le i < k)
$$

两步的顺序不能对调。若先更新 $f[u]$，$v$ 子树里的点会进入 $f[u]$，接着和自己配对，把同一子树内部、最近公共祖先更低的点对再算一遍。

两个因子分别来自 $u$ 上已经合并的点和 $v$ 的子树，两者点集不相交，乘积不超过 $\lfloor n / 2 \rfloor \cdot \lceil n / 2 \rceil$。答案不超过 $\binom{n}{2}$。在本题范围内两者都落在 $32$ 位有符号整数里；代码仍用 $64$ 位整数累加答案。

### 复杂度

- 时间：$O(nk)$。每条边在合并时扫描一遍长度 $k$ 的距离数组。
- 空间：$O(nk)$。$f$ 是 $(n + 1) \times (k + 1)$ 的表。

## 样例

### Sample 1（基本功能）

**输入：**

```
5 2
1 2
2 3
3 4
2 5
```

**输出：**

```
4
```

**说明：** 树为 $1-2-3-4$，且 $2$ 连着 $5$。距离为 $2$ 的点对是 $(1, 3)$、$(1, 5)$、$(3, 5)$、$(2, 4)$。

---

### Sample 2（边界：链）

**输入：**

```
5 3
1 2
2 3
3 4
4 5
```

**输出：**

```
2
```

**说明：** 五个点连成一条链，距离恰好为 $3$ 的点对只有 $(1, 4)$ 和 $(2, 5)$。
