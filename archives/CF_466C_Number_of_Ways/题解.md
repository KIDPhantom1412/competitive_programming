# CF_466C_Number_of_Ways

- **来源**：Codeforces 466C（Codeforces Round 266 (Div. 2)），难度 1700
- **标签**：前缀和、双指针、组合计数
- **日期**：2026-10-20

## 一句话题目

统计有多少种方式把数组切成三段非空连续段，使三段元素和相等。

## 一句话题解

总和不能被 $3$ 整除则无解。否则令 $T = S / 3$，从左到右扫前缀，遇到前缀和等于 $2T$ 时，累加它左边已经出现过的「前缀和等于 $T$」的切点数。

## 题目描述

给定长度为 $n$ 的整数数组 $a_1, a_2, \ldots, a_n$。统计满足下面条件的下标对 $(i, j)$ 的个数（$2 \le i \le j \le n - 1$）：

$$
\sum_{k=1}^{i-1} a_k = \sum_{k=i}^{j} a_k = \sum_{k=j+1}^{n} a_k.
$$

三段都必须非空，所以第一段至少占位置 $1$，第三段至少占位置 $n$。

**输入格式**：第一行一个整数 $n$（$1 \le n \le 5 \cdot 10^5$）。第二行 $n$ 个整数 $a_1, a_2, \ldots, a_n$（$|a_i| \le 10^9$）。

**输出格式**：输出一行一个整数，表示方案数。

## 解法 1：前缀和顺序计数

### 思路

记 $S$ 为数组总和，$P_r = a_1 + \cdots + a_r$。若 $S$ 不能被 $3$ 整除，答案是 $0$。否则每段目标和都是 $T = S / 3$。

下标对和前缀的对应关系是：第一段右端点 $L = i - 1$，第二段右端点 $R = j$。约束 $2 \le i \le j \le n - 1$ 等价于

$$
1 \le L < R \le n - 1, \quad P_L = T, \quad P_R = 2T.
$$

$L < R$ 是严格的：两刀不能落在同一个前缀上。从左到右维护「已经出现过的 $P_L = T$ 的位置数」$\mathrm{cnt}$。扫到位置 $R$ 时，若 $R < n$ 且 $P_R = 2T$，则左边每个合法的 $L$ 都能和它配成一组，答案加上 $\mathrm{cnt}$。$\mathrm{cnt}$ 必须在这次累加之后再更新，否则 $T = 0$ 时同一个位置会既当 $L$ 又当 $R$。

$S = 0$ 时 $T = 2T = 0$，上面的扫描仍然正确，代码里单独写成组合数只是等价写法。此时 $P_n = 0$ 一定成立，位置 $n$ 不能当切点，先把它丢掉，再在剩余的前缀 $0$ 位置里任取两个：

$$
ans = \binom{k}{2} = \frac{k(k-1)}{2},
$$

其中 $k$ 是 $1 \le r \le n - 1$ 中 $P_r = 0$ 的个数。实现上 $\mathrm{cnt}$ 从 $-1$ 开始，把位置 $n$ 也数进去，刚好抵消掉末位。

$|S| \le 5 \cdot 10^{14}$，前缀和与答案都要用 64 位整数。答案最坏大约是 $O(n^2)$，不超过 $10^{11}$ 量级。

### 复杂度

- 时间：$O(n)$
- 空间：$O(n)$

见 `correct_code_01.cpp`。

### 坑点

错把「前缀等于 $T$ 的个数」和「前缀等于 $2T$ 的个数」直接相乘。这样会把 $2T$ 出现在 $T$ 左边的非法配对也算进去。

反例 $2, -1, 1, 1$：$S = 3$，$T = 1$，前缀是 $2, 1, 2, 3$。$T$ 出现 $1$ 次，$2T$ 出现 $2$ 次，直接相乘得到 $2$；合法切点只有 $(L, R) = (2, 3)$，答案是 $1$。提交在 test 24 上就是这个顺序错误。

另外两条容易一起写错：

- 第三段必须非空，$R = n$ 不能计。$T \ne 0$ 时 $P_n = 3T$，既不等于 $T$ 也不等于 $2T$，末位不会被误计；但 $T = 0$ 时末位一定是 $0$，必须显式丢掉。
- 同一个位置不能既当 $L$ 又当 $R$。$T = 0$ 时 $T = 2T$，必须先用旧的 $\mathrm{cnt}$ 累加答案，再把当前位置计入 $\mathrm{cnt}$。

## 样例

### Sample 1（基本功能）

题目样例。$S = 9$，$T = 3$，前缀 $1, 3, 6, 6, 9$。$L = 2$ 配 $R = 3$ 或 $R = 4$，两种切法都合法。

**输入：**

```
5
1 2 3 0 3
```

**输出：**

```
2
```

**说明：** 切分是 $[1, 2] \mid [3] \mid [0, 3]$ 和 $[1, 2] \mid [3, 0] \mid [3]$。

---

### Sample 2（边界：总和为 0）

题目样例。$S = 0$，前缀 $0, 1, 0, 0$。位置 $4$ 是末位，丢掉后只剩位置 $1, 3$，只能取一组。

**输入：**

```
4
0 1 -1 0
```

**输出：**

```
1
```

**说明：** 唯一方案是 $[0] \mid [1, -1] \mid [0]$。

---

### Sample 3（边界：$n < 3$）

题目样例。长度不足 $3$，三段不可能都非空。

**输入：**

```
2
4 1
```

**输出：**

```
0
```

**说明：** 直接输出 $0$。

---

### Sample 4（坑点：$2T$ 出现在 $T$ 左边）

$S = 3$，$T = 1$，前缀 $2, 1, 2, 3$。位置 $1$ 的前缀是 $2T$，但它左边没有 $T$ 切点。

**输入：**

```
4
2 -1 1 1
```

**输出：**

```
1
```

**说明：** 只有 $(L, R) = (2, 3)$。若把两类前缀个数相乘会得到 $2$。

---

### Sample 5（边界：总和为负）

$S = -3$，$T = -1$，前缀 $-2, -1, -2, -3$。和 Sample 4 对称，负数整除不影响 $S \bmod 3$ 的判断。

**输入：**

```
4
-2 1 -1 -1
```

**输出：**

```
1
```

**说明：** 唯一方案是 $[-2, 1] \mid [-1] \mid [-1]$。
