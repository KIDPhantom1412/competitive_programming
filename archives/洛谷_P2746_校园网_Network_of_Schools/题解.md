# 洛谷_P2746_校园网_Network_of_Schools

- **来源**：洛谷 P2746 [IOI 1996 / USACO5.3] 校园网 Network of Schools
- **标签**：图论、SCC、Tarjan、缩点
- **日期**：2026-11-22

## 一句话题目

给定 $N$ 个学校之间的单向软件分享关系，求①至少给几所学校下发软件能使所有学校都获得；②至少添加几条分享关系，才能给任意一所学校下发一次软件就使所有学校获得。

## 一句话题解

Tarjan 求强连通分量后缩点成 DAG；答案 1 为入度为 $0$ 的 SCC 个数，答案 2 为 $\max(\text{入度}0\text{个数},\ \text{出度}0\text{个数})$，整图本身强连通时答案 2 为 $0$。

## 题目描述

有一些学校会向其他学校分享软件，即如果这个学校得到了软件，那么在分享列表中的学校也会得到软件。注意这种关系是单向的，即如果 $a$ 在 $b$ 的列表中，那么 $b$ 不一定在 $a$ 的列表中。

现在，你需要向其中一些学校下发新软件。为了节约下发软件的成本，你需要回答以下两个问题。

1. 至少需要向几个学校下发新软件，可以使得所有学校均获得新软件。
2. 定义一次扩展为在某个学校的分享列表中增加一个学校。至少需要进行几次扩展，才可以使得无论对哪个学校**仅下发一次软件**就可以使得所有学校获得新软件。

两个问题相互独立。

**输入格式**：第一行一个正整数 $N$，表示学校数目，编号 $1$ 到 $N$。接下来 $N$ 行，每行一个分享列表，第 $i+1$ 行为学校 $i$ 的分享列表中的学校编号，每个列表用 $0$ 结束，空列表只用一个 $0$ 表示。

**输出格式**：两行，第一行输出问题 1 的解，第二行输出问题 2 的解。

**数据范围**：$2 \le N \le 100$。

## 解法 1：Tarjan 缩点（SCC）

### 思路

把"分享关系"看成有向边，得到有向图。同一个强连通分量（SCC）内的学校互相可达：给其中任意一所下发软件，整个 SCC 都能获得；反过来，要让一个 SCC 获得软件，只需给它的任意一所学校下发。因此把每个 SCC 缩成一个点，得到的缩点图是 DAG。

**问题 1**：缩点后，入度为 $0$ 的 SCC 没有其他 SCC 能把软件传给它，必须直接下发；其余 SCC 都能从某个入度为 $0$ 的 SCC 沿 DAG 到达。所以答案 1 就是入度为 $0$ 的 SCC 个数：

$$
ans_1 = |\{S \mid \mathrm{in}(S) = 0\}|
$$

**问题 2**：要使"给任意一所学校下发一次即可让所有学校获得"，等价于整张图强连通，即缩点后的 DAG 强连通。给一个入度为 $0$ 的 SCC 加入边、给一个出度为 $0$ 的 SCC 加出边，一条新边可以同时解决一个"源"和一个"汇"。设入度为 $0$ 的 SCC 个数为 $x$、出度为 $0$ 的个数为 $y$：

- 若整图本来强连通（缩点后只有 $1$ 个 SCC，此时 $x = y = 1$），答案是 $0$；
- 否则把 $x$ 个源和 $y$ 个汇配对连边（多余的连成环状），最少加边数为：

$$
ans_2 = \max(x,\ y)
$$

具体构造：将源和汇各自排成环配对连边，每条边消去一个源和一个汇，故下界为 $\max(x,y)$ 且可达。

统计缩点图入/出度时注意：**同一 SCC 内部的边不计**，且重边不影响入/出度是否为 $0$ 的判断，无需去重。

### 复杂度

- 时间：$O(N + M)$
- 空间：$O(N + M)$

### 代码

见 `correct_code_01.cpp`。

### 坑点

1. **问题 2 的公式写错**：初版误写成 $x + y - 1$。当 $x = 1$ 时 $x + y - 1 = y = \max(x, y)$ 恰好相等，官方样例正好是这种情况，侥幸通过；但 $x \ge 2$ 且 $y \ge 2$ 时就会多算（如 $N=2$ 无边的图：$x=y=2$，$x+y-1=3$，正确答案是 $2$）。正确公式是 $\max(x, y)$。
2. **整图强连通时要特判输出 $0$**：此时 $x = y = 1$，$\max(x,y)=1$，但不需要任何扩展，答案为 $0$。不能直接套公式。

## 样例

### Sample 1（基本功能）

**输入：**
```
5
2 4 3 0
4 5 0
0
0
1 0
```

**输出：**
```
1
2
```

**说明：** SCC 为 $\{1,2,4,5\}$ 与 $\{3\}$，前者入度为 $0$ 故答案 1 为 $1$；后者是唯一出度为 $0$ 的 SCC，$x=1,y=2$，答案 2 为 $\max(1,2)=2$。

---

### Sample 2（坑点：问题 2 公式误用 $x+y-1$）

**输入：**
```
2
0
0
```

**输出：**
```
2
2
```

**说明：** 两所学校互不可达，$x=y=2$。问题 1 需要给两所学校各下发一次；问题 2 加两条边 $1 \to 2$、$2 \to 1$ 即可，答案是 $\max(2,2)=2$，而不是 $x+y-1=3$。

---

### Sample 3（边界：整图强连通）

**输入：**
```
3
2 0
3 0
1 0
```

**输出：**
```
1
0
```

**说明：** 整个图是一个 SCC，给任意一所学校下发即可（答案 1 为 $1$），且无需任何扩展（答案 2 为 $0$，需特判）。
