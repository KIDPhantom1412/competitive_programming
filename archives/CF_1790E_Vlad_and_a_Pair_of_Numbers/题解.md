# CF_1790E_Vlad_and_a_Pair_of_Numbers

- **来源**：Codeforces 1790E（Codeforces Round 847, Div. 3），难度 1400
- **标签**：位运算、构造
- **日期**：2026-11-10

## 一句话题目

给定 $x$，求正整数 $a$、$b$，使 $a \oplus b = (a + b) / 2 = x$，或判断无解。

## 一句话题解

由 $a + b = (a \oplus b) + 2(a \& b)$ 得 $a \& b = x / 2$。$x$ 必须为偶数，且 $x$ 与 $x / 2$ 没有公共的 $1$ 位；把 $x / 2$ 的位同时赋给 $a$ 和 $b$，把 $x$ 的位只赋给 $a$。

## 题目描述

Vlad 有两个正整数 $a$、$b$（$a, b > 0$），满足

$$
a \oplus b = \frac{a + b}{2},
$$

其中 $\oplus$ 是按位异或，除法精确整除、不做舍入。他只记住了 $x = a \oplus b$，要求任意一对满足条件的 $a$、$b$，或判断不存在。

**输入格式**：第一行一个整数 $t$（$1 \le t \le 10^4$），表示测试组数。每组一行一个整数 $x$（$1 \le x \le 2^{29}$）。

**输出格式**：对每组数据输出一行。若存在合法的 $a$、$b$（$0 < a, b \le 2^{32}$），输出任意一对；否则输出 $-1$。

## 解法 1：按位拆开与和异或

### 思路

恒等式 $a + b = (a \oplus b) + 2(a \& b)$：异或记下两边不同的位，与记下两边都为 $1$ 的位，后者在加法里会进位，所以要乘 $2$。

题目要求 $(a + b) / 2 = a \oplus b = x$，因此 $a + b = 2x$。代入恒等式：

$$
x + 2(a \& b) = 2x \implies a \& b = \frac{x}{2}.
$$

于是有两个必要条件：

1. $x$ 必须是偶数，否则 $x / 2$ 不是整数。
2. $a \& b$ 与 $a \oplus b$ 不能在同一位上同时为 $1$。也就是 $(x / 2) \& x = 0$，即 $x$ 的二进制里没有相邻的两个 $1$。

两个条件一起也是充分的。构造：

- $x / 2$ 里为 $1$ 的位，在 $a$ 和 $b$ 里都置 $1$；
- $x$ 里为 $1$ 的位，只在 $a$ 里置 $1$。

这样 $a \oplus b = x$、$a \& b = x / 2$，从而 $(a + b) / 2 = x$。$x \ge 2$ 且为偶数时 $b = x / 2 \ge 1$，$a = x \mid (x / 2) \ge x \ge 2$。异或的那些位放在 $b$ 上同样合法，所以答案不唯一。

代码按位实现同一件事，并在冲突时直接输出 $-1$：

1. 先把 $x \gg 1$ 的每一位同时写入 $a$ 和 $b$。
2. 再看 $x$ 的每一位。这一位是 $1$ 时，它必须属于异或；若 $a$ 或 $b$ 上已经有这一位，说明它和 $x / 2$ 冲突，无解，否则只写入 $a$。这一位是 $0$ 时，$a$ 和 $b$ 在这一位上必须相同。
3. 若 $a + b$ 是奇数，无解。奇数 $x$ 的最低位只会进 $a$，和的奇偶性正好被这里抓住。

$x \le 2^{29}$，最高用到第 $29$ 位（从 $0$ 计），循环到 $30$ 即可。$a + b = 2x \le 2^{30}$，在 $32$ 位有符号整数里不会溢出。

## 样例

### Sample 1（基本功能）

题目样例。$x = 5$ 是奇数，$x = 6 = 110_2$ 有相邻的 $1$，都无解。其余四组答案不唯一，题面给出的是另一组合法构造。

**输入：**

```
6
2
5
10
6
18
36
```

**输出：**

```
3 1
-1
13 7
-1
25 11
50 22
```

**说明**：按「$x / 2$ 的位两边都放、$x$ 的位只放在 $a$」构造，四组有解的数据会得到 $3\ 1$、$15\ 5$、$27\ 9$、$54\ 18$。以 $x = 10$ 为例，$10 = 1010_2$，$5 = 0101_2$，两者没有公共的 $1$ 位，故 $a = 1111_2 = 15$、$b = 0101_2 = 5$，$15 \oplus 5 = 10$，$(15 + 5) / 2 = 10$。题面的 $13$ 和 $7$ 只是把异或位分到了另一侧。

### Sample 2（边界）

最小的奇数、以及上界 $x = 2^{29}$。

**输入：**

```
2
1
536870912
```

**输出：**

```
-1
805306368 268435456
```

**说明**：$x = 1$ 是奇数，无解。$x = 2^{29}$ 只有第 $29$ 位为 $1$，$x / 2 = 2^{28}$，两者不冲突，构造得到 $a = 2^{29} + 2^{28} = 805306368$、$b = 2^{28} = 268435456$。
