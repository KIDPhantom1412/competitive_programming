## 一句话题目

构造一个长度为 $N$、元素和为 $S$ 的正整数数组，并选一个整数 $K$（$0 \le K \le S$），使得任何非空子数组的和都不等于 $K$ 也不等于 $S-K$；判断 Petya 能否做到。

## 一句话题解

$S \ge 2N$ 时 Petya 必胜：取 $N-1$ 个 $2$ 和一个 $S-2(N-1)$，$K = 1$；$S < 2N$ 时必败，因为前缀和除以 $S$ 的余数只有 $N$ 个，其中必有两个相差 $K$（鸽笼原理）。

## 题目描述

Petya 和 Vasya 在玩一个游戏。游戏开始时，Petya 需要构造一个长度为 $N$ 的正整数数组，所有元素之和等于 $S$。然后 Petya 选择一个整数 $K$，满足 $0 \le K \le S$。

如果 Vasya 能在数组中找到一个非空子数组，使其元素和恰好等于 $K$ 或 $S-K$，则 Vasya 获胜；否则 Vasya 失败，Petya 获胜。

给定 $N$ 和 $S$，判断 Petya 是否有必胜策略（双方都最优）。若能，输出一种方案。

**输入格式**：一行两个整数 $N$ 和 $S$（$1 \le N \le S \le 10^6$）。

**输出格式**：若 Petya 能获胜，第一行输出 `YES`，第二行输出任意一个满足条件的数组（$N$ 个正整数，和为 $S$），第三行输出 $K$；否则输出 `NO`。字母大小写均可，答案不唯一。

## 解法 1：构造 + 鸽笼原理判定

### 思路

**第一步：把子数组和变成前缀和之差。**

设前缀和 $p_i = a_1 + a_2 + \cdots + a_i$，并记 $p_0 = 0$。由于元素都是正整数，前缀和严格递增：

$$
0 = p_0 < p_1 < \cdots < p_N = S
$$

子数组 $a_{l} + \cdots + a_{r}$ 的和恰好等于 $p_{r} - p_{l-1}$。所以：

> Vasya 获胜 $\iff$ 存在两个下标 $x < y$，使 $p_y - p_x = K$ 或 $p_y - p_x = S - K$。

**第二步：证明 $S < 2N$ 时 Petya 必败。**

先注意两个边界值：整个数组的和就是 $S$，所以 $K = 0$ 时 Vasya 取整个数组（和为 $S - K = S$）获胜，$K = S$ 时同样获胜。因此 Petya 只会考虑 $0 < K < S$，以下均设 $0 < K < S$。

关键观察：把所有等式放到「除以 $S$ 的余数」里看。

- $p_y - p_x = K$ 就是 $p_y - p_x \equiv K \pmod S$；
- $p_y - p_x = S - K$ 等价于 $p_x - p_y = K - S \equiv K \pmod S$。

也就是说，两种情况可以统一成一句话：

> Vasya 获胜 $\iff$ 存在两个前缀和 $p_x, p_y$，它们除以 $S$ 的余数相差 $K$（模 $S$ 意义下）。

现在做一次鸽笼原理。$N+1$ 个前缀和 $p_0, p_1, \ldots, p_N$ 除以 $S$ 的余数：

- $p_0 = 0$ 与 $p_N = S$ 的余数都是 $0$，是同一个；
- 中间的 $p_1, \ldots, p_{N-1}$ 都在 $0$ 和 $S$ 之间，两两不同且余数非零。

所以余数集合 $R$ **恰好有 $N$ 个不同的元素**。

假设 Petya 想赢，即 Vasya 找不到这样的两个前缀和。那么对 $R$ 中每个余数 $r$，$r + K \pmod S$ 不能再出现在 $R$ 中（否则这两个余数差恰为 $K$，Vasya 获胜）。这意味着 $R$ 与 $R + K = \{r + K \bmod S \mid r \in R\}$ 是两个**不相交**的集合，而它们各有 $N$ 个元素，共 $2N$ 个元素，全部落在模 $S$ 的 $S$ 个余数中，因此必须有

$$
2N \le S
$$

换句话说，只要 $S < 2N$，$R$ 与 $R + K$ 就必然相交，Vasya 总能找到和为 $K$ 或 $S-K$ 的子数组。Petya 无论怎么构造、怎么选 $K$ 都会输，故输出 `NO`。

**第三步：$S \ge 2N$ 时的必胜构造。**

取数组

$$
\underbrace{2,\ 2,\ \ldots,\ 2}_{N-1 \text{ 个}},\ S - 2(N-1)
$$

并取 $K = 1$。由 $S \ge 2N$ 知 $S - 2(N-1) \ge 2$，所有元素都是正整数，且和为 $S$。验证 Vasya 无路可走：

- **任何非空子数组的和都 $\ge 2$**（每个元素 $\ge 2$），所以和为 $K = 1$ 的子数组不存在；
- **任何真子数组**（不是整个数组）至少漏掉一个元素，而漏掉的元素 $\ge 2$，故其和 $\le S - 2 < S - 1$；整个数组的和是 $S \ne S - 1$。所以和为 $S - K = S - 1$ 的子数组也不存在。

因此 $S \ge 2N$ 时输出 `YES`、上述数组和 $K = 1$ 即可。

### 复杂度

- 时间：$O(N)$
- 空间：$O(1)$

### 代码

见 `correct_code_01.cpp`。

### 坑点

- 边界是 $S \ge 2N$ 而不是 $S > 2N$：$S = 2N$ 恰好可构造（全部取 $2$，$K = 1$）。
- 最后一个元素是 $S - 2(N-1)$（只对前 $N-1$ 个乘 $2$），不要写成 $S - 2N$，否则总和不是 $S$。
- $N = 1$ 时数组只有一个元素 $S$，$K = 1$ 依然成立（$S \ge 2$ 时取到 $S$，和 $1$、$S-1$ 都不可达）。

## 样例

### Sample 1（基本功能）

**输入：**
```
1 4
```

**输出：**
```
YES
4
2
```

**说明：** 数组只有一个元素 $4$，子数组和只有 $4$；$K = 2$ 时 $K$ 和 $S-K = 2$ 都取不到。答案不唯一，本代码输出 $K = 1$，同样正确。

---

### Sample 2（边界）

**输入：**
```
3 4
```

**输出：**
```
NO
```

**说明：** $S = 4 < 2N = 6$，由鸽笼原理 Petya 必败。

---

### Sample 3（基本功能）

**输入：**
```
3 8
```

**输出：**
```
YES
2 1 5
4
```

**说明：** 子数组和为 $\{1, 2, 3, 5, 6, 8\}$，$K = 4$ 时 $4$ 和 $4$ 都取不到。官方答案如此；本代码输出 `2 2 4` 和 $K = 1$，同样正确。

---

### Sample 4（边界：$S = 2N$ 恰好成立）

**输入：**
```
2 4
```

**输出：**
```
YES
2 2
1
```

**说明：** $S = 2N$ 时仍可构造：全部取 $2$，子数组和为 $\{2, 4\}$，$K = 1$ 与 $S-K = 3$ 都取不到。

---

### Sample 5（极端数据）

**输入：**
```
1 1000000
```

**输出：**
```
YES
1000000
1
```

**说明：** $N = 1$ 的极端情况，子数组和只有 $10^6$，$K = 1$ 时 $1$ 与 $999999$ 都取不到。
