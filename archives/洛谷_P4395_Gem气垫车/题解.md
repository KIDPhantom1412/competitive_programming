## 一句话题目

给一棵树，为每个节点分配一个正整数权值，相邻节点权值不同，求最小总权值。

## 一句话题解

树形 DP：设 `f[u][j]` 表示节点 `u` 取颜色 `j` 时子树 `u` 的最小总代价，子节点转移时取与 `u` 颜色不同的最小值。

## 题目描述

给出一棵树，要求为树上的结点标上权值，权值可以是任意的正整数。

唯一的限制条件是相邻的两个结点不能标上相同的权值，要求一种方案，使得整棵树的总价值最小。

### 输入格式

先给出一个数字 $N$ 代表树上有 $N$ 个点，$N \le 10000$。

下面 $N-1$ 行，代表两个结点 $u,v(1\le u,v\le N)$ 相连。

### 输出格式

最小的总权值。

### 数据范围

$N \le 10000$。

## 解法 1：树形 DP

### 思路

设 `f[u][j]` 表示以 `u` 为根的子树中，节点 `u` 被染成颜色 `j` 时的最小总权值。

状态转移：对于 `u` 的每个子节点 `v`，由于相邻节点颜色不同，`v` 不能取颜色 `j`，因此从 `v` 的其余颜色中取最小值：

```
f[u][j] += min(f[v][k])  (k != j)
```

初始化：`f[u][j] = j`，即只包含 `u` 自己时，权值为 `j`。

颜色上界：

在任意最优染色中，若节点 `u` 的颜色为 `c`，则对任意 `k < c`，`u` 至少有一个邻居颜色为 `k`；否则把 `u` 直接改染成 `k` 就能让总权值更小，矛盾。因此最优染色满足类似 Grundy 染色的性质。

对节点 `u` 的颜色 `c` 做归纳：

- `c = 1`：`u` 所在子树至少 1 个节点。
- `c > 1`：`u` 有颜色分别为 `1, 2, ..., c-1` 的 `c-1` 个不同邻居，这些邻居对应子树互不相交，且按归纳假设分别至少包含 `1, 2, 4, ..., 2^{c-2}` 个节点。于是 `u` 的子树至少包含

```
1 + 1 + 2 + 4 + ... + 2^{c-2} = 2^{c-1}
```

个节点。设 `x` 为整棵树在最优染色中可能出现的最大颜色值，则 `2^{x-1} \le n`；而颜色 `x+1` 至少需要 `2^x` 个节点，因此 `n < 2^x`。于是得到

```text
2^{x-1} \le n < 2^x
```

解得 `x = floor(log2 n) + 1 \le ceil(log2 n) + 1`。

代码取 `m = ceil(log2 N) + 1`（当 $N \le 10000$ 时 `m <= 15`），足够覆盖最优解。

最终答案：`min(f[root][j])`，其中 `j` 取遍 `[1, m]`。

### 复杂度

- 时间：$O(N \cdot m^2)$，其中 $m = \lceil \log_2 N \rceil + 1 \le 15$，约为 $O(N \log^2 N)$。
- 空间：$O(N \cdot m)$。

## 样例

### Sample 1（基本功能）

**输入：**
```
10
7 5
1 2
1 7
8 9
4 1
9 7
5 6
10 2
9 3
```

**输出：**
```
14
```

**说明：** 输出为 $14$。该样例中按树形 DP 计算可得此最小总权值。

### Sample 2（边界）

**输入：**
```
1
```

**输出：**
```
1
```

**说明：** 只有一个节点时，直接赋权值 1 即可。

---

### Sample 3（颜色上界说明）

**输入：**
```
10
1 2
1 3
1 4
1 5
1 6
2 7
2 8
2 9
2 10
```

**输出：**
```
13
```

**说明：** 若把节点 1、2 染成 1、2，则两簇叶子分别为 2、1，总权值 15；但若把节点 2 升到颜色 3，它的 4 片叶子都能降为 1，总权值降为 $2+3+4\times1+4\times1 = 13$。可见最优解不一定只用两种颜色。
