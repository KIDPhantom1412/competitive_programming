## 一句话题目

给定 $k$，白色花只能以连续 $k$ 朵为一组出现，求吃掉花数在 $[a, b]$ 之间的合法红白序列方案数之和，对 $10^9+7$ 取模，多组询问。

## 一句话题解

令 $f[i]$ 为长度为 $i$ 的方案数，$f[i] = f[i-1] + f[i-k]$（末尾放 1 朵红花或 1 组白花），预处理前缀和后 $O(1)$ 回答每个询问。

## 题目描述

Marmot 晚餐吃红白两种花，一顿晚餐可以表示为一个由若干朵花组成的序列，其中一些是白色、一些是红色。

为了让晚餐美味，有一个规则：Marmot 只以大小为 $k$ 的组吃白花，即每段连续白花的长度必须是 $k$ 的倍数（可看作若干个长度为 $k$ 的白花组首尾相接），红花不受限制。

现在 Marmot 想知道吃掉花数在 $a$ 到 $b$ 之间有多少种方案。方案数可能很大，对 $1000000007$（$10^9+7$）取模。

**输入格式**

第一行两个整数 $t$ 和 $k$（$1 \le t, k \le 10^5$），$t$ 表示询问数。

接下来 $t$ 行，每行两个整数 $a_i$、$b_i$（$1 \le a_i \le b_i \le 10^5$），描述第 $i$ 个询问。

**输出格式**

输出 $t$ 行，第 $i$ 行为吃掉花数在 $a_i$ 到 $b_i$ 之间的方案数，对 $10^9+7$ 取模。

## 解法 1：线性递推 + 前缀和

### 思路

令 $f[i]$ 表示恰好吃 $i$ 朵花的合法序列数。考虑序列最后一段：

- 末尾是 1 朵红花：去掉它后是长度 $i-1$ 的合法序列，贡献 $f[i-1]$；
- 末尾是 1 组白花（连续 $k$ 朵）：去掉它后是长度 $i-k$ 的合法序列，贡献 $f[i-k]$。

于是有递推式：

$$
f[i] = f[i-1] + f[i-k] \quad (i \ge k)
$$

边界：$f[0] = 1$（空序列），且 $1 \le i < k$ 时白花无法成组，只有全红一种方案，即 $f[i] = 1$。

每个询问 $[a, b]$ 的答案为 $\sum_{i=a}^{b} f[i]$，对 $f$ 求前缀和 $ps$ 后即可 $O(1)$ 回答：

$$
ans = ps[b] - ps[a-1]
$$

注意减法结果可能为负，取模时需先加 $MOD$ 再取模。

### 复杂度

- 时间：$O(\max\{b\} + t)$
- 空间：$O(\max\{b\})$

## 样例

### Sample 1（基本功能）

**输入：**
```
3 2
1 3
2 3
4 4
```

**输出：**
```
6
5
5
```

**说明：** $k = 2$ 时 $f[1..4] = 1, 2, 3, 5$，$[1,3]$ 为 $1+2+3=6$，$[2,3]$ 为 $2+3=5$，$[4,4]$ 为 $f[4]=5$。

---

### Sample 2（边界：$k$ 大于询问区间）

**输入：**
```
1 5
1 4
```

**输出：**
```
4
```

**说明：** $k = 5$ 时长度 $1$ 到 $4$ 的白花均无法成组，每个长度只有全红 $1$ 种方案，答案为 $1+1+1+1=4$。
