# HDU_4630_No_Pain_No_Game

- **来源**：HDU 4630
- **标签**：树状数组、离线处理、数论、GCD
- **日期**：2026-08-02

## 一句话题目

给定 1~n 的排列与多组区间询问，求区间内任意两数最大 gcd。

## 一句话题解

离线按左端点从右往左扫描，对每个因子记录其最近出现位置，并用树状数组维护前缀最大值，从而快速回答每个询问。

## 题目描述

Life is a game, and you lose it, so you suicide.
But you can not kill yourself before you solve this problem.

Given a sequence of numbers a1, a2, ..., an, which are a permutation of 1..n.

You need to answer some queries, each with the following format:
If we choose two numbers a, b (shouldn't be the same) from interval [l, r], what is the maximum gcd(a, b)? If there's no way to choose two distinct numbers (l = r), then the answer is zero.

### Input

First line contains T (T <= 5), the number of test cases.

For each test case:

- First line: n (1 <= n <= 50000).
- Second line: n numbers a1, a2, ..., an.
- Third line: Q (1 <= Q <= 50000), the number of queries.
- Then Q lines follow, each contains two integers l, r (1 <= l <= r <= n).

### Output

For each test case, for each query print the answer in one line.

### 数据范围

- T <= 5
- 1 <= n, Q <= 50000
- a 是 1..n 的排列

## 解法 1：离线扫描 + 树状数组

### 思路

对于任意区间 [l, r]，答案就是区间内所有数两两 gcd 的最大值。

关键观察：最大 gcd 一定等于某个 d，使得区间 [l, r] 中至少有两个数都是 d 的倍数。因此，只需要找到满足该条件的最大 d 即可。

离线处理询问：

1. 把所有询问按左端点 l 从大到小排序。
2. 从右向左扫描位置 i（1 <= i <= n）。
3. 对每个因子 d，维护 `st[d]` 表示在 i 右侧（包括当前扫描到的位置）A 是 d 的倍数的最近下标。
4. 当扫描到位置 i 时，枚举 A[i] 的所有因子 d：
   - 如果 `st[d]` 存在，说明数对 (i, st[d]) 都是 d 的倍数，在树状数组的位置 `st[d]` 上更新最大值 d。
   - 然后令 `st[d] = i`。
5. 当扫描到某个询问的左端点 i 时，用树状数组查询 [1, r] 的最大值，即为该询问的答案。

树状数组中保存的是“左端点位置 -> 以该位置为左端点、右端点不超过当前扫描位置的所有数对的最大 gcd”。查询 `query(r)` 即可得到 [l, r] 区间内所有满足条件的数对的最大 gcd。

### 复杂度

- 时间：O(T * (n * sqrt(n) + (n + m) * log n))，其中 n, m <= 50000
- 空间：O(n + m)

### 代码

见 `correct_code_01.cpp`。

### 坑点

- **更新位置要写 `st[d]` 而不是 `i`**：最初错误地把当前扫描位置 i 作为更新位置，导致只统计了以 i 为右端点的数对，遗漏了左端点大于 i 的数对，输出全部变为 0。修正后改为 `update(st[d], d)`。
- **离线顺序**：先更新树状数组，再处理左端点为 i 的询问。
- **平方因子**：当 k == A[i] / k 时，避免重复更新同一个因子。
- **多组测试用例**：每次 `solve` 前清空树状数组和 `st` 数组。
