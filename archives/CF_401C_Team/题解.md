## 一句话题目

用 $n$ 个 $0$ 和 $m$ 个 $1$ 排成一行，使序列中不出现相邻的 $0$，也不出现连续三个 $1$；做不到则输出 $-1$。

## 一句话题解

$n > m + 1$ 或 $m > 2(n + 1)$ 时无解；否则 $0$ 比 $1$ 多时先放 `01`，$1$ 明显更多时放 `110`，其余放 `10`。

## 题目描述

有 $n$ 张写着 $0$ 的卡片和 $m$ 张写着 $1$ 的卡片。把它们排成一行，要求：

- 不能有两张相邻的 $0$；
- 不能有三张连续的 $1$。

若存在合法排列，输出任意一种（字符之间不加空格）；否则输出 $-1$。

**输入格式**：一行两个整数 $n, m$（$1 \le n, m \le 10^6$）。

**输出格式**：一行，为合法的 $01$ 串，或 $-1$。

## 解法 1：贪心构造

### 思路

$m$ 个 $1$ 最多隔出 $m + 1$ 个空位，每个空位最多放 $1$ 个 $0$，所以 $n \le m + 1$。$n$ 个 $0$ 最多隔出 $n + 1$ 个空位，每个空位最多放 $2$ 个 $1$，所以 $m \le 2(n + 1)$。任一条件不成立就无解。

有解时按下面的顺序拼接，直到两种卡片都用完：

- 只剩 $1$：直接接上。此时最多还剩 $2$ 个，而且前一段以 $0$ 结尾，不会形成 `111`。
- 只剩 $0$：直接接上。有解时这里最多还剩 $1$ 个，而且它前面是 $1$。
- $n > m$：有解时只能是 $n = m + 1$，多出来的那个 $0$ 必须先放。每次放 `01`。
- $m \le 2n$：放 `10`。剩下的 $1$ 仍能被剩下的 $0$ 隔开。
- 否则：放 `110`，先消耗多出来的 $1$。

### 复杂度

- 时间：$O(n + m)$
- 空间：$O(n + m)$

### 代码

见 `correct_code_01.cpp`。

### 坑点

可行性判断本身是对的，四个官方样例也都能给出合法串。样例里要么 $n < m$，要么直接无解，没有 $n = m + 1$。

错误出在 $n > m$ 时仍走 `10`。因为此时 $m \le n$ 成立，循环会先放下 $m$ 段 `10`，最后只剩 $1$ 个 $0$，再接到串尾。`10` 以 $0$ 结尾，这个 $0$ 接上去就变成 `00`。

例如 $n = 2$、$m = 1$ 会得到 `100`，合法答案是 `010`。

错误分支：

```cpp
} else if (m <= n || (m <= n * 2)) {
    res += "10";
    n--;
    m--;
}
```

修复：在这个分支之前，当 $n > m$ 时改为放 `01`。放完后多出来的那个 $0$ 前面是 $1$。

## 样例

### Sample 1（基本功能）

**输入：**

```
1 2
```

**输出：**

```
101
```

**说明：** 一个 $0$ 放在两个 $1$ 中间。

---

### Sample 2（基本功能）

**输入：**

```
4 10
```

**输出：**

```
11011011011011
```

**说明：** $1$ 较多，主体是 `110`，末尾再补两个 $1$。合法串不唯一。

---

### Sample 3（边界）

**输入：**

```
1 5
```

**输出：**

```
-1
```

**说明：** 一个 $0$ 最多隔开 $4$ 个 $1$（`11011`），$5$ 个 $1$ 必然出现 `111`。

---

### Sample 4（坑点：$n = m + 1$）

**输入：**

```
2 1
```

**输出：**

```
010
```

**说明：** $0$ 比 $1$ 多一个，必须先放 $0$。若先放 `10` 再补最后一个 $0$，会得到非法的 `100`。
