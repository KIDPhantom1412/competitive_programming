# CF_1108D_Diverse_Garland

- **来源**：Codeforces 1108D（Codeforces Round 535, Div. 3），难度 1400
- **标签**：构造、DP、贪心
- **日期**：2026-11-29

## 一句话题目

给定由 `R`/`G`/`B` 组成的长为 $n$ 的灯串，重新染色最少的灯，使得任意相邻两灯颜色不同，输出最少染色次数和任意一种方案。

## 一句话题解

把串划分为极长同色连续段，长度为 $L$ 的段恰好需要 $\lfloor L/2 \rfloor$ 次染色：从段内第 $2$ 个位置起每隔一个染一个，改成与左右邻居都不同的颜色；下界由 $\lfloor L/2 \rfloor$ 对互不相交的同色相邻对给出。

## 题目描述

有 $n$ 盏灯排成一排，第 $i$ 盏灯的颜色是 $s_i$（`R`、`G`、`B` 之一）。可以给若干盏灯重新染色（改为另一种颜色），要求染完后的灯串 $t$ 是 **diverse** 的：任意相邻两盏灯颜色不同，即对每个 $1 \le i \le n - 1$ 都满足 $t_i \ne t_{i+1}$。

在所有把原灯串染成 diverse 的方案中，选重新染色盏数最少的一个；若有多个最优方案，任取其一。

**输入格式**：第一行一个整数 $n$（$1 \le n \le 2 \cdot 10^5$）。第二行一个长度为 $n$ 的字符串 $s$，只含 `R`、`G`、`B`。

**输出格式**：第一行输出一个整数 $r$——最少重新染色次数。第二行输出一个长度为 $n$ 的 diverse 灯串 $t$。

## 解法 1：贪心（连续段内隔位染色）

### 思路

把 $s$ 划分成极长的相同字符连续段（下称「段」）。相邻灯颜色冲突只发生在段内部；相邻两段的边界处本来就是不同色的。

**下界。** 对长度为 $L$ 的段，取其中互不相交的相邻位置对 $(1,2),\ (3,4),\ \ldots$，共 $\lfloor L/2 \rfloor$ 对（位置按段内相对偏移编号）。每对的两盏灯原本同色，最终必须异色，所以每对至少有一盏被染色。不同对、不同段之间的位置都不相交，因此总染色次数至少为所有段的 $\lfloor L/2 \rfloor$ 之和。

**构造（达到下界）。** 对每个长度为 $L$ 的段，把段内相对段首偏移为 $1, 3, 5, \ldots$ 的位置各染一次（即从第 $2$ 个位置起每隔一个染一个），恰好 $\lfloor L/2 \rfloor$ 个位置。每个位置染成与左右邻居都不同的颜色（三种颜色里总能找到）：

- 被染位置的左右邻居都是偏移为偶数、未被染色的位置，保持段原色 $c_0$。若被染位置不是段尾，左右都是 $c_0$，任取 $\ne c_0$ 的颜色即可。
- 若被染位置恰好是段尾且段后还有字符（下一段的段首，颜色 $c_1 \ne c_0$），则需要同时避开 $c_0$ 和 $c_1$，三种颜色中恰好剩下唯一的一种可用。

染色后，段内每对相邻位置都至少有一个被染过，且染的颜色 $\ne c_0$，故段内相邻全部异色；段尾被染时也避开了下一段的段首颜色，边界同样异色。总染色数恰好是各段 $\lfloor L/2 \rfloor$ 之和，达到下界，因此最优。

### 复杂度

- 时间：$O(n)$。每个位置至多被访问常数次。
- 空间：$O(n)$。

## 样例

### Sample 1（基本功能）

**输入：**

```
9
RBGRRBRGG
```

**输出：**

```
2
RBGRGBRGR
```

**说明：** 题目样例。两个长度为 $2$ 的段各染 $1$ 个位置（1-based：第 $5$ 位 `R→G`、第 $9$ 位 `G→R`）即达到最小值 $2$。

---

### Sample 2（基本功能）

**输入：**

```
8
BBBGBRRR
```

**输出：**

```
2
BRBGBRGR
```

**说明：** 题目样例。两个长度为 $3$ 的段各染中间 $1$ 个位置（第 $2$ 位 `B→R`、第 $7$ 位 `R→G`）。存在多种最优方案，任取其一即可。

---

### Sample 3（边界）

**输入：**

```
1
R
```

**输出：**

```
0
R
```

**说明：** $n = 1$ 时没有相邻对，无需染色。

---

### Sample 4（极端数据）

**输入：**

```
5
GGGGG
```

**输出：**

```
2
GRGRG
```

**说明：** 整串是单个长度为 $5$ 的段，需要 $\lfloor 5/2 \rfloor = 2$ 次染色；隔位染色后为 `GRGRG`。
