## 一句话题目

统计有多少种下标排列，能使重排后的序列在每个分割点上前缀按位与都等于后缀按位与，答案对 $10^9 + 7$ 取模。

## 一句话题解

设全体元素的按位与为 $s$。合法排列当且仅当首尾都放值等于 $s$ 的元素，答案是 $\mathrm{cnt}(\mathrm{cnt} - 1)(n - 2)! \bmod (10^9 + 7)$，其中 $\mathrm{cnt}$ 是值等于 $s$ 的元素个数。

## 题目描述

给定长度为 $n$（$n \ge 2$）的非负整数序列 $a_1, a_2, \ldots, a_n$。若对每个 $i$（$1 \le i \le n - 1$）都有

$$
a_1 \& a_2 \& \cdots \& a_i = a_{i + 1} \& a_{i + 2} \& \cdots \& a_n,
$$

则称这个序列是好的，其中 $\&$ 是按位与。

求有多少个 $1$ 到 $n$ 的排列 $p$，使得 $a_{p_1}, a_{p_2}, \ldots, a_{p_n}$ 是好序列。排列按位置区分，相同数值的不同下标算不同方案。答案对 $10^9 + 7$ 取模。

**输入格式**：第一行一个整数 $t$（$1 \le t \le 10^4$），表示测试组数。每组第一行一个整数 $n$（$2 \le n \le 2 \cdot 10^5$），第二行 $n$ 个整数 $a_1, a_2, \ldots, a_n$（$0 \le a_i \le 10^9$）。保证所有测试的 $n$ 之和不超过 $2 \cdot 10^5$。

**输出格式**：输出 $t$ 行，第 $i$ 行是第 $i$ 组的好排列数对 $10^9 + 7$ 取模的结果。

## 解法 1：全局与固定首尾

### 思路

令 $s = a_1 \& a_2 \& \cdots \& a_n$。$s$ 里为 $1$ 的每一位，在每个 $a_i$ 里都是 $1$，所以任意非空子集的按位与都包含 $s$ 的全部 $1$ 位。

先看必要性。取 $i = 1$，条件是

$$
a_{p_1} = a_{p_2} \& \cdots \& a_{p_n}.
$$

右边再与 $a_{p_1}$ 与起来就是全体元素的与 $s$，而右边已经等于 $a_{p_1}$，所以 $a_{p_1} = s$。对称地，取 $i = n - 1$ 得到 $a_{p_n} = s$。因此值等于 $s$ 的元素必须至少有两个，否则答案是 $0$。

再看充分性。若 $a_{p_1} = a_{p_n} = s$，则任意前缀都含有 $a_{p_1} = s$，前缀与等于 $s$；任意后缀都含有 $a_{p_n} = s$，后缀与也等于 $s$。每个分割点两侧都等于 $s$，序列一定是好的。中间元素不需要再满足额外的与条件。

于是只是在选位置：第一个位置有 $\mathrm{cnt}$ 种选择，最后一个位置在剩下的等于 $s$ 的元素里有 $\mathrm{cnt} - 1$ 种选择，中间 $n - 2$ 个位置任意排列。即

$$
ans = \mathrm{cnt} \times (\mathrm{cnt} - 1) \times (n - 2)! \pmod{10^9 + 7}.
$$

$\mathrm{cnt} < 2$ 时这个式子自然为 $0$。阶乘对 $10^9 + 7$ 预处理。$\mathrm{cnt} \le 2 \cdot 10^5$，先算 $\mathrm{cnt}(\mathrm{cnt} - 1)$ 再取模，用 64 位整数不会溢出。

### 复杂度

- 时间：$O(N + \sum n)$，其中 $N = 2 \cdot 10^5$ 是阶乘预处理上界
- 空间：$O(N)$

## 样例

### Sample 1（基本功能）

题目样例。四组分别对应：全部相等、全局与没有对应元素、恰好三个 $0$、恰好两个等于全局与的元素。

**输入：**

```
4
3
1 1 1
5
1 2 3 4 5
5
0 2 0 3 0
4
1 3 5 1
```

**输出：**

```
6
0
36
4
```

**说明：** 第一组 $s = 1$、$\mathrm{cnt} = 3$，答案 $3 \times 2 \times 1! = 6$。第二组 $s = 0$、$\mathrm{cnt} = 0$，答案为 $0$。第三组 $s = 0$、$\mathrm{cnt} = 3$，答案 $3 \times 2 \times 3! = 36$。第四组 $s = 1$、$\mathrm{cnt} = 2$，答案 $2 \times 1 \times 2! = 4$。

---

### Sample 2（边界）

$n = 2$ 时中间为空，$(n - 2)! = 1$。两个元素相等才有好排列，且两种顺序都合法。

**输入：**

```
2
2
1 1
2
1 2
```

**输出：**

```
2
0
```

**说明：** 第一组 $s = 1$、$\mathrm{cnt} = 2$，答案 $2 \times 1 \times 0! = 2$。第二组 $s = 0$，序列里没有 $0$。
