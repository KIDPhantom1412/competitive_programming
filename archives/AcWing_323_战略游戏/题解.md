## 一句话题目

在树上放置最少数量的士兵，使得每条边至少被一个端点上的士兵观察到。

## 一句话题解

树形 DP：每个节点分「放置士兵」和「不放置士兵」两种状态，不放置时所有子节点必须放置士兵。

## 题目描述

城市的道路构成一棵树。每个节点上的士兵可以观察到所有与该点相连的边。要求在节点上放置最少数量的士兵，使得他们能够观察到所有的边。

### 输入格式

输入包含多组测试数据，每组描述一棵树。

- 第一行：整数 `N`，表示节点数。
- 接下来 `N` 行，每行格式为：`u:(m) v1 v2 ...`，表示节点 `u` 有 `m` 个子节点 `v1, v2, ...`。

节点编号从 `0` 到 `N-1`，每个节点的子节点数不超过 10。

### 输出格式

对于每组测试数据，输出一行，表示最少需要的士兵数。

### 数据范围

`0 < N ≤ 1500`

一个测试点所有 `N` 之和不超过 `300650`。

## 解法 1：树形 DP

### 思路

把无根树以 `0` 为根做 DFS，设：

- `f[u][0]`：节点 `u` 不放置士兵时，以 `u` 为根的子树所需的最少士兵数。
- `f[u][1]`：节点 `u` 放置士兵时，以 `u` 为根的子树所需的最少士兵数。

转移：

- 若 `u` 不放置士兵，则 `u` 到每个子节点的边必须被子节点覆盖，因此每个子节点都必须放置士兵：
  `f[u][0] = Σ f[v][1]`
- 若 `u` 放置士兵，则子节点可选可不选：
  `f[u][1] = 1 + Σ min(f[v][0], f[v][1])`

最终答案为 `min(f[0][0], f[0][1])`。

### 复杂度

- 时间：O(N)
- 空间：O(N)

### 代码

见 `correct_code_01.cpp`。

### 坑点

1. **输入格式特殊**：每行是 `u:(m) v1 v2 ...`，不能按普通整数读入，要解析冒号和括号。
2. **节点输入顺序不固定**：样例中先给出节点 `3` 的信息，所以建边时要用读入的 `u`，不能直接用循环变量 `i`。
3. **不要混用 `scanf` 和 `cin`**：在 `sync_with_stdio(false)` 后混用会导致读取顺序混乱，引发 Segmentation Fault。
4. **原始错误代码**（`main.cpp.orig`）：第一次用 `std::cin >> t >> t` 试图读入节点编号和子节点数，结果第二个 `t` 解析失败，未初始化导致 `while (t--)` 循环失控，数组越界。

## 样例

### Sample 1（基本功能）

**输入：**

```
4
0:(1) 1
1:(2) 2 3
2:(0)
3:(0)
```

**输出：**

```
1
```

**说明：** 在节点 1 放置一名士兵即可覆盖全部边。

---

### Sample 2（输入顺序不固定）

**输入：**

```
5
3:(3) 1 4 2
1:(1) 0
2:(0)
0:(0)
4:(0)
```

**输出：**

```
2
```

**说明：** 节点编号不是按 0~N-1 顺序给出，建边时必须使用读入的节点编号。
