## 一句话题目

给定一棵 $n$ 个点的树，选恰好 $k$ 个点，使得每个节点都至少有一个相邻节点被选中，求方案数对 $10^9+7$ 取模。

## 一句话题解

树形 DP，设 `f[u][j][s][c]` 表示 $u$ 的子树用了 $j$ 个设备，$s$ 表示 $u$ 是否放置设备，$c$ 表示 $u$ 是否被某个子节点覆盖。按 $u$ 是否放置设备分类子节点的合法状态，做树上背包合并。

## 题目描述

外星人的母舰可以看成是一棵 $n$ 个节点、 $n-1$ 条边的无向树。在节点 $u$ 上安装监听设备，可以监听与 $u$ 直接相邻的所有节点。设备不能监听自己所在的节点。

$\text{JYY}$ 的特工携带了 $k$ 个监听设备，要在树上放置这些设备，要求母舰上所有节点的通信都被监听。每个节点至多安装一个设备，且设备必须被用完。

求不同的放置方案数，答案对 $1,000,000,007$ 取模。

**输入格式：**
- 第一行两个整数 $n,k$；
- 接下来 $n-1$ 行，每行两个整数 $u,v$ 表示一条边。

**输出格式：**
- 一行，表示方案数。

**数据范围：**
- $1 \le n \le 10^5$
- $1 \le k \le \min(n, 100)$

## 解法 1：树形 DP

### 思路

状态定义：

```
f[u][j][s][c]
  u：当前节点
  j：子树 u 中使用了 j 个设备
  s = 0/1：u 是否放置设备
  c = 0/1：u 是否被某个子节点覆盖
```

根节点没有父节点，因此根必须被自己的子节点覆盖。最终答案取：

```cpp
f[1][k][0][1] + f[1][k][1][1]
```

对每个子节点 $v$ 做树上背包合并：

- **若 $u$ 不选**：$v$ 必须被 $v$ 自己的子节点覆盖，只能取 `f[v][*][0][1]`、`f[v][*][1][1]`；
- **若 $u$ 选**：$v$ 被 $u$ 覆盖，可取 `f[v][*][*][0]`、`f[v][*][*][1]`。

初始化：

- `f[u][0][0][0] = 1`：$u$ 不选，还没被覆盖；
- `f[u][1][1][0] = 1`：$u$ 选，用掉 1 个设备，还没被自己的子节点覆盖。

$k=0$ 的特殊处理：当当前子节点贡献 $0$ 个设备时：

- $u$ 不选：该子节点不可能被覆盖（没设备、父节点也不覆盖），所以 `f[u][j][0][*]` 全部置 $0$；
- $u$ 选：该子节点被 $u$ 覆盖，若子节点是叶子则合法，乘以 `f[v][0][0][0] + f[v][0][0][1]`。

每合并完一个子节点后，把 `f[u][0][0][0]` 清 $0$：若 $u$ 有子节点且 $u$ 不选，$0$ 个设备无法覆盖这些子节点。但叶子节点没有走这个循环，`f[u][0][0][0] = 1` 仍然保留，表示叶子等待父节点覆盖。

### 复杂度

- 时间：$O(n \cdot k)$（实际有效复杂度，树上背包受子树大小限制）
- 空间：$O(n \cdot k)$

见 `correct_code_01.cpp`。

### 坑点

1. `f` 数组第二维至少要开 $101$，不能按样例只开 $15$。$k$ 最大为 $100$。
2. 遍历邻接表时取点是 `E[i].v`，不是 `E[i].n`（后者是 next 指针）。
3. 必须初始化 `f[u][1][1][0] = 1`，否则根本选不中点。
4. $k=0$ 分支不能直接加旧值，否则合并多个子节点时会重复计数；也不能简单保留旧值，因为子节点 $0$ 设备时可能非法。
5. $u$ 不选和 $u$ 选时，子节点可取的合法状态不同，必须分开处理。
6. 最终答案要相加后取模，不能用 `max`。
7. 注意 `f[u][0][0][0]` 在合并子节点后要清 $0$，否则会把“$u$ 不选、$0$ 设备、没被子节点覆盖”的非法状态继续上传。

## 样例

### Sample 1（基本功能）

**输入：**
```
5 3
1 2
2 3
3 4
4 5
```

**输出：**
```
1
```

**说明：** 唯一合法方案是在节点 $2,3,4$ 放置设备。

---

### Sample 2（边界：n=2, k=2）

**输入：**
```
2 2
1 2
```

**输出：**
```
1
```

**说明：** 两个点都放设备，互相覆盖。

---

### Sample 3（边界：n=2, k=1）

**输入：**
```
2 1
1 2
```

**输出：**
```
0
```

**说明：** 只放一个设备时，放设备那个点自身不会被覆盖，所以非法。

---

### Sample 4（坑点：星形树）

**输入：**
```
5 2
1 2
1 3
1 4
1 5
```

**输出：**
```
4
```

**说明：** 必须选中心点 $1$ 覆盖所有叶子，再从 $4$ 个叶子中选 $1$ 个覆盖中心点，共 $4$ 种方案。
