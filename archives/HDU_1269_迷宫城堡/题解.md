# HDU_1269_迷宫城堡

- **来源**：HDU 1269，HDU 2006-4 Programming Contest，作者 Gordon

- **日期**：2026-11-16

## 一句话题目

判断有向图中任意两个房间是否都互相可达。

## 一句话题解

整张图强连通，当且仅当强连通分量个数为 $1$。用 Kosaraju 做两遍 DFS，分量数为 $1$ 输出 `Yes`，否则输出 `No`。
用 Tarjan 一遍 DFS 维护 $dfn$ 和 $low$，以栈弹出每个分量。分量数为 $1$ 输出 `Yes`，否则输出 `No`。

## 题目描述

城堡里有 $N$ 个房间、$M$ 条单向通道（$N \le 10000$，$M \le 100000$）。通道从 $A$ 通向 $B$，并不表示能从 $B$ 回到 $A$。房间编号为 $1$ 到 $N$。

问：是否对任意房间 $i, j$，都存在从 $i$ 到 $j$ 的路径，也存在从 $j$ 到 $i$ 的路径。

**输入格式：** 多组数据。每组第一行两个整数 $N, M$，接下来 $M$ 行，每行两个整数 $a, b$，表示一条从 $a$ 到 $b$ 的通道。输入以一行 `0 0` 结束。

**输出格式：** 每组数据一行。任意两房间互相可达则输出 `Yes`，否则输出 `No`。

**数据范围与限制：** $N \le 10000$，$M \le 100000$。时间限制 $1000$ ms，内存限制 $32768$ KB。

## 解法 1：Kosaraju 求强连通分量

### 思路

「任意两点互相可达」就是整张有向图强连通。强连通分量是极大的互相可达点集，把每个分量缩成一点后，得到的是有向无环图。

- 分量个数为 $1$：所有点都在同一个分量里，任意两点互相可达。
- 分量个数大于 $1$：缩点后的图不是强连通的，总存在一对点不能互相到达。

因此只需要判断强连通分量个数是否为 $1$。用 Kosaraju：

1. 在原图上 DFS。一个点的所有后继都访问完、即将返回时，把它记入结束序。结束越晚的点越靠后。
2. 清空访问标记。按结束序的逆序，在反图上 DFS。每次从一个尚未访问的点出发，走出的就是一个强连通分量。

反图把所有边反向。原图里能互相到达的点，在反图里仍然互相到达，所以分量本身不变。逆序启动保证：当前起点所在分量，在缩点图里没有指向还没处理的分量的边；反图上从它出发，走不到别的分量。

多组数据之间要清空两条邻接表、访问标记和结束序。原图和反图可以共用一条边池：每读入一条通道 $a \to b$，就在原图加 $a \to b$，在反图加 $b \to a$。

$N = 1$ 时没有需要互相到达的不同房间，分量数为 $1$，答案是 `Yes`。没有通道、且 $N > 1$ 时每个房间单独成一个分量，答案是 `No`。

### 复杂度

- 时间：$O(N + M)$，两遍 DFS。
- 空间：$O(N + M)$，原图、反图和结束序。

## 解法 2：Tarjan 求强连通分量

### 思路

判断条件与解法 1 相同：强连通分量个数为 $1$。Tarjan 用一次 DFS 同时完成访问和划分分量。

每个点 $u$ 记录两个值：

- $dfn_u$：第一次访问 $u$ 的时间戳。
- $low_u$：$u$ 及其子树经过最多一条指向栈中点的边，能回到的最小 $dfn$。

访问 $u$ 时令 $dfn_u = low_u = ++ts$，并把 $u$ 压栈。接着处理出边 $u \to v$：

- $v$ 尚未访问：递归 $v$，返回后 $low_u = \min(low_u, low_v)$。
- $v$ 已访问且仍在栈中：这是返祖边，或指向栈中点的横叉边，$low_u = \min(low_u, dfn_v)$。
- $v$ 已经属于某个弹完的分量：忽略。缩点之后这条边指向别的分量，不能用来更新 $low$。

$low_u = dfn_u$ 时，$u$ 是当前分量的根。从栈顶一直弹到 $u$，弹出来的点组成一个强连通分量。代码不另开「在栈中」数组：$scc_v = 0$ 表示 $v$ 还没归入任何分量，也就是仍在栈上。

图不连通时，对每个 $dfn$ 仍为 $0$ 的点再启动一次 DFS。最后分量数为 $1$ 输出 `Yes`，否则输出 `No`。

多组数据之间用 `assign` 重建邻接表，并把 $dfn$、$low$、$scc$ 全部置 $0$，同时换成空栈。

### 复杂度

- 时间：$O(N + M)$，每个点和每条边各访问一次。
- 空间：$O(N + M)$，邻接表、三个标记数组和栈。

### 代码

见 `correct_code_02.cpp`。

### 坑点

1. **访问时必须入栈。** 只写了 $dfn$ 和 $low$、没有 `push` 时，分量根要对空栈取栈顶，第一组数据就会段错误。
2. **`resize` 不去掉旧数据。** `vector::resize` 只给新扩出来的位置填默认值，已有元素保持上一组的边和标记。邻接表会留下旧通道；`dfn` 不清则这些点被当成已访问，DFS 不再进入，`cnt` 停在 $0$，答案变成 `No`。每组都要用 `assign` 重建。

## 样例

### Sample 1（基本功能）

**输入：**

```
3 3
1 2
2 3
3 1
3 3
1 2
2 3
3 2
0 0
```

**输出：**

```
Yes
No
```

**说明：** 第一组是环 $1 \to 2 \to 3 \to 1$，只有一个强连通分量。第二组里 $1$ 能到 $2$、$3$，但没有任何边回到 $1$，分量是 $\{1\}$ 和 $\{2, 3\}$。

---

### Sample 2（边界）

**输入：**

```
1 0
2 0
2 2
1 2
2 1
0 0
```

**输出：**

```
Yes
No
Yes
```

**说明：** 单个房间视为强连通。两个房间之间没有通道时不能互相到达；两条通道方向相反时合成一个分量。
