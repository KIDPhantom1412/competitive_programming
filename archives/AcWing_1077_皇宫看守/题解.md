# AcWing 1077 皇宫看守

- **来源**：AcWing 1077
- **标签**：树形 DP、最小权支配集
- **日期**：2026-07-21

## 一句话题目

一棵 n 个结点的树，每个结点放守卫花费不同，守卫能看守自己和相邻结点，求看守全部结点的最小花费。

## 一句话题解

树形 DP：f[u][0/1/2] 分别表示 u 被父亲覆盖 / 被孩子覆盖 / 自己放守卫时子树的最小花费；其中"被孩子覆盖"要求至少一个孩子放守卫，用 `sum(min(f[v][1],f[v][2])) + min(f[v][2] - min(f[v][1],f[v][2]))` 转移。

## 题目描述

皇宫各宫殿呈一棵树，一个宫殿的守卫能观察本宫殿及与其直接相连的宫殿。每个宫殿安排守卫费用不同，经费不足以在每个宫殿都安排守卫。求看守全部宫殿的最少经费。

**输入格式**：第一行 n。接下来 n 行，每行：结点标号 i、经费 k、子结点数 m、m 个子结点标号。结点标号在 1~n 之间。

**输出格式**：一个整数，最少经费。

**数据范围**：1 ≤ n ≤ 1500

## 解法 1：树形 DP（三状态）

### 思路

状态定义（对以 u 为根的子树，子树内所有结点都被看守的最小花费）：

- `f[u][0]`：u 不放守卫，由父亲看守（u 的孩子只需被覆盖）
- `f[u][1]`：u 不放守卫，由至少一个孩子看守
- `f[u][2]`：u 放守卫（孩子对 u 无要求，随意取最优）

转移：

```
f[u][0] = Σ min(f[v][1], f[v][2])                  // 孩子不能靠 u，须被覆盖
f[u][2] = W[u] + Σ min(f[v][0], f[v][1], f[v][2])  // u 放守卫，孩子三态取最优
f[u][1] = f[u][0] + extra                          // 见下
```

**extra 的含义**：`f[u][1]` 要求**至少一个**孩子放守卫。先求 base = `Σ min(f[v][1], f[v][2])`（所有孩子各取最优，等价于 f[u][0]），但这样可能没有任何孩子放守卫；于是从孩子中挑一个"升级为放守卫"，增量为 `f[v][2] - min(f[v][1], f[v][2])`（注意 min 包含 f[v][2] 本身，故增量恒非负），extra 取所有孩子中的最小增量。

为什么只需为一个孩子买单：

1. base 已"免费"包含所有自愿放守卫的孩子——若 `f[v][2] ≤ f[v][1]`，base 中 v 已是放守卫状态，此时增量为 0，约束自动满足。
2. 假设最优解要强制两个增量为正的孩子都放守卫，把其中较贵的换成 `f[v][1]`（它被自己的孩子覆盖，不依赖 u），u 仍被另一个孩子覆盖，方案合法且更便宜——矛盾。故最多强制一个孩子，选增量最小者。

答案：`min(f[root][1], f[root][2])`（根没有父亲，不能取 f[root][0]）。

### 复杂度

- 时间：O(n)
- 空间：O(n)

### 代码

见 `correct_code_01.cpp`。

### 坑点

最初代码两处转移错误：

1. `f[u][0] += f[v][1]`：漏掉了 `f[v][2]` 可能更小的情况，应为 `min(f[v][1], f[v][2])`。
2. `f[u][1] += f[v][2]`：强制**所有**孩子都放守卫，高估代价；正确做法是 base + extra（见思路）。原代码里 `if (f[u][1] == INF) f[u][1] = 0;` 的补丁也是这个错误的产物。

题目样例恰好两种情况都碰不上，样例能过但 OJ 上 WA。

## 样例

### Sample 1（基本功能）

**输入：**
```
6
1 30 3 2 3 4
2 16 2 5 6
3 5 0
4 4 0
5 11 0
6 5 0
```

**输出：**
```
25
```

**说明：** 在 2、3、4 结点安排守卫，16+5+4=25（原题样例）。

---

### Sample 2（坑点：f[u][1] 强制所有孩子放守卫）

**输入：**
```
5
1 100 2 2 3
2 100 1 4
3 100 1 5
4 1 0
5 1 0
```

**输出：**
```
101
```

**说明：** 最优为在 2（覆盖 1、2、4）和 5（覆盖 3、5）放守卫，100+1=101；错误代码输出 102（1 号放守卫）。

---

### Sample 3（边界：单结点）

**输入：**
```
1
1 5 0
```

**输出：**
```
5
```

**说明：** n=1 时只能自己放守卫。
