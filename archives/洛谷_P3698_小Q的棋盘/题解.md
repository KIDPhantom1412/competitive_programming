# 洛谷_P3698_小Q的棋盘

- **来源**：洛谷
- **标签**：树, DFS, 贪心
- **日期**：2026-07-03

## 一句话题目

在一棵树上从根节点 0 出发走 N 步，求最多能经过多少个不同节点（可重复经过但不重复计数）。

## 一句话题解

DFS 求从根出发的最长路径（节点数），贪心策略：若步数不够走完最长路径则直达 N+1 个节点；否则走完最长路径后，剩余步数每 2 步可额外探索一个分支节点。答案需用总节点数 V 取最小值。

## 题目描述

小 Q 正在设计一种棋类游戏。棋子可以放在棋盘上的格点中。某些格点之间有连线，棋子只能在有连线的格点之间移动。整个棋盘上共有 V 个格点，编号为 0,1,2,…,V−1，它们是连通的，也就是说棋子从任意格点出发，总能到达所有的格点。棋子从一个格点移动到另外任一格点的路径是唯一的（即棋盘是一棵树）。

小 Q 现在想知道，当棋子从格点 0 出发，移动 N 步最多能经过多少格点。格点可以重复经过多次，但不重复计数。

**输入格式**：第一行包含 2 个正整数 V, N，接下来 V−1 行每行两个数 a_i, b_i，表示编号为 a_i, b_i 的格点之间有连线。

**输出格式**：输出一行一个整数，表示最多经过的格点数量。

**数据范围**：1 ≤ N, V ≤ 100。

## 解法 1：贪心 + DFS 求最长路径

### 思路

核心观察：在一棵树上，从根出发的路径可以看作一条"主干"（从根到某个叶子）加上若干"支路"（从主干分叉出去再返回）。

- 主干上的每个节点只需 **1 步**即可到达（向前走不回头）
- 支路上的每个节点需要 **2 步**（分支出去 + 沿原路返回主干）

因此，要让有限步数访问最多节点，应该让**主干尽可能长**——即选从根出发的最长链。

具体步骤：
1. DFS 遍历整棵树，求出从根 0 出发到任意节点的最长路径上的**节点数** `maxDepth`
2. 分类讨论：
   - 若 N ≤ maxDepth − 1：步数不够走完最长链，直接往深处走 N 步，访问 N+1 个节点
   - 若 N > maxDepth − 1：先用 maxDepth−1 步走完最长链到达最远叶子，剩余 `N − (maxDepth − 1)` 步。每 2 步可多访问一个支路节点。最终答案 = `maxDepth + (N − maxDepth + 1) / 2`，**并用 V 取最小值**（不能超过总节点数）

### 复杂度

- 时间：O(V²)（邻接矩阵 DFS，可优化为邻接表 O(V)）
- 空间：O(V²)（邻接矩阵，可优化为 O(V)）

### 代码

见 `correct_code_01.cpp`。

### 坑点

1. **答案未用 V 取最小值**（第 33 行）：公式 `maxDepth + (m - maxDepth + 1) / 2` 在 N 远大于 V 时会算出超过总节点数的值。例如 V=1, N=5 时公式结果为 3，但总共只有 1 个节点。修复方式：`std::min(n, maxDepth + (m - maxDepth + 1) / 2)`。

## 样例

### Sample 1（基本功能 — 链状图）

**输入：**
```
5 2
1 0
2 1
3 2
4 3
```

**输出：**
```
3
```

**说明：** 从 0 出发走 2 步，经过 0, 1, 2 共 3 个格点。


**输出：**
```

```

**说明：** 路径 0→1→3→5→3→7，经过 0, 1, 3, 5, 7 共 5 个格点。从最长链上分支访问支路节点。

**说明：** 只有一个格点，无论多少步最多经过 1 个。未加 min(V, ans) 限制时公式会错误输出 3。
