# HDU 1561 - The more, The Better

- **来源**：HDU 1561
- **标签**：树形 DP、依赖背包、背包问题
- **日期**：2026-06-24

## 一句话题目

给定 N 个城堡（每个城堡有依赖关系，攻克前提城堡才能攻克该城堡）和最多攻打 M 个城堡的限制，每个城堡有宝藏价值，求能获得的最大宝藏价值。

## 一句话题解

建立虚拟根节点 0，将依赖关系转化为树，然后在树上做分组背包 / 依赖背包，最终答案为 `f[0][M+1]`。

## 题目描述

ACboy 喜欢玩一种战略游戏。在一个地图上，有 N 座城堡，每座城堡都有一定的宝物。在每次游戏中 ACboy 允许攻克 M 个城堡并获得里面的宝物。但由于地理位置原因，有些城堡不能直接攻克，要攻克这些城堡必须先攻克其他某一个特定的城堡。你能帮 ACboy 算出要获得尽量多的宝物应该攻克哪 M 个城堡吗？

**输入格式：** 每个测试实例首先包括 2 个整数 N, M（$1 \le M \le N \le 200$）。在接下来的 N 行里，每行包括 2 个整数 a, b。在第 i 行，a 代表要攻克第 i 个城堡必须先攻克第 a 个城堡，如果 a = 0 则代表可以直接攻克第 i 个城堡。b 代表第 i 个城堡的宝物数量，$b \ge 0$。当 N = 0, M = 0 输入结束。

**输出格式：** 对于每个测试实例，输出一个整数，代表 ACboy 攻克 M 个城堡所获得的最多宝物的数量。

**数据范围：** $1 \le M \le N \le 200$，$b \ge 0$

## 解法 1：树形 DP + 依赖背包

### 思路

本题是一道典型的「树上依赖背包」问题。

依赖关系天然形成一片森林：如果城堡 i 的 prerequisite 是 a，则 a 是 i 的父节点；所有 a = 0 的城堡没有父节点，可以视为直接从虚拟根节点 0 出发。

为了把多棵树合并成一棵树，我们建立一个虚拟根节点 0，它的权值为 0，并向所有 a = 0 的城堡连边。于是问题变成：

> 在这棵有根树中，选择恰好 M+1 个节点（包括虚拟根 0），要求若选择某个节点，则必须选择它的父节点。最大化所选节点的权值和。

设 `f[u][j]` 表示在 u 的子树中，**必须选 u**，一共选 j 个节点能获得的最大宝物数。

- 初始化：`f[u][1] = W[u]`（只选 u 自己）。本实现中把所有 `f[u][i]` 都初始化为 `W[u]`，由于 $b \ge 0$，这个下界不会导致最终答案出错。
- 转移：对每个子节点 v，做 0/1 背包合并：
  ```cpp
  for (int j = m + 1; j >= 1; j--)
      for (int k = 1; k <= j - 1; k++)
          f[u][j] = max(f[u][j], f[u][j - k] + f[v][k]);
  ```
  外层从大到小枚举 j，保证每个子节点只被合并一次（0/1 背包）。
- 答案：`f[0][M + 1]`，因为虚拟根 0 必须选，剩下的 M 个节点就是题目要求的 M 个城堡。

### 复杂度

- 时间：$O(N \cdot M^2)$，$N \le 200, M \le 200$，最大约 $8 \times 10^6$ 次运算，可轻松通过。
- 空间：`f[N][N]`，约 $4 \times 10^4$ 个整数，非常小。

### 代码

见 `correct_code_01.cpp`。

### 坑点

本次调试中代码直接通过样例，没有遇到 WA/TLE/RE。主要关注点：

1. **状态初始化**：本实现把 `f[u][i]` 全部初始化为 `W[u]`，在 $b \ge 0$ 条件下安全。更稳妥的做法是 `f[u][1] = W[u]`，其余初始化为 0 或 -INF。
2. **虚拟根节点**：必须加入权值为 0 的虚拟根 0，把多棵依赖树连成一棵，否则无法统一处理所有 a = 0 的城堡。
3. **容量偏移**：最终答案是 `f[0][M + 1]` 而不是 `f[0][M]`，因为虚拟根 0 占据了 1 个节点名额。
4. **输入效率**：多测时建议加 `ios::sync_with_stdio(false); cin.tie(nullptr);`。

## 样例

### Sample 1（基本功能）

**输入：**
```
3 2
0 1
0 2
0 3
```

**输出：**
```
5
```

**说明：** 3 个城堡都依赖根节点 0，打 2 个最多拿 2+3=5。

### Sample 2（基本功能）

**输入：**
```
7 4
2 2
0 1
0 4
2 1
7 1
7 6
2 2
```

**输出：**
```
13
```

**说明：** 7 个城堡，依赖关系构成树，打 4 个最多拿 13。验证树形 DP 正确性。
