# 坑点总结

## 遇到的错误

本次调试中，代码直接通过了样例，没有遇到 WA/TLE/RE。主要关注的是对状态初始化的理解。

## 注意事项

1. **状态初始化**：本实现把 `f[u][i]` 全部初始化为 `W[u]`。这是非标准写法，但在本题 $b \ge 0$ 的条件下是安全的。更稳妥的做法是：
   ```cpp
   f[u][1] = W[u];
   for (int i = 2; i <= m + 1; i++) f[u][i] = 0; // 或 -INF
   ```

2. **虚拟根节点**：必须加入一个权值为 0 的虚拟根 0，把多棵依赖树连成一棵，否则无法统一处理所有 a = 0 的城堡。

3. **容量偏移**：最终答案是 `f[0][M + 1]` 而不是 `f[0][M]`，因为虚拟根 0 占据了 1 个节点名额。

4. **输入效率**：HDU 数据量不大，但多测时建议加上：
   ```cpp
   std::ios::sync_with_stdio(false);
   std::cin.tie(nullptr);
   ```

5. **数组大小**：`E[N]` 在本题中足够（最多 N 条边），注意 1-based 索引不要越界。
