# HDU 1561 - The more, The Better

- **来源**：HDU 1561
- **难度**：中等
- **标签**：树形 DP、依赖背包、背包问题
- **日期**：2026-06-24

## 一句话题目

给定 N 个城堡（每个城堡有依赖关系，攻克前提城堡才能攻克该城堡）和最多攻打 M 个城堡的限制，每个城堡有宝藏价值，求能获得的最大宝藏价值。

## 一句话题解

建立虚拟根节点 0，将依赖关系转化为树，然后在树上做分组背包 / 依赖背包，最终答案为 `f[0][M+1]`。
