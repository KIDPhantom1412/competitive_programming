## 一句话题目

已知二进制串中相邻字符对有 $n_0$ 个 `00`、$n_2$ 个 `11`、$n_1$ 个 `01`/`10`，构造任意一个满足条件的串。

## 一句话题解

把 $n_0+1$ 个 `0` 与 $n_2+1$ 个 `1` 拼成两段，交界处天然贡献 1 个 `01`；再从末尾的 `1` 开始交替追加 $n_1-1$ 个字符，新增的每一对都是 `10` 或 `01`；$n_1=0$ 时退化为单一字符段。

## 题目描述

给定一个二进制串 $s$（长度为 $n$），统计所有 $n-1$ 个长度为 2 的子串中含 `1` 的个数：

- $n_0$：含 0 个 `1` 的子串数，即 `00` 的个数；
- $n_1$：含 1 个 `1` 的子串数，即 `01` 与 `10` 的个数之和；
- $n_2$：含 2 个 `1` 的子串数，即 `11` 的个数。

现在只给出 $n_0,n_1,n_2$，要求还原出**任意一个**对应的二进制串。保证至少一个数大于 0，且答案一定存在。

**输入格式**：第一行一个整数 $t$（$1\le t\le 1000$），表示测试组数。接下来 $t$ 行，每行三个整数 $n_0,n_1,n_2$（$0\le n_0,n_1,n_2\le 100$，$n_0+n_1+n_2>0$）。

**输出格式**：对每组数据输出一行一个二进制串。若有多解，输出任意一个即可。

## 解法 1：分段 + 交替补齐

### 思路

一个二进制串中，`0` 的总个数等于 $n_0 + 1$（把串按 `0` 切成若干段，段内 `00` 的个数之和为 $n_0$），同理 `1` 的总个数为 $n_2+1$。所以串长固定为 $n_0+n_1+n_2+1$。

**情况一：$n_1=0$。** 此时不存在 `01`/`10`，整个串只有一种字符，因此 $n_0$ 与 $n_2$ 至多一个非零。若 $n_0>0$，答案就是 $n_0+1$ 个 `0`；否则答案是 $n_2+1$ 个 `1`。

**情况二：$n_1>0$。** 先写出两段：

- 左段：$n_0+1$ 个 `0`，贡献 $n_0$ 个 `00`；
- 右段：$n_2+1$ 个 `1`，贡献 $n_2$ 个 `11`。

两段交界处是 `01`，贡献了 1 个混合对。还需要补 $n_1-1$ 个混合对，而在右段末尾（一个 `1`）之后交替追加字符时，每次新增的一对必为 `10` 或 `01`，既不会产生 `00` 也不会产生 `11`。因此只需从 `0` 开始、`0`/`1` 交替地追加 $n_1-1$ 个字符即可。

例如 $n_0=1,n_1=3,n_2=5$：`00` + `111111` + `01` = `0011111101`，其中 `00` 一个、`11` 五个、混合对三个。

### 复杂度

- 时间：每组 $O(n_0+n_1+n_2)$
- 空间：$O(n_0+n_1+n_2)$（输出串本身）
