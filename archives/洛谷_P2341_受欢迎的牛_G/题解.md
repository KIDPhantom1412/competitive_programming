# 洛谷_P2341_受欢迎的牛_G

- **来源**：洛谷 P2341 [USACO03FALL / HAOI2006] 受欢迎的牛 G
- **标签**：强连通分量、Tarjan、缩点、DAG 出度
- **日期**：2026-11-21

## 一句话题目

给定 $N$ 头牛与 $M$ 条「$A$ 喜欢 $B$」的有向关系，喜欢关系满足自反（每头牛喜欢自己）与传递（$A$ 喜欢 $B$、$B$ 喜欢 $C$ $\Rightarrow$ $A$ 喜欢 $C$），求被所有牛喜欢的牛的数量。

## 一句话题解

Tarjan 求强连通分量并缩点，答案为缩点后 DAG 中**唯一**的出度为 $0$ 的 SCC 的大小；这样的 SCC 不唯一则输出 $0$。

## 题目描述

每头奶牛都梦想成为牛棚里的明星。被所有奶牛喜欢的奶牛就是一头明星奶牛。

所有奶牛都是自恋狂，每头奶牛总喜欢自己。奶牛之间的「喜欢」是可以传递的——如果 $A$ 喜欢 $B$，$B$ 喜欢 $C$，那么 $A$ 也喜欢 $C$。牛栏里共有 $N$ 头奶牛，给定一些奶牛之间的爱慕关系，请你算出有多少头奶牛可以当明星。

### 输入格式

第一行：两个用空格分开的整数 $N$ 和 $M$。

接下来 $M$ 行：每行两个用空格分开的整数 $A$ 和 $B$，表示 $A$ 喜欢 $B$。

### 输出格式

一行单独一个整数，表示明星奶牛的数量。

### 数据范围

- 对于 $10\%$ 的数据，$N \le 20$，$M \le 50$；
- 对于 $30\%$ 的数据，$N \le 10^3$，$M \le 2 \times 10^4$；
- 对于 $70\%$ 的数据，$N \le 5 \times 10^3$，$M \le 5 \times 10^4$；
- 对于 $100\%$ 的数据，$1 \le N \le 10^4$，$1 \le M \le 5 \times 10^4$。

时间限制 $1\text{ s}$，内存限制 $128\text{ MB}$。

## 解法 1：Tarjan 缩点 + 出度统计

### 思路

一个点 $u$ 能当明星，当且仅当**所有**点都能到达 $u$。

先把图缩成 DAG：

- 同一个 SCC 内的点互相可达，所以「一个 SCC 内有一个点是明星」等价于「这个 SCC 内所有点都是明星」，答案必然是某个 SCC 的大小。
- 若 $u$ 是明星，则 $u$ 所在的 SCC 不能有出边（否则沿出边走出 SCC 的点回不来，那个点就不能到达 $u$），即它是 DAG 上的**汇点**。
- 若汇点 SCC 有两个或以上，它们之间互不可达，谁都不是明星，答案为 $0$；若汇点 SCC 唯一，则 DAG 中任何点都能沿出边走到底，最终到达这个唯一的汇点，于是它包含的所有点都是明星。

所以只需统计每个 SCC 的出度：

1. Tarjan 求 SCC，编号 $1 \sim cnt$；
2. 遍历所有边，若两端属于不同 SCC，则给起点的 SCC 出度 $+1$（重边重复计数不影响「是否为 $0$」）；
3. 统计出度为 $0$ 的 SCC 个数：$\ge 2$ 输出 $0$，否则输出该 SCC 的点数。

### 复杂度

- 时间：$O(n + m)$（Tarjan 一次 DFS，再加一次遍历所有边）
- 空间：$O(n + m)$（邻接表 + `dfn`/`low`/`scc`/栈）

### 代码

见 `correct_code_01.cpp`。

### 坑点

1. **Tarjan 的 else 分支必须判断「是否还在栈中」**。写成
   ```cpp
   } else {
       low[u] = std::min(low[u], dfn[v]);
   }
   ```
   会把**指向已完成的 SCC** 的边也当成回边，把 $low_u$ 拉到别的 SCC 的 $dfn$ 上，导致 $u$ 不再被判为 SCC 根、点永远留在栈中。
   用 `3\ 3 / 1\to2 / 2\to1 / 3\to2` 这一组数据可以看到：真实有 $\{1,2\}$、$\{3\}$ 两个 SCC，但漏判时 `cnt` 只有 $1$，且 `scc[3]` 一直是初值 $0$。
   本写法用 `else if (!scc[v])` 代替 `inStk` 数组——`scc` 只在出栈时赋值，所以 `!scc[v]` 恰好等价于「$v$ 仍在栈中」，省掉一个数组和成对维护的麻烦。
   注意：对本题的答案，漏判碰巧不影响（漏标点必有一条边指向已完成的 SCC，不可能是汇点），但 SCC 标号是坏的，一旦题目要求按 SCC 大小 / 编号 / 反拓扑序处理就会出错，必须写对。
2. 汇点 SCC 唯一性一旦被破坏就可以直接输出 $0$ 并返回，不必继续统计。
3. 重边、自环都不需要特判：重边只会让出度重复累加（不影响是否 $0$），自环两端同属一个 SCC 会被跳过。
4. Tarjan 内部用了 `this auto&&`（C++23 的 deducing this），提交时需选 C++23 编译器；若评测机不支持，改成 `std::function<void(int)>` 或普通递归函数即可（$n \le 10^4$，递归深度安全）。

## 样例

### Sample 1（官方样例）

**输入：**

```
3 3
1 2
2 1
2 3
```

**输出：**

```
1
```

**说明：** 只有 3 号奶牛可以当明星。缩点后 $\{1,2\} \to \{3\}$，唯一出度为 $0$ 的 SCC 是 $\{3\}$，大小为 $1$。

---

### Sample 2（坑点：Tarjan 漏判 inStack）

**输入：**

```
3 3
1 2
2 1
3 2
```

**输出：**

```
2
```

**说明：** 缩点后 $\{3\} \to \{1,2\}$，唯一汇点是 $\{1,2\}$，答案 $2$。漏判 inStack 时 `cnt` 会算成 $1$ 且 `scc[3]` 为 $0$（答案仍碰巧正确，但 SCC 标号已坏）。

---

### Sample 3（边界：汇点 SCC 不唯一）

**输入：**

```
4 4
1 2
2 1
3 2
3 4
```

**输出：**

```
0
```

**说明：** 缩点后 $\{3\} \to \{1,2\}$、$\{3\} \to \{4\}$，汇点有 $\{1,2\}$ 和 $\{4\}$ 两个，无解。

---

### Sample 4（边界：整张图强连通）

**输入：**

```
3 3
1 2
2 3
3 1
```

**输出：**

```
3
```

**说明：** 只有一个 SCC，任何牛都被所有牛喜欢。
