## 一句话题目

两片各有 $n$ 个节点的森林（Mocha 和 Diana 各一片），给两边加**相同的**边，要求加完后两边仍是森林，求最多能加多少条边并输出方案。

## 一句话题解

两个并查集分别维护两片森林的连通性，$O(n^2)$ 枚举所有点对，在两边都不同连通块时加边合并；答案恰好是 $\min(c_1, c_2) - 1$（$c_1, c_2$ 为初始连通块数），任何极大方案都是最优方案。

## 题目描述

森林是无环无向图（不一定连通）。Mocha 和 Diana 各有一片 $n$ 个节点的森林，想给两片森林加边，要求：

- 加边后两边都仍是森林；
- 两边加的边必须完全相同：$(u, v)$ 加给 Mocha 就必须加给 Diana，反之亦然。

求最多能加多少条边，并输出方案（任意一个即可）。

**输入**：第一行三个整数 $n, m_1, m_2$（$1 \le n \le 1000$，$0 \le m_1, m_2 < n$）；接下来 $m_1$ 行是 Mocha 森林的边，再 $m_2$ 行是 Diana 森林的边，每行两个整数 $u, v$（$1 \le u, v \le n$，$u \ne v$）。

**输出**：第一行输出最大边数 $h$，接下来 $h$ 行每行输出一条边 $u, v$。多解输出任意一个即可。

## 解法 1：双并查集 + 贪心枚举点对

### 思路

用两个并查集 $P_1, P_2$ 分别维护 Mocha 和 Diana 森林的连通性。枚举所有点对 $(i, j)$（$j < i$），若 $i, j$ 在**两边**都不同连通块，则这条边在两片森林中都不会成环，加边并在两个并查集中同时合并，记录答案。

**正确性与最优性**：设初始连通块数为 $c_1$、$c_2$。每加一条边，两边的连通块数各减 $1$，故加 $k$ 条边后两边连通块数分别为 $c_1 - k$、$c_2 - k$。可以证明：只要两边都还剩至少 $2$ 个连通块，就一定存在合法点对（任取 Mocha 的两个不同块 $X \ne Y$，块内任取 $u \in X, v \in Y$；若所有这样的点对在 Diana 中都同块，则 $X \cup Y$ 整体落在 Diana 的同一个块里，再引入第三个 Mocha 块可推出 Diana 全部同块，与 Diana 剩 $\ge 2$ 块矛盾）。因此贪心一定能做到不能再加为止，此时必有一边只剩 $1$ 个连通块：

$$
h = \min(c_1, c_2) - 1
$$

即任何极大方案都是最优的，不必担心枚举顺序影响答案。

### 复杂度

- 时间：$O(n^2 \alpha(n))$，$n = 1000$ 时约 $5 \times 10^5$ 次合并操作
- 空间：$O(n)$

### 代码

见 `correct_code_01.cpp`。

### 坑点

- **建 Diana 并查集时写错下标导致自赋值**：原代码读入 Diana 的边时写成

  ```cpp
  P2[find(P2, b)] = find(P2, b);   // 自赋值，等于什么都没合并
  ```

  应为 `P2[find(P2, a)] = find(P2, b);`。后果是 $P_2$ 保持全单点，Diana 的初始边完全失效，加边只受 Mocha 约束，会在 Diana 一侧成环，输出的边数偏大且方案非法（Wrong answer on test 2）。test 1 的答案恰好是 $0$，不会暴露此错误。
- **本题答案不唯一**（Special Judge）：输出的边只要合法且数量最大即可，不能用样例 `diff` 对拍，验证时应写 checker 检查「加边后两边无环 + 边数等于 $\min(c_1, c_2) - 1$」。

## 样例

### Sample 1（基本功能）

**输入：**
```
8 1 2
1 7
2 6
1 5
```

**输出：**
```
5
2 1
3 1
4 1
7 5
8 1
```

**说明：** Mocha 初始有 $7$ 个连通块，Diana 有 $6$ 个，$h = \min(7, 6) - 1 = 5$。输出的边可以与官方样例不同（多解）。

---

### Sample 2（边界：答案为 0）

**输入：**
```
3 2 2
1 2
2 3
1 2
1 3
```

**输出：**
```
0
```

**说明：** 两边都已经是 $3$ 个点的树（各只剩 $1$ 个连通块），任意加边都会在两边同时成环，$h = \min(1, 1) - 1 = 0$。

---

### Sample 3（坑点：Diana 初始边漏合并）

**输入：**
```
5 3 2
5 4
2 1
4 3
4 3
1 4
```

**输出：**
```
1
3 2
```

**说明：** Mocha 连通块为 $\{5,4,3\}, \{2,1\}$，Diana 连通块为 $\{4,3,1\}, \{2\}, \{5\}$，$h = \min(2, 3) - 1 = 1$。此用例即暴露坑点的反例：错误代码漏合并 Diana 的 $(4,3),(1,4)$，会输出 $(3,1)$ 这条使 Diana 成环的边。正确代码输出的 $(3,2)$ 在两边均不成环（官方输出为 $(2,4)$，两者都合法）。
