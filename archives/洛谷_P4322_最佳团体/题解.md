## 一句话题目

在推荐关系形成的树中招募 K 名候选人（含其所有推荐人），使总战斗值与总费用的比值最大。

## 一句话题解

分数规划二分答案，将比值转化为“总战斗值 - mid × 总费用”的最大值问题；再用 DFS 序 + 子树大小的树形 01 背包判断可行性。

## 题目描述

JSOI 信息学代表队有 N 名候选人，编号 1 到 N，JYY 编号为 0。
每个候选人 i 由编号比它小的候选人 R_i 推荐（R_i = 0 表示 JYY 自己看上）。
招募候选人 i 时，R_i 也必须在团队中；JYY 自己始终在团队中。
每个候选人有招募费用 S_i 和战斗值 P_i。
要求招募 K 名候选人（不含 JYY），使得总战斗值 / 总招募费用最大。

**输入：** 第一行两个正整数 K、N。接下来 N 行，每行三个整数 S_i、P_i、R_i。

**输出：** 一个实数，表示最大比值，保留三位小数。

**数据范围：** $1 \le K \le N \le 2500$，$0 < S_i, P_i \le 10^4$，$0 \le R_i < i$。

## 解法 1：树形 DP + 分数规划

### 思路

1. 答案具有单调性：若存在方案使比值 ≥ mid，则对任意更小的 mid 也一定存在。因此二分答案 mid。
2. 对每个 mid，把每个候选人的“价值”设为 $V_i = P_i - \text{mid} \cdot S_i$。问题变成：在满足依赖关系的前提下，选 K 个候选人，使得 $\sum V_i > 0$。
3. JYY 必选，把 JYY 也占一个名额，即 DP 要选 $m = K + 1$ 个节点。
4. 推荐关系形成一棵以 0 为根的树。利用 DFS 后序遍历，子树节点在序列中连续出现。
5. 设 `f[i][j]` 表示 DFS 序前 i 个节点中选 j 个的最大价值和：
   - 不选 `pos[i]`：整棵子树都不能选，跳到 `i - size[pos[i]]`。
   - 选 `pos[i]`：子树中其余节点已经处理完，从 `f[i-1][j-1]` 转移，加上 `V[pos[i]]`。

### 复杂度

- 时间：$O(N^2 \cdot \log \epsilon^{-1})$，其中 DP 为 $O(N^2)$，二分约 50 次。
- 空间：$O(N^2)$。

### 代码

见 `correct_code_01.cpp`。

### 坑点

1. **建图方向容易写反**：`dfs(0)` 需要从根往下走，邻接表必须存“父节点 → 子节点”。错误代码写成了 `add(i, c)`（子节点指向父节点），导致 `H[0]` 为空，DFS 只访问到 JYY，输出错误。
2. **JYY 占名额**：DP 中 `m = K + 1`，最后判断 `f[cnt][m]`。
3. **二分精度**：保留三位小数时，精度不能太低，建议 `1e-7`，避免四舍五入错误。

## 样例

### Sample 1（基本功能）

**输入：**
```
1 2
1000 1 0
1 1000 1
```

**输出：**
```
0.001
```

**说明：** 选候选人 2 必须同时选候选人 1，超过 K=1 的限制，因此只能选候选人 1，比值为 1/1000 = 0.001。

---

### Sample 2（坑点：建图方向）

**输入：**
```
1 2
1000 1 0
1 1000 1
```

**输出：**
```
0.000
```

**说明：** 这是错误代码（`add(i, c)`）在本样例上的输出。因 DFS 从 0 出发无法到达任何候选人，DP 认为无法选够 K 人，返回 0。
