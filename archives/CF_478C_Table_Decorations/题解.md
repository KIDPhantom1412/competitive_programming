## 一句话题目

红、绿、蓝气球各有若干个，每张桌子恰好用 3 个气球且不能三个同色，求最多能装饰多少张桌子。

## 一句话题解

排序后 $a \le b \le c$。$c \ge 2(a+b)$ 时每桌 2 个 $c$ 配 1 个其他颜色，答案是 $a+b$；否则丢掉总数模 3 的余数，再把用掉的气球拆成「2 个最多的一堆 + 1 个其他」和「1 个最多的一堆 + 2 个其他」。

## 题目描述

有 $r$ 个红气球、$g$ 个绿气球、$b$ 个蓝气球。装饰一张桌子恰好需要 3 个气球，同一张桌子上的 3 个气球不能是同一种颜色。求最多能装饰多少张桌子。

**输入格式**：一行三个整数 $r, g, b$（$0 \le r, g, b \le 2 \cdot 10^9$）。

**输出格式**：一行一个整数，为最多桌子数。

## 解法 1：按最多颜色构造

### 思路

把三种颜色排序为 $a \le b \le c$。一张合法桌子只有两类：三种颜色各 1 个，或者两种颜色按 $2+1$ 分配。三个同色不合法。

桌子数有两个上界：

- 每桌消耗 3 个气球，所以不超过 $\lfloor (a+b+c)/3 \rfloor$。
- 颜色 $c$ 不能自己摆一桌，每桌至少要用 1 个 $a$ 或 $b$，所以不超过 $a+b$。

答案就是这两个上界的较小值。$c \ge 2(a+b)$ 时较小值是 $a+b$，否则是总数除以 3。两种情况都能构造出来。$2(a+b) \le c \le 2(a+b)+2$ 时两个式子相等。

**第一种构造：$c \ge 2(a+b)$。**

摆 $a$ 桌「2 个 $c$ + 1 个 $a$」，再摆 $b$ 桌「2 个 $c$ + 1 个 $b$」，一共 $a+b$ 桌。用掉的 $c$ 是 $2(a+b)$，不超过 $c$。

**第二种构造：$c < 2(a+b)$。**

记 $s = a+b+c = 3t+r$，其中 $t = \lfloor s/3 \rfloor$，$0 \le r \le 2$。$t = 0$ 时气球不足 3 个，答案是 0。下面设 $t \ge 1$，要摆满 $t$ 桌，一共使用 $3t$ 个气球，丢掉 $r$ 个。

$t$ 桌里同一种颜色至多出现 $2t$ 次。先说明 $c$ 只会是 $c \le 2t$，或者 $c = 2t+1$。若 $c \ge 2t+1$，由 $c < 2(a+b)$ 得 $2(a+b) \ge c+1$，即 $a+b \ge \lceil (c+1)/2 \rceil$。同时 $a+b = s-c \le 3t+r-(2t+1) = t+r-1$。因此

$$
\left\lceil\frac{c+1}{2}\right\rceil \le t+r-1
$$

也就是 $c \le 2t+2r-3$。再和 $c \ge 2t+1$ 比较，只能是 $r = 2$、$c = 2t+1$。两种情况分别丢掉 $r$ 个气球，留下三堆个数之和为 $3t$、每种不超过 $2t$ 的气球。

**$c \le 2t$。** 此时 $a \le b \le c \le 2t$。从 $a,b$ 里丢掉 $r$ 个，三种颜色其余的全部留下。$a+b = s-c \ge 3t+r-2t = t+r \ge r$，这些气球丢得掉。

**$c = 2t+1$。** 此时 $r = 2$，$a+b = s-c = t+1$。丢掉 1 个 $c$ 和 1 个 $a$ 或 $b$，留下 $2t$ 个 $c$，再留下 $t$ 个 $a,b$。$b \le a+b = t+1 \le 2t$，留下的每种颜色也不超过 $2t$。

现在把留下的三堆气球摆成 $t$ 桌。三堆个数之和是 $3t$，每种不超过 $2t$，从少到多记为 $u \le v \le w$。最多的一堆至少有 $t$ 个，否则三堆之和不到 $3t$，所以 $t \le w \le 2t$。令 $x = w-t$，分成两类桌子：

- $x$ 桌：2 个最多的那一堆，再配 1 个另外两堆里的气球；
- $t-x$ 桌：1 个最多的那一堆，再配 2 个另外两堆里的气球。

最多的那一堆用掉 $2x+(t-x) = w$ 个。另外两堆一共用掉 $x+2(t-x) = u+v$ 个，按手里的个数往这些空位上填即可。每一桌都带了最多的那一堆，配上的 1 个或 2 个气球不会变成三个同色。

所以 $c < 2(a+b)$ 时可以摆满 $\lfloor (a+b+c)/3 \rfloor$ 桌。

### 复杂度

- 时间：$O(1)$
- 空间：$O(1)$

### 代码

见 `correct_code_01.cpp`。

### 坑点

$c \ge 2(a+b)$ 时答案是另外两种颜色的个数之和 $a+b$，不是 $b+c$。$1\ 1\ 100$ 只能摆 2 桌：每桌最多 2 个蓝色，仅有的 2 个其他颜色各配一桌，剩下的蓝色三个同色，不能再摆。若输出 $b+c$ 会得到 101。

$a, b$ 最大都是 $2 \cdot 10^9$，$(a+b) \cdot 2$ 达到 $8 \cdot 10^9$，比较时要用 64 位整数。

## 样例

### Sample 1（基本功能）

题目样例。排序后是 $3,4,5$，$5 < 2 \cdot (3+4)$，总数 $12$ 除以 3 得 $4$，余数 $0$，三堆全部用上。最多的一堆是 $5$，$x = 5-4 = 1$。按第二种构造：1 桌拿这堆里的 2 个再配 1 个，另外 3 桌各拿这堆里的 1 个再配 2 个。按三堆从少到多，一组具体摆法是 $(1,0,2)$、$(2,0,1)$、$(0,2,1)$、$(0,2,1)$。

**输入：**

```
5 4 3
```

**输出：**

```
4
```

**说明：** 这组数据走第二种构造，三种颜色全部用完。

---

### Sample 2（基本功能）

三种颜色各 1 个，正好摆一桌。

**输入：**

```
1 1 1
```

**输出：**

```
1
```

**说明：** $(1,1,1)$ 合法。

---

### Sample 3（基本功能）

$2+3+3=8$，除以 3 得 2。

**输入：**

```
2 3 3
```

**输出：**

```
2
```

**说明：** 还剩 2 个气球，凑不满下一桌。

---

### Sample 4（坑点：最多颜色远多于另外两种）

排序后 $1,1,100$。$100 \ge 2 \cdot (1+1)$，答案是 $1+1=2$。

**输入：**

```
1 1 100
```

**输出：**

```
2
```

**说明：** 错加成 $1+100$ 会输出 101。

---

### Sample 5（边界）

只有一种颜色，任意 3 个都同色。

**输入：**

```
0 0 5
```

**输出：**

```
0
```

**说明：** 另外两种之和是 0，一桌都摆不了。

---

### Sample 6（极端数据）

三种颜色都取到上限。$3 \cdot 2 \cdot 10^9$ 除以 3 仍是 $2 \cdot 10^9$，另外两种之和更大。

**输入：**

```
2000000000 2000000000 2000000000
```

**输出：**

```
2000000000
```

**说明：** 中间乘积超过 32 位整数范围，计数要用 64 位。
