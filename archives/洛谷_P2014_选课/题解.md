## 一句话题目

N 门有先修关系的课程，每门有学分，从中选恰好 M 门，求能获得的最大学分。

## 一句话题解

以虚拟根节点 0 建立先修树，按 DFS 后序得到线性序列，然后在该序列上做“选当前节点 / 跳过整棵子树”的 0/1 背包。

## 题目描述

在大学里，为了达到一定的学分，必须从很多课程里选择一些课程来学习。课程里有些课程必须在某些课程之前学习，若课程 a 是课程 b 的先修课，则只有学完了课程 a，才能学习课程 b。

现有 N 门课，每门课有若干学分，分别记为 s1, s2, ..., sN。每门课有一门或没有直接先修课（k_i = 0 表示没有直接先修课）。一个学生要从这些课程里选择 M 门课程学习，问他能获得的最大学分是多少。

题目保证课程安排无冲突（不会出现 a 是 b 的先修课，b 也是 a 的先修课的情况）。

**输入：**
第一行有两个整数 N, M，用空格隔开。
接下来的 N 行，第 i+1 行包含两个整数 k_i 和 s_i，k_i 表示第 i 门课的直接先修课，s_i 表示第 i 门课的学分。

**输出：**
只有一行，选 M 门课程的最大学分。

**数据范围：**
- 1 ≤ N ≤ 300
- 1 ≤ M ≤ 300
- 0 ≤ k_i ≤ N
- 1 ≤ s_i ≤ 20
- 数据保证至少存在一个 k_i = 0

## 解法 1：树形背包 + DFS 序线性化

### 思路

1. 以虚拟根节点 0 为根，把先修关系建成一棵树（森林）。根节点 0 的学分设为 0。
2. 做一次 DFS 后序遍历，得到每个节点的子树大小 `size[u]`，以及它在线性序列中的位置 `pos[i]`。
3. 在 DFS 序上做 DP：
   - `f[i][j]`：考虑前 i 个节点，共选 j 个节点的最大价值（根节点后续会被强制选上）。
   - 对于节点 `pos[i]` 有两种选择：
     - 选它：占用 1 个名额，价值加上 `W[pos[i]]`，状态来自 `f[i-1][j-1]`。
     - 不选它：则整个子树都不能选，跳到该子树之前 `f[i - size[pos[i]]][j]`。
   - 转移方程：`f[i][j] = max(f[i-1][j-1] + W[pos[i]], f[i-size[pos[i]]][j])`
4. 最终答案为 `f[cnt][m+1]`，因为虚拟根节点 0 必须被选中，占用 1 个名额。

### 复杂度

- 时间：O(NM)
- 空间：O(NM)

### 坑点

**初始化 `f[i][0]` 必须全部为 0，不能只设置 `f[0][0]`。**

原代码只写 `f[0][0] = 0`，其余 `f[i][0]` 为 `-INF`，导致 DP 无法表达“从当前节点开始新选一棵子树”的合法中间状态。链状数据会因此得到错误答案。

错误代码：
```cpp
for (int i = 0; i <= cnt; i++) {
    std::fill_n(f[i], m + 2, -INF);
}
f[0][0] = 0;
```

修复：
```cpp
for (int i = 0; i <= cnt; i++) {
    std::fill_n(f[i], m + 2, -INF);
    f[i][0] = 0;
}
```

## 样例

### Sample 1（基本功能）

**输入：**
```
7 4
2 2
0 1
0 4
2 1
7 1
7 6
2 2
```

**输出：**
```
13
```

**说明：** 最优方案为选修课程 3、6、7、2，学分 4+6+2+1=13。

---

### Sample 2（坑点：链状数据）

**输入：**
```
2 1
0 5
1 3
```

**输出：**
```
5
```

**说明：** 只能选 1 门课，课程 2 依赖课程 1，若选课程 2 会占用 2 门课名额，不合法。因此只能单独选课程 1，学分 5。原代码在此处会因 `f[i][0]` 初始化错误而输出错误答案。
