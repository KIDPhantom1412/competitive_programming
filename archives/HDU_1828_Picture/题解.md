## 一句话题目

求若干轴对齐矩形并集的周长。

## 一句话题解

扫描线 + 线段树：维护当前横截面的覆盖长度与连续覆盖段数，横边贡献为长度变化量，竖边贡献为段数 × 2 × 高度差。

## 题目描述

墙上贴了若干矩形海报（边均水平或竖直），矩形可互相覆盖。求所有矩形并集边界的总长度（周长）。

**输入**

- 第一行：矩形个数 $n$
- 随后 $n$ 行：每个矩形左下角与右上角坐标 $x_1\ y_1\ x_2\ y_2$
- 多组数据，读至 EOF

**输出**

- 一行一个非负整数，表示并集周长

**数据范围**

- $0 \le n < 5000$
- 坐标 $\in [-10000, 10000]$，每个矩形面积为正

## 解法 1：扫描线 + 线段树（维护覆盖长度与段数）

### 思路

将每个矩形拆成两条水平边：下边权值 $+1$（进入），上边权值 $-1$（离开）。按 $y$ 从小到大扫描。

对 $x$ 坐标离散化，线段树叶子对应相邻离散点之间的真实线段长度。每个节点维护：

| 字段 | 含义 |
|------|------|
| `len` | 区间总长度 |
| `v` | 当前被覆盖的长度 |
| `cnt` | 连续覆盖段的个数 |
| `lb` / `rb` | 左右端点是否被覆盖 |
| `d` | 覆盖次数（懒标记式计数） |

`pull` 时：若 `d > 0` 则整段覆盖，`v = len`，`cnt = 1`；否则合并左右子树，若左右在交界处都覆盖则 `cnt` 减一（两段合并）。

扫描到第 $i$ 条边时：

1. **竖边贡献**：`cnt × 2 × (y_i - y_{i-1})`（每段覆盖区间上下各一条竖边）
2. **更新**线段树：区间 `[find(x1)+1, find(x2)]` 加 $d$
3. **横边贡献**：`|new_len - old_len|`（覆盖长度增减对应新增/消失的横边）

### 复杂度

- 时间：$O(n \log n)$
- 空间：$O(n)$
