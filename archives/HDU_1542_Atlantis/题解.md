# HDU_1542_Atlantis

- **来源**：HDU 1542
- **标签**：扫描线、离散化、线段树、矩形并面积
- **日期**：2026-08-20

## 一句话题目

求平面上若干轴对齐矩形所覆盖区域的总面积。

## 一句话题解

按 $y$ 扫描，用离散化后的线段树维护当前被覆盖的 $x$ 区间总长度，乘以相邻扫描线的高度差累加。

## 题目描述

输入包含若干测试用例。每个用例第一行给整数 $n$（$1 \le n \le 100$），接下来 $n$ 行每行四个实数 $x_1, y_1, x_2, y_2$（$0 \le x_1 < x_2, y_1 < y_2 \le 100000$），表示一个矩形的左上角和右下角。输入以单独一行 $0$ 结束。

对每个测试用例输出：

```
Test case #k
Total explored area: a
```

其中 $k$ 为测试用例编号（从 $1$ 开始），$a$ 为总面积，保留两位小数。每个用例后输出一个空行。

## 解法 1：扫描线 + 离散化 + 线段树

### 思路

1. 将每个矩形拆成两条水平扫描线：下边界 $(y_1, x_1, x_2, +1)$ 和上边界 $(y_2, x_1, x_2, -1)$。
2. 将所有 $x$ 坐标离散化并排序去重，相邻坐标形成若干基本区间 $[xs_i, xs_{i+1}]$。
3. 建立线段树，每个叶子节点对应一个基本区间，维护该区间的原始长度 `len`；内部节点 `len` 为子节点之和。
4. 按 $y$ 从小到大处理扫描线。对于相邻两条扫描线 $line_{i-1}$ 和 $line_i$，当前线段树根节点的 `v` 即为该 $y$ 层被覆盖的 $x$ 总长度，贡献面积为 `v * (line_i.y - line_{i-1}.y)`。
5. 处理完面积贡献后，对当前扫描线对应的 $x$ 区间进行 `update`：完全覆盖则 `d += delta`，然后 `pull` 更新 `v`。

### 与普通线段树的区别

这道题中的线段树**有 tag 但不需要 `push`**。这里的 `d` 表示覆盖层数（而不是区间加的懒标记），核心规则：

- 若 `d > 0`，说明该节点代表的整个区间被至少一个矩形完全覆盖，`v = len`。
- 若 `d == 0`，说明没有完整覆盖该区间的矩形，`v` 由子节点决定（叶子则为 $0$）。

因此在 `update` 中，无论是完全覆盖直接返回，还是递归到子节点后返回，都只需调用 `pull` 即可，不需要下传懒标记。

### 复杂度

- 时间：$O(n \log n)$（排序 + 2n 次线段树更新）
- 空间：$O(n)$

### 坑点

1. **`find` 的参数必须是 `double`**：坐标是实数，若写成 `int find(int x)`，传入 `7.8` 会被截断成 `7`，导致 `lower_bound` 返回错误下标，矩形 $x$ 区间映射错误。
2. **数组要开够**：最多有 $2n = 200$ 条扫描线，原代码 `N = 110` 会越界。
3. **`pull` 要正确处理叶子节点**：叶子节点没有子节点，不能访问 `tr[u*2]` 和 `tr[u*2+1]`，否则读取未初始化内存，样例会从 `180.00` 变成 `75.00`。
4. **输出格式**：每个测试用例后要有空行，面积保留两位小数。

## 样例

### Sample 1（基本功能）

**输入：**

```
2
10 10 20 20
15 15 25 25.5
0
```

**输出：**

```
Test case #1
Total explored area: 180.00

```

**说明：** 两个矩形相交面积为 $5 \times 5 = 25$，并面积为 $100 + 105 - 25 = 180$。

---

### Sample 2（坑点：浮点坐标与 `find` 截断）

**输入：**

```
3
1.3 2.4 11.4 16.0
7.6 4.2 15.2 9.4
7.8 12.1 9.8 17.9
0
```

**输出：**

```
Test case #1
Total explored area: 160.92

```

**说明：** 包含小数的 $x$ 坐标若用 `int find(int x)` 会被截断，导致第三个矩形 $[7.8, 9.8]$ 被错误映射为 $[7.6, 9.8]$，面积偏大。
