- **日期**：2026-07-25

## 一句话题目

给一棵以 1 为根的树，每个节点占领需要 `ceil(bugs/20)` 个士兵并获得一定价值；在士兵数不超过 M 的前提下，求包含根的连通子树的最大总价值。

## 一句话题解

树形 DP + 分组背包：`f[u][j]` 表示以 `u` 为根的子树分配 `j` 个士兵能获得的最大价值；合并子树时 `k` 必须从 1 开始（进入子树至少需要 1 个士兵）。

## 题目描述

（来自 HDU 1011）

地下基地是一棵树，1 号房间是入口。每个房间有一定数量的 bugs 和可能藏有 brain。一个士兵可以干掉 20 个 bugs。为尽快结束战斗，每经过一个房间就要留下足够士兵清掉该房间所有 bugs；士兵不会重复进入房间。

选择若干房间（必须是包含根的连通子树），使得所用士兵数不超过 M，且捕获 brain 的价值之和最大。

**输入**：多组测试数据。每组第一行 `N M`，接下来 N 行每行 `bugs possibility`，再接下来 `N-1` 行边。以 `-1 -1` 结束。

**输出**：每组一行最大价值。

**数据范围**：`0 < N, M <= 100`

## 解法 1：树形 DP + 分组背包

### 思路

1. 把每个房间的士兵花费转换为 `cost = ceil(bugs / 20)`。
2. 设 `f[u][j]` 为以 `u` 为根的子树使用 **恰好** `j` 个士兵时能获得的最大价值。
3. 初始化：
   ```
   f[u][j] = -INF          (j < cost[u])
   f[u][j] = W[u]          (j >= cost[u])
   ```
   多余的士兵可以浪费在 `u` 这个房间里。
4. 对每个子节点 `v` 做分组背包：
   ```
   for j = m .. 1
       for k = 1 .. j
           f[u][j] = max(f[u][j], f[u][j-k] + f[v][k])
   ```
5. 答案：`max(0, f[1][m])`。

### 复杂度

- 时间：O(N · M²)，`100 * 100² = 10⁶`，可过。
- 空间：O(N · M)。

### 代码

见 `correct_code_01.cpp`。

### 坑点

1. **`k` 必须从 1 开始**  
   从父房间走进子房间至少需要 1 个士兵。如果 `k = 0` 被允许，像“0 bugs 的子房间”就会被免费拿走，导致答案偏大。

2. **不要给所有房间强制定 `cost = max(1, ceil(bugs/20))`**  
   入口房间是起点，没有“走过去”的费用；如果 bugs=0，入口可以免费站住。给所有房间加 `max(1, ...)` 会错误地限制入口。

3. **`m == 0` 必须特判输出 0**  
   即使入口房间 bugs=0，评测数据也约定没有士兵时答案为 0。

4. **答案是 `max(0, f[1][m])`**  
   如果入口房间都进不去，`f[1][m]` 是 `-INF`，需要截断成 0。

5. **多组数据要重置前向星**  
   每组数据都要把 `idx` 和 `H[]` 清空。

6. **调试中遇到的原始错误**  
   - 初始代码把 `V[i]` 误写成 `V[u]`，导致所有房间花费被算成 0。  
   - 原始错误代码未归档（`main.cpp.orig` 已清理）。

## 样例

### Sample 1（基本功能）

**输入：**
```
5 10
50 10
40 10
40 20
65 30
70 30
1 2
1 3
2 4
2 5
1 1
20 7
-1 -1
```

**输出：**
```
50
7
```

**说明：** 官方样例；第一个测试用例最优为入口→2→4，花费 `3+2+4=9`，价值 `10+10+30=50`。

---

### Sample 2（坑点：k=0 会免费拿脑子）

**输入：**
```
3 1
0 5
0 10
0 20
1 2
1 3
-1 -1
```

**输出：**
```
25
```

**说明：** 入口价值 5，两个子房间都 0 bugs；只有 1 个士兵，最多走进其中一个子房间，所以 `5 + 20 = 25`。若 `k` 从 0 开始，会错误输出 `35`。

---

### Sample 3（边界：m = 0）

**输入：**
```
1 0
0 10
-1 -1
```

**输出：**
```
0
```

**说明：** 没有士兵，即使入口房间没怪，答案也必须是 0。
