# CF_1974D_Ingenuity-2

- **来源**：[Codeforces 1974D — Ingenuity-2](https://codeforces.com/problemset/problem/1974/D)，Codeforces Round 946 (Div. 3)，难度 1400
- **标签**：构造、贪心、模拟
- **日期**：2026-11-06

## 一句话题目

把 $n$ 条移动指令分给两辆都从原点出发的设备，要求每台设备至少执行一条指令，且执行完后两台设备停在同一坐标，求任意一种分配方案或判定无解。

## 一句话题解

设总位移为 $(s_x, s_y)$，两台设备位移相同意味着 $s_x, s_y$ 都必须是偶数，否则无解；一般情况把总位移的一半分给 R、另一半分给 H，若总位移为 $(0,0)$ 则先给 R 一对相反的指令（净位移为 $0$）并保证 H 非空，即可构造出方案。

## 题目描述

火星表面是无限大的坐标平面，探测车 Perseverance-2 与直升机 Ingenuity-2 初始都在原点 $(0,0)$。给定长度为 $n$ 的指令串 $s$，每条指令为下列四种之一：

- `N`：向北移动一米，$(x,y) \to (x,y+1)$；
- `S`：向南移动一米，$(x,y) \to (x,y-1)$；
- `E`：向东移动一米，$(x,y) \to (x+1,y)$；
- `W`：向西移动一米，$(x,y) \to (x-1,y)$。

每条指令必须由两台设备中的一台执行，且**每台设备至少要执行一条指令**。判断是否存在一种分配方式，使得所有指令执行完毕后两台设备位于同一点；若存在，给出任意一种方案。

**输入格式：**

- 第一行是测试组数 $t$。
- 每组测试第一行是整数 $n$，第二行是长度为 $n$、只含 `N`、`S`、`E`、`W` 的字符串 $s$。

**输出格式：**

- 无解时输出一行 `NO`。
- 否则输出一个长度为 $n$ 的字符串 $p$，只含 `R` 与 `H`：$p_i = \text{R}$ 表示第 $i$ 条指令由探测车执行，$p_i = \text{H}$ 表示由直升机执行。
- 若有多组合法方案，输出任意一组。

**数据范围：** $1 \le t \le 10^4$，$1 \le n \le 2\cdot 10^5$，所有测试的 $n$ 之和不超过 $2\cdot 10^5$。

**资源限制：** 时间 $2$ 秒，内存 $256$ MB。

## 解法 1：奇偶性判定 + 贪心分配

### 思路

设探测车 R 的净位移为 $(r_x, r_y)$，直升机 H 的净位移为 $(h_x, h_y)$，总位移为 $(s_x, s_y) = (r_x + h_x,\ r_y + h_y)$。

两车最终同点即 $r_x = h_x$、$r_y = h_y$，于是 $s_x = 2r_x$、$s_y = 2r_y$。因此**总位移的两个分量必须都是偶数**，只要有一个是奇数就直接输出 `NO`（例如 `WWW` 的总位移为 $(-3,0)$）。

若均为偶数，就让 R 承担总位移的一半：

- 若 $s_x > 0$，R 需要 $s_x/2$ 条 `E`；若 $s_x < 0$，R 需要 $-s_x/2$ 条 `W`；
- $y$ 方向同理，$s_y > 0$ 取 `N`，$s_y < 0$ 取 `S`。

从左到右扫描指令串，默认全部交给 H；遇到"R 还需要的同向指令"就把它给 R 并把该方向的需求数量减一。最后 R 的净位移恰为 $(s_x/2, s_y/2)$，H 的净位移为总位移减去它，同样恰为 $(s_x/2, s_y/2)$，二者必然相等。由于这些数量不超过对应指令的实际条数（净位移为正方向的一半，必然有足够多条），贪心一定能凑齐。

**总位移为 $(0,0)$ 的边界：** 此时 R 需要的指令数为 $0$，上面的分配会把所有指令都给 H，R 一条都没执行，不合法。这时改为：把第 $1$ 条指令和**之后第一条与它方向相反的指令**交给 R（这一对净位移为 $0$），其余全部交给 H。由总位移为 $0$ 可知相反方向的指令一定存在；只要 H 非空（这两条指令不是全部指令），方案就合法。

唯一真正无解的情况是：总位移为 $(0,0)$ 且 $n = 2$（如 `SN`、`WE`），此时必须把两条指令分别给两台设备，但它们净位移都不为 $0$，只能输出 `NO`。

### 复杂度

- 时间：$O(n)$，每组数据只需一次扫描（总位移）+ 一次分配扫描。
- 空间：$O(n)$，用于存放答案串。

## 样例

### Sample 1（基本功能）

**输入：**

```
1
6
NENSNE
```

**输出：**

```
RRHHHH
```

**说明：** R 执行 `N`、`E` 到达 $(1,1)$，H 执行 `N`、`S`、`N`、`E` 也到达 $(1,1)$；官方样例给的是另一种合法方案 `RRHRRH`。

---

### Sample 2（边界：总位移为 $0$ 无法拆分 / 奇数位移）

**输入：**

```
3
2
SN
2
SS
3
WWW
```

**输出：**

```
NO
RH
NO
```

**说明：** `SN` 总位移为 $(0,0)$ 但两条指令必须分给两台设备，净位移无法都归零；`SS` 各分一条 `S` 即可；`WWW` 的 $s_x = -3$ 为奇数，无解。

---

### Sample 3（坑点：总位移为 $(0,0)$ 但 $n > 2$ 有解）

**输入：**

```
1
4
WEWE
```

**输出：**

```
RRHH
```

**说明：** 把 `W`、`E` 给 R，另一对 `W`、`E` 给 H，两台设备净位移都是 $(0,0)$，说明 $0$ 位移时不能直接判无解。
