# 洛谷_P3177_树上染色

- **来源**：洛谷 P3177
- **标签**：树形 DP、树上背包、边贡献
- **日期**：2026-07-11

## 一句话题目

在树中选 k 个点染黑，其余染白，最大化同色点两两距离之和。

## 一句话题解

树形背包：统计每条边两侧同色点对的数量，按子树中黑点个数做背包合并。

## 题目描述

有一棵点数为 n 的树，树边有边权。给定非负整数 k，选择 k 个点染黑，其余 n-k 个染白。收益为所有黑点两两之间的距离加上所有白点两两之间的距离之和。求最大收益。

**输入格式：**  
第一行两个整数 n, k。  
接下来 n-1 行，每行三个正整数 u, v, w，表示边 (u, v) 边权为 w。

**输出格式：**  
一个正整数，表示最大收益。

**数据范围：** $0 \leq k \leq n \leq 2000$，$1 \leq w \leq 10^4$。

## 解法 1：树形背包 DP

### 思路

把树任意定根（这里选 1）。考虑一条边 $e=(u,v)$（$v$ 是 $u$ 的儿子），边权为 $w$。若 $v$ 的子树中有 $k$ 个黑点，则：

- 经过 $e$ 的黑点对的数量为 $k \cdot (m-k)$，其中 $m$ 是全局黑点总数。
- 经过 $e$ 的白点对数量为 $(size[v]-k) \cdot (n-m-(size[v]-k))$。

因此该边对总收益的贡献为：

$$
w \cdot \big[ k(m-k) + (size[v]-k)(n-m-(size[v]-k)) \big]
$$

设 `f[u][j]` 表示以 $u$ 为根的子树中染 $j$ 个黑点能获得的最大收益。合并儿子 $v$ 时枚举 $v$ 子树中的黑点数 $k$：

$$
f[u][j] = \max_{0 \le k \le \min(j, size[v])} \big\{ f[u][j-k] + f[v][k] + w \cdot [ k(m-k) + (size[v]-k)(n-m-(size[v]-k)) ] \big\}
$$

其中 $m$ 为全局黑点总数（输入 $k$ 经颜色对称化后得到的有效值）。由于颜色对称，若 $k > n/2$ 可令 $m = \min(k, n-k)$，最后输出 `f[1][m]`。

### 复杂度

- 时间：$O(n^2)$（树形背包，每对节点至多被合并一次）
- 空间：$O(n^2)$（DP 数组 `f[N][N]`）

### 坑点

调试时发现 3 处错误：

1. **死循环**：`for (int j = ...; j >= 0; j++)` 中写成了 `j++`，应为 `j--`。导致 $j$ 无限增大，访问越界后段错误。
2. **$k$ 未限制子树大小**：内层循环 `k <= j` 会让 $k$ 超过子树 `v` 的节点数，应限制为 `k <= min(j, size[v])`。
3. **黑点贡献公式错误**：原代码用 `k * (j - k)` 按子树内局部黑点计数，但边 $(u,v)$ 对黑点的贡献应取决于全局黑点总数 $m$，即 `k * (m - k)`。白点公式应为 `(size[v] - k) * (n - m - (size[v] - k))`。

## 样例

### Sample 1（基本功能）

**输入：**
```
3 1
1 2 1
1 3 2
```

**输出：**
```
3
```

**说明：** 把根节点 1 染黑，2、3 染白，白点距离和为 1+2=3。

---

### Sample 2（边界：k=0 全白）

**输入：**
```
3 0
1 2 1
1 3 2
```

**输出：**
```
6
```

**说明：** 全白时收益为三对点距离之和：1+2+3=6。

---

### Sample 3（路径：答案为 4）

**输入：**
```
4 2
1 2 1
2 3 1
3 4 1
```

**输出：**
```
4
```

**说明：** 把两端 1、4 染黑，中间 2、3 染白，黑点对距离 3 + 白点对距离 1 = 4。
