# A. Did We Get Everything Covered?

- **来源**：Codeforces Round 921 (Div. 1) - Problem A（同场 Div. 2 的 C 题）
- **标签**：构造、贪心、字符串、dp、最短路
- **日期**：2026-11-20

## 一句话题目

给定 $n,k$ 和只由前 $k$ 个小写字母构成的串 $s$，判断是否**所有**长度为 $n$ 的字母表串都是 $s$ 的子序列；若否，输出一个不是子序列的反例。

## 一句话题解

把 $s$ 从左到右贪心切成尽量多的「凑齐全部 $k$ 种字母」的段并记录每段的收尾字符，能切满 $n$ 段则输出 `YES`，否则把最后一段缺失的字母重复补足 $n$ 位作为反例。

## 题目描述

给定正整数 $n, k$ 与一个长度为 $m$ 的字符串 $s$，其中 $s$ 只包含前 $k$ 个小写英文字母。

判断：由前 $k$ 个小写字母构成的**所有**长度为 $n$ 的字符串，是否都作为子序列出现在 $s$ 中。

若是，输出 `YES`；否则输出 `NO`，并在下一行输出一个长度为 $n$、只由前 $k$ 个小写字母构成、且**不是** $s$ 的子序列的字符串。若有多解，输出任意一个即可。

子序列指从原串中删除若干（可以为零）字符、不改变剩余字符相对顺序后得到的串。

**输入格式**

第一行一个整数 $t$（$1 \le t \le 10^5$），表示数据组数。

每组数据第一行三个整数 $n, k, m$（$1 \le n \le 26$，$1 \le k \le 26$，$1 \le m \le 1000$）。

第二行一个长度为 $m$ 的字符串 $s$，只包含前 $k$ 个小写英文字母。

保证所有数据的 $m$ 之和、$n$ 之和均不超过 $10^6$。

**输出格式**

对每组数据，若答案是 `YES` 输出一行 `YES`；否则输出一行 `NO`，再输出一行长度为 $n$ 的反例串。`YES`/`NO` 大小写不敏感。

## 解法 1：贪心分段 + 构造反例

### 思路

**贪心切段。** 从当前指针 $j$ 出发向后扫描，用一个集合 $U$ 记录本段已出现的字母。当 $|U| = k$ 时，说明从段首到当前位置 $p$ 首次凑齐了全部 $k$ 种字母，把 $s[p]$ 计入答案 `res`，然后令 $j \leftarrow p + 1$ 开始切下一段。这样能切出尽量多的段，记段数为 $cnt$（`res` 的长度）。

**判定。** 若 $cnt \ge n$，取前 $n$ 段。因为每段内部都含有全部 $k$ 种字母，任意给一个长度为 $n$ 的串 $t = t_1 t_2 \dots t_n$，只需在第 $i$ 段内部按顺序找到 $t_i$ 即可（段的先后顺序天然满足），所以 $t$ 必是子序列，答案为 `YES`。

**构造反例。** 若 $cnt < n$，说明第 $cnt + 1$ 段（从 $p_{cnt} + 1$ 开始的后缀）缺失至少一种字母。设该后缀缺失字母 $c$（取最小的即可），令

$$
w = res + \underbrace{c\,c\,\dots\,c}_{n - cnt \text{ 个}} .
$$

显然 $|w| = n$ 且只用前 $k$ 个字母，下面证明 $w$ 不是子序列。

记第 $i$ 段为 $[p_{i-1} + 1,\, p_i]$（$p_0 = -1$），即在 $[p_{i-1}+1, p_i - 1]$ 内字母种类不足 $k$。特别地，设 $s[p_i]$ 为第 $i$ 段的收尾字符，若 $s[p_i]$ 在 $[p_{i-1}+1, p_i-1]$ 中出现过，那么该前缀已经收齐 $k$ 种字母，与 $p_i$ 是**首次**收齐相矛盾。因此

> $s[p_i]$ 在区间 $[p_{i-1}+1,\ p_i-1]$ 中不出现，即 $s[p_i]$ 的所有出现位置要么 $\le p_{i-1}$，要么 $\ge p_i$。

反设 $w$ 是子序列，取一组嵌入位置 $q_1 < q_2 < \dots < q_n$。由于 $c$ 在 $[p_{cnt}+1, m-1]$ 中完全不出现，$w$ 末尾那些 $c$ 只能匹配在 $\le p_{cnt}$ 的位置，于是 $q_{cnt} < p_{cnt}$。又 $q_{cnt}$ 是 $res[cnt] = s[p_{cnt}]$ 的一次出现，由上面的性质知 $q_{cnt} \le p_{cnt-1}$；同理 $q_{cnt-1} < q_{cnt} \le p_{cnt-1}$ 推出 $q_{cnt-1} \le p_{cnt-2}$，一路回溯得到 $q_1 \le p_0 = -1$，矛盾。$cnt = 0$ 时 $w = c^n$ 而 $c$ 在 $s$ 中根本不出现，同样矛盾。

所以构造合法。实现上「段的收尾字符」恰好就是当前后缀中**首次出现位置最靠后**的那个字母，这与官方题解「取首次出现位置最靠后的字母作为反例的下一位」是同一套贪心。

关于最后补位：失败发生在第 $cnt+1$ 段，此时 `res` 只有 $cnt$ 个字符，故需补 $n - cnt$ 位；因 $cnt \le n - 1$，补的位数恒为正，不存在下溢。

### 复杂度

- 时间：$O\left(\sum m\right)$，指针 $j$ 单调右移，每条数据只扫一遍 $s$
- 空间：$O(k)$

### 坑点

**段尾字符没有推进指针（本解法最初的错误，导致 WA）。**

内层循环写成

```cpp
for (; j < m; j++) {
    ...
    if (int(hs.size()) == K) {
        res += s[j];
        break;        // 缺少 j++，j 停留在 p
    }
}
```

`for` 的 `j++` 在 `break` 时会被跳过，于是下一段又从 $p$ 而非 $p + 1$ 开始扫描，相邻两段**重叠**了一个字符。每段实际跨度被缩短，可能凭空切出更多段，从而把 `NO` 误判成 `YES`（只会造成这一方向的错误）。

最小反例（`n = 3, k = 2, s = bbbbabab`）：

- 正确过程：第 1 段 `bbbba` 在下标 $4$ 收齐 $\{a,b\}$；第 2 段从 $5$ 开始，`ba` 在下标 $6$ 收齐，此时 `res = aa`；第 3 段只剩 `b`，凑不齐，缺 `a`，补 $3 - 2 = 1$ 位，得 `aaa`，而 `aaa` 不是 `bbbbabab` 的子序列，应输出 `NO`。
- 错误过程：第 1 段结束后 $j$ 仍为 $4$，第 2 段从 `ab` 起算、第 3 段从 `ba` 起算，三段全部凑齐，于是错误地输出 `YES`。

**另一个容易踩的坑：本题是多解题，不能逐字对样例。** 官方样例第 2 组期望输出 `aa`，第 3 组期望输出 `ccc`，而本解法输出的是 `ba` 与 `cbc`——它们同样都不是子序列，属于合法答案。若用 `diff` 比对样例，会误以为代码错了；必须写一个 checker 校验「判定是否正确 + 反例是否真不是子序列」，本题的正确性才能被真正验证。

## 样例

### Sample 1（基本功能）

**输入：**

```
3
2 2 4
abba
2 2 3
abb
3 3 10
aabbccabab
```

**输出：**

```
YES
NO
ba
NO
cbc
```

**说明：** 官方样例。第 1 组 `abba` 含有长度 2 的全部 $4$ 个串，输出 `YES`；第 2 组 `abb` 中 `aa` 缺一个 `a`，本解法给出同样非子序列的 `ba`；第 3 组本解法给出 `cbc`（`c` 在下标 4、`b` 在下标 7，之后已无 `c`）。官方对应输出为 `YES / NO aa / NO ccc`，多解均被接受。

---

### Sample 2（坑点：段尾字符未推进指针导致误判 YES）

**输入：**

```
1
3 2 8
bbbbabab
```

**输出：**

```
NO
aaa
```

**说明：** 修正前输出 `YES`，是错误的：`aaa` 中只有两个 `a`，不可能是 `bbbbabab` 的子序列。三段贪心只切出 2 段（`bbbba` 与 `ba`），剩余后缀只有 `b`，缺 `a`，补足 3 位得到 `aaa`。

---

### Sample 3（边界：$k=1$、$n=1$、整串恰好一种排列、串长不足）

**输入：**

```
4
2 1 1
a
1 1 1
a
26 26 26
abcdefghijklmnopqrstuvwxyz
3 2 2
ab
```

**输出：**

```
NO
aa
YES
NO
zaaaaaaaaaaaaaaaaaaaaaaaaa
NO
baa
```

**说明：** 第 1 组 $k=1$ 时唯一的长度 2 串是 `aa`，而 `s` 只有一个 `a`，输出 `NO / aa`；第 2 组 $n=1$ 且 `a` 存在，输出 `YES`；第 3 组 `s` 是字母表的一次排列，$n=26$ 需要 `zzz…` 这类重复串，输出 `NO` 且反例为 `z` 后接 25 个 `a`；第 4 组串长 $2 < n + k - 1$，只能切出 1 段，反例 `baa` 中的 `a` 在 `b` 之后已不存在。
