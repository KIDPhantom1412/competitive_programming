## 一句话题目

两片各有 $n$ 个节点的森林（Mocha 和 Diana 各一片），给两边加**相同的**边，要求加完后两边仍是森林，求最多能加多少条边并输出方案（Hard Version，$n \le 10^5$）。

## 一句话题解

把两片森林的连通块看成网格的行与列（格子 = 同属某行块与某列块的点），一次操作 = 取不同行不同列的两个非空格子连边并合并两行两列；行/列各维护非空格子集合小合大合并，$O(n \log^2 n)$ 做满 $\min(c_1, c_2) - 1$ 次操作。

## 题目描述

森林是无环无向图（不一定连通）。Mocha 和 Diana 各有一片 $n$ 个节点的森林，想给两片森林加边，要求：

- 加边后两边都仍是森林；
- 两边加的边必须完全相同：$(u, v)$ 加给 Mocha 就必须加给 Diana，反之亦然。

求最多能加多少条边，并输出方案（任意一个即可）。

**输入**：第一行三个整数 $n, m_1, m_2$（$1 \le n \le 10^5$，$0 \le m_1, m_2 < n$）；接下来 $m_1$ 行是 Mocha 森林的边，再 $m_2$ 行是 Diana 森林的边，每行两个整数 $u, v$（$1 \le u, v \le n$，$u \ne v$）。

**输出**：第一行输出最大边数 $h$，接下来 $h$ 行每行输出一条边 $u, v$。多解输出任意一个即可。

**限制**：时间 $2$ 秒，内存 $256$ MB。与 Easy Version 唯一区别是 $n$ 的范围（Easy 为 $n \le 10^3$）。

## 解法 1：网格模型 + 行列集合小合大

### 思路

**网格模型**。行 = Mocha 的连通块，列 = Diana 的连通块，格子 $(i, j)$ = 同时属于 Mocha 块 $i$ 与 Diana 块 $j$ 的点。边 $(u, v)$ 合法当且仅当 $u, v$ 所在格子**不同行且不同列**（同行 → Mocha 成环，同列 → Diana 成环）；加边后两行合并、两列合并。每个格子只需保留一个代表点。

**维护**。`A[row]` = 该行的非空列集合，`B[col]` = 该列的非空行集合，`overlap[row][col]` = 格子代表点。合并两行（或两列）时小集合插入大集合，元素在对侧集合中同步改名，小集合删除——每个元素一生只被移动 $O(\log n)$ 次。

**WLOG 行数 $\le$ 列数**。一次操作使行、列各减 $1$，行数减列数保持不变；而下面的论证需要行数 $\le$ 列数。森林连通块数恒为 $n - m$，故 $m_1 < m_2$ 时整体交换两片森林的角色即可。

**每次操作**：弹出集合最大的两行 $x, y$（并保证 $|A[x]| \ge |A[y]|$），取 $c = \min A[y]$、$b = \min A[x]$，若 $b = c$ 则把 $b$ 换成 $A[x]$ 的第二个元素（安全性见下），输出边 $(\text{overlap}[x][b],\ \text{overlap}[y][c])$，然后小合大合并行 $x, y$ 与列 $b, c$。

**正确性与最优性**：只要还剩 $\ge 2$ 行，合法操作就存在：

- 若存在某行列集合 $\ge 2$ 个元素（弹出的 $x$ 必是它），任取另一行 $y$ 与 $c \in A[y]$，$A[x]$ 中必有 $\ne c$ 的元素作 $b$；
- 否则所有行都是单点集合。格子总数 $=$ 行数，而非空列数 $\le$ 格子总数，结合行数 $\le$ 列数知全部取等——每列也恰好一个格子，各行的单点列互不相同，任取两行自动 $b \ne c$。

于是操作能一直做到某一边只剩 $1$ 个连通块。每条边使两边连通块数各减 $1$，故

$$
h = \min(c_1, c_2) - 1
$$

即达到最优（与 Easy Version 结论相同，但其 $O(n^2)$ 枚举在 $n = 10^5$ 下不可行）。

### 复杂度

- 时间：$O(n \log^2 n)$（每个元素被移动 $O(\log n)$ 次，每次 $O(\log n)$）
- 空间：$O(n)$（非空格子数 $\le n$）

### 坑点

- **DSU 未初始化**：全局数组初始全 $0$，必须先置 `P1[i] = P2[i] = i`。漏掉后 `find` 恒返回 $0$、所有点被并成同一块，输出里还会出现不存在的 $0$ 号点。
- **漏掉 WLOG 行列交换**（`if (m1 < m2) std::swap(P1, P2);`）：正确性论证的第二个分支依赖行数 $\le$ 列数。缺失时存在这样的状态：弹出的两行都已退化成同一个单点集合 $\{c\}$，`b1 == b2` 之后

  ```cpp
  b1 = *++it;   // A[a1] 只有一个元素，++it 解引用 end()，UB
  ```

  会解出在某一侧成环的非法边。
- **弹出的第二行取错集合**：$b_2$ 应取自行 $a_2$ 的列集合 `A[a2]`，误写 `B[a2]`（键是列）会对空 `set` 解引用 `begin()`。
- **小合大比较对象错误**：合并两行应比较 `A[a1].size()` 与 `A[a2].size()`，误拿行集合与列集合（`A[a1].size() < B[a2].size()`）比较会破坏"迭代小集合"的保证。
- **size 条目失效（tutorial 官方代码同样存在）**：列合并时，同时持有被合并两列的行会少一个格子、集合变小，必须同步更新该行的 size 条目。否则"弹出最大行"依据的是陈旧大小——两个实际已退化为单点的行被当作最大行弹出，正好触发上面的 `*++it` UB。用 `priority_queue` 还须额外防止同一行出现两条有效条目（它不能按值删除，只能惰性删除），用 `std::set<std::pair<int,int>>` 对旧值 `erase` + 新值 `insert` 最稳妥。反例见 Sample 4：未同步维护的写法会输出 $(2, 4)$ 这条使 Diana 一侧成环的边。
- **本题答案不唯一**（Special Judge）：验证应写 checker 检查「每条边加入后两边仍无环 + 边数等于 $\min(c_1, c_2) - 1$」，不能与样例输出 `diff` 对拍。

## 样例

### Sample 1（基本功能）

**输入：**
```
5 3 2
5 4
2 1
4 3
4 3
1 4
```

**输出：**
```
1
2 4
```

**说明：** Mocha 连通块为 $\{5,4,3\}, \{2,1\}$，Diana 连通块为 $\{4,3,1\}, \{2\}, \{5\}$，$h = \min(2, 3) - 1 = 1$。（本输出与官方一致；多解时任一合法方案均可。）

---

### Sample 2（边界：答案为 0）

**输入：**
```
3 2 2
1 2
2 3
1 2
1 3
```

**输出：**
```
0
```

**说明：** 两边都已是 $3$ 个点的树（各只剩 $1$ 个连通块），任意加边都会两边同时成环，$h = \min(1, 1) - 1 = 0$。

---

### Sample 3（边界：单点）

**输入：**
```
1 0 0
```

**输出：**
```
0
```

**说明：** $n = 1$ 时没有任何可加的边，$h = 0$。
