## 一句话题目

维护一个数列，支持区间加 k 与查询区间和两种操作。

## 一句话题解

用双树状数组维护差分数组：tr1 存差分值、tr2 存差分加权值，利用前缀和公式 P(x) = x·S1(x) − S2(x) 实现 O(log n) 的区间加与区间求和。

## 题目描述

已知一个数列 {a_i}，需要进行两种操作：

1. `1 x y k`：将区间 [x, y] 内每个数加上 k。
2. `2 x y`：输出区间 [x, y] 内每个数的和。

**输入**：第一行两个整数 n, m；第二行 n 个整数 a_i；接下来 m 行每行 3 或 4 个整数表示一个操作。

**输出**：对每个操作 2 输出一行整数。

**数据范围**：1 ≤ n, m ≤ 10^5，a_i、k 为正数，任意时刻数列的和不超过 2×10^18（需用 long long）。

## 解法 1：双树状数组（差分 + 前缀和公式）

### 思路

设 d 为 a 的差分数组（区间加 [l, r] 等价于 d_l += k，d_{r+1} −= k）。前缀和：

```
P(x) = Σ_{i≤x} a_i = Σ_{j≤x} d_j·(x−j+1) = (x+1)·Σd_j − Σ j·d_j
```

用 tr1 维护 d 的前缀和 S1(x) = Σd_j，tr2 维护 Σ(j−1)·d_j，则 P(x) = x·S1(x) − S2(x)。区间加 [l, r] 时：

- tr1：位置 l 加 k，位置 r+1 减 k
- tr2：位置 l 加 (l−1)·k，位置 r+1 减 r·k

区间查询 [l, r] = P(r) − P(l−1)。

### 复杂度

- 时间：O((n + m) log n)
- 空间：O(n)

见 `correct_code_01.cpp`。

### 坑点

1. **初始化不要手动差分**（WA 主因）：该双树状数组维护的就是原数组 a，读入 a_i 时直接 `update(i, i, a_i)` 即可。若误用差分思想写成 `update(i, i, cur - pre)`，建出来的会是原数组的差分数组，所有查询结果错误（样例会输出 1/-1/10 而非 11/8/20）。
2. **k 要用 long long**：题目只保证数列和不超过 2×10^18，k 可能超过 int 范围，用 `int k` 读入会溢出。
