## 一句话题目

在线查询区间 $[l,r]$ 中所有不同整数的「首次出现位置」（升序），输出第 $\lceil k/2 \rceil$ 个位置（$k$ 为区间内不同整数个数）；每次查询的参数依赖上一个答案解码。

## 一句话题解

从右往左建可持久化线段树，`root[i]` 维护后缀 $[i,n]$ 中每个值首次出现的位置（重复值删旧插新）；查询时在 `root[l]` 上统计 $\le r$ 的位置数得到 $k$，再在树上二分第 $\lceil k/2 \rceil$ 小的位置。

## 题目描述

给定长度为 $n$ 的整数序列 $a_1,a_2,\cdots,a_n$，共 $m$ 次查询。第 $i$ 次查询给出 $l_i, r_i$，记子序列 $a_{l_i},\cdots,a_{r_i}$ 中每个整数首次出现的位置（按原序列下标，升序）为 $p_1^{(i)}<p_2^{(i)}<\cdots<p_{k_i}^{(i)}$，其中 $k_i$ 为区间内不同整数个数，输出 $p_{\lceil k_i/2 \rceil}^{(i)}$。

读入的 $l_i', r_i'$ 需要按上一问答案 $ans_{i-1}$（$ans_0=0$）解码：

$$l_i = \min\{(l_i'+ans_{i-1})\bmod n+1,\ (r_i'+ans_{i-1})\bmod n+1\}$$
$$r_i = \max\{(l_i'+ans_{i-1})\bmod n+1,\ (r_i'+ans_{i-1})\bmod n+1\}$$

- 输入：第一行 $T$（$T\le 2$）；每组数据 $n, m$（$n,m\le 2\times10^5$），一行 $n$ 个整数（$0\le a_i\le 2\times10^5$），随后 $m$ 行 $l_i', r_i'$。
- 输出：每组数据一行 `Case #x: p1 p2 ... pm`。
- 限制：4.5s / 128MB。

## 解法 1：可持久化线段树（主席树）

### 思路

经典「区间不同数」技巧：从右往左扫描，用 `ht[v]` 记录值 $v$ 当前最近一次出现的位置。扫到位置 $i$ 时：

- 若 $a_i$ 未出现：`root[i] = root[i+1]` 在位置 $i$ 加 1；
- 若已出现：先在旧位置 `ht[a_i]` 减 1，再在位置 $i$ 加 1。

这样 `root[i]` 中恰好包含后缀 $[i,n]$ 每个值**首次**出现的位置（各 +1）。对查询 $[l,r]$：`root[l]` 中落在 $[l,r]$ 内的位置数就是不同整数个数 $k$；再在 `root[l]` 上按权值二分，找第 $\lceil k/2 \rceil = (k+1)/2$ 小的位置即为答案。

查询时以空树 `root[n+1]` 作为减法的另一端（即 `querySum(root[n+1], root[l], ...)`）。由于答案强制在线（依赖 $ans_{i-1}$ 解码），必须边查询边更新 `res`。

### 复杂度

- 时间：$O((n+m)\log n)$
- 空间：$O(n\log n)$，每次位置变化产生 $O(\log n)$ 个新节点，最坏约 $2n\log n \approx 7.2\times10^6$ 个节点

### 代码

见 `correct_code_01.cpp`。

### 坑点

1. **`queryKth` 中左子树和写错**：写成了 `tr[v].sum - tr[u].sum`（整个节点的总和），导致向左/向右判断错误，返回树中不存在的位置。应为 `tr[tr[v].l].sum - tr[tr[u].l].sum`。
2. **`res`（即 $ans_{i-1}$）忘记更新**：答案只输出没赋值给 `res`，从第二个查询起解码出的 $l, r$ 全部错误。
3. **输出格式**：要求每个测试点输出一行 `Case #x: p1 p2 ... pm`，前缀和单行空格分隔缺一不可。

## 样例

### Sample 1（基本功能，同时暴露坑点 1、2）

**输入：**
```
2
5 2
3 3 1 5 4
2 2
4 4
5 2
2 5 2 1 2
2 3
2 4
```

**输出：**
```
Case #1: 3 3
Case #2: 3 1
```

**说明：** 题目官方样例。第一组第二个查询依赖 $ans_1=3$ 解码，可暴露「`res` 未更新」的 bug；查询路径经过多分支，可暴露 `queryKth` 左子树和的错误。

---

### Sample 2（自定义：值域小、重复多）

**输入：**
```
1
6 3
2 1 2 3 1 3
1 6
2 5
3 4
```

**输出：**
```
Case #1: 1 2 2
```

**说明：** 小值域多重复数据，验证「删旧位置、插新位置」逻辑及答案链式解码（$ans$ 依次为 1、2、2，第三问用 $ans_2=2$ 解码后 $l=r=2$）。
