# HDU 4027 Can you answer these queries?

- **来源**：HDU 4027 / The 36th ACM/ICPC Asia Regional Shanghai Site Online Contest
- **标签**：线段树, 区间开方, 势能线段树
- **日期**：2026-08-05

## 一句话题目

维护一个数组，支持两种操作：区间每个数开平方（向下取整），区间求和。

## 一句话题解

线段树维护区间和。由于正整数的平方根收敛到 1 极快（≤6 次），用 tag 标记区间是否全为 1，若全为 1 则跳过更新，每个位置最多被暴力更新约 6 次，均摊 O((N+M) log N)。

## 题目描述

有 N 艘战舰排成一行（1 ≤ N ≤ 100000），每艘战舰有一个耐久值 Ei。我方秘密武器每次攻击可对一段连续战舰的耐久值执行开平方（向下取整）操作。指挥官要求回答区间耐久值之和的查询。

**输入格式：**

多组测试数据，EOF 结束。每组数据：

- 第一行：整数 N
- 第二行：N 个整数 Ei，保证所有 Ei 之和 < 2^63
- 第三行：整数 M（1 ≤ M ≤ 100000）
- 接下来 M 行：每行三个整数 T, X, Y
  - T = 0：对区间 [X, Y] 每个数开平方
  - T = 1：查询区间 [X, Y] 的和

**输出格式：**

每组数据先输出 `Case #编号:`，然后每个查询操作输出一行结果。每组数据后跟一个空行。

**数据范围：**

- N, M ≤ 100000
- 所有 Ei 之和 < 2^63
- 多组测试数据

## 解法 1：势能线段树（区间开方 + 剪枝）

### 思路

本题的核心在于 **平方根收敛极快**：

- 一个正整数经过不超过 6~7 次开平方就会变成 1（对于 ≤ 2^63 的值）。
- 一旦变成 1，再怎么开平方还是 1，无需再操作。

因此，线段树每个节点维护两个信息：

1. `v`：区间和（`long long`）
2. `tag`：该区间是否已"稳定"（即区间所有值都是 1）

`tag` 的判断条件：`区间和 == 区间长度`。因为：
- 所有值都 ≥ 1（**题目隐含保证耐久值不为 0**）
- 若区间和等于区间长度，说明每个位置都是 1，区间已稳定

更新时：
- 若节点 tag 为 true 且完全覆盖，直接返回（剪枝）
- 否则递归到叶子暴力开方，回溯时 pushup 更新 v 和 tag

查询就是标准的线段树区间求和。

这样每个位置最多被暴力更新约 6 次，总复杂度 O((N+M) log N)。

### 复杂度

- 时间：O((N+M) log N)（均摊）
- 空间：O(N)

### 坑点

1. **耐久值永不等于 0（隐含条件）**：题目未明确声明，但实际数据中 endurance 始终 ≥ 1。这是 tag 剪枝策略正确的前提——若存在 0，则 `区间和 == 区间长度` 无法等价于"区间全为 1"。题面中「sum of all endurance value is less than 2^63」暗示了值的范围，但并未显式排除 0。实测所有测试数据中 Ei ≥ 1。

2. **X 和 Y 大小关系不确定**：题目不保证 X ≤ Y，代码中必须对 l > r 的情况进行 swap。这是 HDU 系列题目经典坑点。

3. **区间和用 long long**：sum < 2^63 意味着需要 64 位整数。线段树节点的 v 和查询结果都要用 `long long`。

4. **多组数据 + 空行**：每组数据输出 `Case #编号:`，且每组末尾输出一个空行。`Case #编号:` 后面也要换行。

5. **不要用懒惰标记（lazy tag）**：开平方操作不满足区间可加性——不能通过一个 lazy 值来表示"这个区间所有数都开方了 k 次"。只能用 tag 做"是否全为 1"的剪枝，无法使用传统的区间修改 lazy 标记。
